
# setup

### Setup

* setup 函数是 Vue 3 组合式 API 的入口点，用于组织和封装组件的逻辑。
* 它在组件实例初始化时，props 解析之后，data、computed、methods 等选项之前执行。可以把它看作是一个在组件创建之前执行的函数，用来定义组件所需的响应式数据、方法和生命周期钩子等。


beforeCreate： beforeCreate（选项式 API）：此钩子在 Vue 2 选项式 API 中有，在 Vue 3 组合式 API 里基本不使用。在这个阶段，组件实例刚刚开始初始化，data、props 等都还未初始化

### 参数

* setup 函数接收两个参数：
    * **props**：是一个响应式对象，包含了父组件传递给子组件的所有属性。需要注意不能对其进行解构赋值，因为解构会破坏其响应式特性。
    * **context**：是一个普通对象，包含三个属性：
        * attrs：包含了所有未定义为 props 的属性。
        * slots：用于访问组件的插槽内容。
        * emit：用于触发自定义事件。

### 返回值情况

#### 返回对象


```vue
<!-- 返回一个普通对象，对象中的属性和方法会暴露给模板使用。适用于需要在模板中使用定义的数据和方法的场景 -->
<script>
import { ref } from 'vue';
export default {
  setup() {
    const count = ref(0);
    const increment = () => {
      count.value++;
    };
    return {
      count,
      increment
    };
  }
};
</script>
```
#### 返回渲染函数
```vue
<!--返回一个渲染函数，用于手动渲染组件。适用于需要更灵活地控制组件渲染逻辑的场景，例如： -->
<script>
import { h, ref } from 'vue';
export default {
  setup() {
    const count = ref(0);
    const increment = () => {
      count.value++;
    };
    return () =>
      h('div', [
        h('p', `Count: ${count.value}`),
        h('button', { onClick: increment }, 'Increment')
      ]);
  }
};
</script>
```

### 语法糖 <script setup>

* 语法简洁性：<script setup> 语法糖更加简洁，不需要显式地返回要暴露给模板的数据和方法，变量和函数会自动暴露。而传统 setup 选项需要手动返回一个对象。
* 导入方式：在 <script setup> 中可以直接导入和使用组合式 API 函数，无需额外的操作；传统 setup 选项需要在组件定义中使用。
* 上下文获取：<script setup> 中没有显式的 props 和 context 参数，需要使用 defineProps 和 defineEmits 等宏来获取；传统 setup 选项通过参数直接获取。


```vue

<template>
  <div>
    <!-- 显示父组件传递的 message prop -->
    <p>{{ message }}</p>
    <!-- 点击按钮触发自定义事件 -->
    <button @click="handleClick">Send Event</button>
  </div>
</template>

<script>
import { defineComponent } from 'vue';

export default defineComponent({
  props: {
    message: {
      type: String,
      required: true
    }
  },
  setup(props, context) {
    // context 上有 attrs / slots / emit / expose
    console.log(props.message);
    return {};
  }
});
</script>

<script setup>
// defineProps / defineEmits 是编译器宏，无需 import
import { onBeforeMount, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted } from 'vue';

// 定义 props，这里期望接收一个字符串类型的 message
const props = defineProps({
  message: {
    type: String,
    required: true
  }
});

// 定义可以触发的自定义事件
const emit = defineEmits(['customEvent']);

// 处理按钮点击事件，触发自定义事件并传递数据
const handleClick = () => {
  emit('customEvent', `Response to: ${props.message}`);
};

// 组合式生命周期钩子（对应关系见「生命周期钩子」篇）
onBeforeMount(() => console.log('Before Mount'));
onMounted(() => console.log('Mounted'));
onBeforeUpdate(() => console.log('Before Update'));
onUpdated(() => console.log('Updated'));
onBeforeUnmount(() => console.log('Before Unmount'));
onUnmounted(() => console.log('Unmounted'));
</script>
```

### 适用场景

```js

// 当组件逻辑变得复杂时，使用 setup 可以将不同的逻辑分离，使代码更易于维护和理解。
// 例如，一个包含表单验证、数据请求等复杂逻辑的组件。
    // useCounter.js
    import { ref } from 'vue';
    export function useCounter(initialValue = 0) {
    const count = ref(initialValue);
    const increment = () => {
        count.value++;
    };
    const decrement = () => {
        count.value--;
    };
    return {
        count,
        increment,
        decrement
    };
    }
```
