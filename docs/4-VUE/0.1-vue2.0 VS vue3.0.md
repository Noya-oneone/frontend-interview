# VUE2 VS VUE3

## 1. VUE2 VS VUE3 
 
  * `核心包体积变小了`： Vue3 移除一些不常用的 API、引入tree-shaking,可以将无用模块"剪辑",仅打包需要的,使打包的整体体积变小了
  * `更快了`： 优化了diff 算法 - 增加了静态标记、事件监听缓存、ssr
  * `更加支持typescript`

  * `composition api 、Option api`
    * **Option API** (data、props、computed、methods、watch、template、directives、components)
    * computed: 响应式、缓存、依赖收集、自动更新、不支持异步，无法监听数据的变化、可指定一个函数作为可读属性，也可定义get/set变成可读写属性
    * watch: 监听数据的变化，执行回调函数，不支持异步，无法获取到变化前后的值
    * methods: 实例方法，支持异步，可以访问实例属性、必须调用时才执行
  * **Composition API**
  * **Object.defineProperty()**: 不能监听数组，数组没有getter,setter ，数组长度不定，太长性能负担大、只是监听属性而不是监听对象，需要遍历属性，只能监听属性变化，不能监听属性删减
  * **Proxy**:  `vue3是通过proxy、监听整个对象`,那么对于删除还是监听当然也能监听到、
      * 同时 Proxy并不能监听到内部深层次的对象变化,而Vue3的处理方式是在 `getter中递归响应式`,这样的好处是`真正访问到的内部对象才会变成响应式`,`而不是无脑递归中去递归响`
      * vue2 使用mixin 进行功能混合,vue3 使用组合式API进行功能混合,更加灵活
