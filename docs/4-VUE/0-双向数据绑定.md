# 双向数据绑定

* 渐进式框架、兼容IE9及以上、组件化设计模式 MVVM 模式:  Model、View、ViewModel，数据双向绑定
* 双向数据绑定 v-model、数据劫持&发布-订阅模式 方式

## 双向数据绑定原理

* 双向数据绑定是指：View（视图）和 Model（数据模型）之间存在双向绑定关系，当 View 中的数据发生变化时，Model 中的数据也会跟着变化，反之亦然。
* 实现双向数据绑定主要是通过数据劫持和发布-订阅模式来实现的。

| 特性 | Vue 2.0   | Vue 3.0|
|--|--|--|
| **实现方式** | `Object.defineProperty`   | `Proxy`|
| **性能** | 初始化时性能较低，需要为每个属性单独设置 getter 和 setter | 初始化时性能更高，`Proxy` 代理整个对象|
| **属性添加/删除**| 需要使用 `Vue.set()` 和 `Vue.delete()` 处理| 可以直接添加或删除属性，无需特殊处理|
| **数组监控** | 部分方法拦截，索引和长度变化不触发更新  | 完整监控数组，包括索引和长度变化|
| **代码简洁性**   | 代码较为复杂，需要手动处理响应式的局限性| 代码更简洁，响应式处理更加全面和自动化  |


### `Vue2.0` 数据双向绑定原理
* 数据劫持：通过 Object.defineProperty() 方法来劫持（监控）各属性的 getter 和 setter，在数据发生变化时通知订阅者，触发相应的监听回调。
* 发布-订阅模式：发布者（View）将自己关心的事件发布到消息中心（消息总线），订阅者（Model）订阅自己关心的事件，当事件发生时，订阅者（Model）接收到消息并执行相应的回调函数。

* ES5提供的`Object.defineProperty()方法来劫持（监控）各属性的getter,setter` ，
* 并在数据（对象）发生变化时通知订阅者，触发相应的监听回
`observer数据监听器、compile扫描模板`，
并对指令进行解析，然后绑定指定事件、watcher订阅者关联observe和compile/update 

### `Vue3.0` 数据双向绑定原理

* Vue3.0 使用 Proxy 实现数据双向绑定，Proxy 是 ES6 中新增的一种对象，它可以拦截目标对象的操作，并在操作时做一些额外的事情。
* Proxy 的 get 和 set 方法来实现的。
* 首先需要创建一个 Proxy 实例，并将其作为参数传入 Vue 实例的 data 属性。
```javascript
const proxy = new Proxy(target, handler);
// target: 要包装的目标对象（可以是任何类型的对象，包括数组、函数等）。
// handler: 一个对象，其属性是当执行一个操作时定义代理行为的函数。
get(target, property, receiver): 拦截对象属性的读取。
set(target, property, value, receiver): 拦截对象属性的设置。
deleteProperty(target, property): 拦截对象属性的删除。
has(target, property): 拦截 in 操作符。
ownKeys(target): 拦截对象自身属性的读取操作（如 Object.getOwnPropertyNames）。
apply(target, thisArg, argumentsList): 拦截函数调用。
```
* 解决了 Vue 2.0 中的许多问题，如性能瓶颈、数组变动检测、属性添加/删除等
* Vue 3.0 的响应式实现中大量使用了 `Reflect API`，这是 ES6 提供的一个`内置对象，用于拦截对象操作`。它的设计初衷是与 Proxy 对应，使得对原始操作的调用更加自然。（用于拦截和操作对象属性的获取行为）
* Proxy `可以一次性代理整个对象`，而不需要像 Object.defineProperty 那样为每个属性单独定义 getter 和 setter。
* Proxy 可以直接拦截对象属性的添加和删除操作,无需使用 Vue.set 或 Vue.delete 来手动添加响应式属性
* Proxy 可以拦截和处理数组索引的变化以及 length 的变化。

## 数据与视图同步更新

* 数据与视图同步更新是指：当数据发生变化时，视图也会自动更新，反之亦然。
  * * Vue不允许在已经创建的实例上动态添加新的响应式属性、若想实现**数据与视图同步更新**,可采取下面三种解决方案:
  * **Vue.set()**： 通过 Vue.set 向响应式对象中添加一个 property,并确保这个新 property同样是响应式的,
且触发视图更新
  * **Object.assign()**： 直接使用 0bject.assign()添加到对象的新属性不会触发更新1
应创建一个新的对象,合并原对象和混入对象的属性
  * **$forcecUpdated()**： 仅仅影响实例本身和插入插槽内容的子组件
