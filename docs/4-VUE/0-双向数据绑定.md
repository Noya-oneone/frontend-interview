# 双向数据绑定

* Vue 是 `MVVM` 模式：Model（数据）、View（视图）、ViewModel（桥梁）—— View 变化自动同步到 Model，Model 变化自动更新 View。
* 实现 = `数据劫持` + `发布-订阅模式`。

## v-model 的本质（高频考点）

`v-model 只是语法糖`：

```html
<input v-model="msg" />
<!-- 等价于（Vue2） -->
<input :value="msg" @input="msg = $event.target.value" />
<!-- 组件上（Vue3）等价于 -->
<Child :modelValue="msg" @update:modelValue="msg = $event" />
```

所以「双向绑定」= `单向数据流（数据 → 视图）` + `事件监听（视图 → 数据）`，并不神秘。

## 响应式原理：Vue2 vs Vue3

| 特性 | Vue 2（`Object.defineProperty`） | Vue 3（`Proxy`） |
|--|--|--|
| 劫持粒度 | 逐个属性设置 getter/setter，初始化`递归整棵对象树` | `代理整个对象`，访问到哪层才懒代理哪层（惰性深层响应） |
| 属性增删 | 监听不到，需 `Vue.set / Vue.delete` | 直接支持 |
| 数组 | 索引赋值、length 变化监听不到，靠重写 7 个变更方法 | 完整拦截，包括索引和 length |
| 初始化性能 | 深层大对象开销大 | 更快（按需代理） |

### Vue2 实现流程

* `Observer（数据劫持）`：用 `Object.defineProperty` 把 data 的每个属性转成 getter/setter；getter 中`收集依赖`，setter 中`通知更新`。
* `Dep（发布者/消息中心）`：每个属性一个 Dep 实例，维护订阅它的 Watcher 列表；数据变化时 `dep.notify()` 通知所有订阅者。
* `Watcher（订阅者）`：连接 Observer 与 Compile —— 组件渲染 Watcher 在渲染时读取数据完成订阅，收到通知后触发 `update` 重新渲染。
* `Compile（模板编译）`：解析模板指令与插值，初始化视图并为每个绑定注册 Watcher。

简化的劫持代码见 [Vue 的数据劫持源码](./0.1-Vue的数据劫持源码.md)，依赖收集细节见 [vue 依赖收集](./0.2-vue%20依赖收集.md)。

### Vue3 实现要点

```js
const proxy = new Proxy(target, {
  get(target, key, receiver) {
    track(target, key);                       // 收集依赖
    const res = Reflect.get(target, key, receiver);
    return typeof res === 'object' && res !== null ? reactive(res) : res; // 惰性深层代理
  },
  set(target, key, value, receiver) {
    const result = Reflect.set(target, key, value, receiver);
    trigger(target, key);                     // 触发更新
    return result;
  },
  deleteProperty(target, key) {               // 删除属性也能拦截
    const result = Reflect.deleteProperty(target, key);
    trigger(target, key);
    return result;
  },
});
```

* 搭配 `Reflect` 操作原对象：保证 this（receiver）指向正确、行为与语言默认一致。
* `惰性递归`：只有真正访问到的嵌套对象才转为响应式，而不是初始化时无脑深遍历 —— 这是相对 Vue2 的关键性能优化。

## Vue2 中给对象加新属性视图不更新怎么办

* `Vue.set(obj, key, value)`（推荐）：新增属性同样变成响应式并触发更新。
* `Object.assign` 换新对象：`this.obj = { ...this.obj, newKey: 1 }`（直接 assign 到原对象不行）。
* `this.$forceUpdate()`：强制当前组件重渲染，治标不治本，尽量避免。

## 常见考点

* **Vue 是双向绑定，为什么还说「单向数据流」？** props 自上而下单向传递不可反向修改；v-model 的「双向」只是模板层的语法糖，数据流转依然是明确的「事件上行、数据下行」。
* **Proxy 为什么不能被 polyfill？** 它是语言层能力，无法用 ES5 模拟 —— 这是 Vue3 放弃 IE11 的根本原因。
