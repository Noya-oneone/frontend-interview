## Vue CLI 的几大特性

* 1、图形化用户界面（GUI）：
    * 使用 vue ui 命令启动 Vue CLI 的图形化界面。它提供了一个用户友好的方式来创建、管理和配置 Vue 项目。
* 2、插件化架构：
    * 你可以添加或移除插件来定制项目设置，插件之间可以无缝协作。
* 3、强大的项目生成器：
    * Vue CLI 提供了灵活的项目生成器，支持创建项目时选择默认预设或手动配置。
    * 预设可以包括 Babel、TypeScript、ESLint、CSS 预处理器等。
* 4、内置的开发服务器：
    * 提供基于 Webpack 的开发服务器，支持热模块替换（HMR）、代理配置、实时重载等功能，优化开发体验。
* 5、多种模式和环境配置：
    * 支持多种构建模式和环境配置。
    * 可以通过 .env 文件设置不同环境下的变量，例如开发、测试和生产环境。
* 6、集成单元测试和端到端测试支持：
    * Vue CLI 支持集成单元测试（如 Jest）和端到端测试（如 Cypress），帮助进行全面的测试驱动开发。
* 7、现代化的构建工具链：
    * 内置现代化的 Webpack 配置，包括代码分割、压缩、资源管理等，优化生产环境构建输出。
* 8、支持 TypeScript：
    提供 TypeScript 支持，允许在 Vue 项目中使用 TypeScript 进行开发。
* 9、自动代码分割和优化：
    * Vue CLI 自动支持代码分割，帮助减少初始加载时间，提升应用性能。
