## 虚拟 DOM 比较：

Vue 在虚拟 DOM 中维护一个树状结构。当数据更新时，Vue 会生成新的虚拟 DOM 树，并与旧的虚拟 DOM 树进行比较（即 diff 算法）。
如果列表项的 key 是唯一的，Vue 能够根据 key 快速匹配新旧虚拟 DOM 树中的元素，从而高效地更新实际 DOM。

## 避免 DOM 重用：

如果没有 key，Vue 会根据元素的顺序和内容来匹配和重用 DOM 元素，这可能导致不必要的 DOM 操作和性能问题。
有了 key，Vue 可以根据 key 确保在重新渲染时，正确地更新、移动或删除 DOM 元素，避免错误和性能损耗。
