# Vue 依赖收集

## 数据劫持：
Vue 2.x：使用 Object.defineProperty 拦截对象属性的读取和写入。
Vue 3.x：使用 Proxy 劫持对象的访问操作。

## 依赖注册：当组件访问响应式数据时，Vue 会将组件的更新逻辑注册为该数据的依赖。

### vue2.0
Dep 类：Vue 2.x 使用 Dep 类来管理依赖。每个响应式对象都有一个对应的 Dep 实例。
Watcher 类：Watcher 是 Vue 2.x 中的一个类，负责管理组件的更新逻辑。当组件访问某个响应式属性时，Watcher 会将自己注册到该属性的 Dep 实例中。

### vue3.0
* Reactive 和 Ref：Vue 3.x 使用 Reactive 和 Ref 来管理响应式状态。每个响应式对象都维护一个依赖列表。
* 依赖收集：当一个组件访问某个响应式对象时，Vue 3.x 会将当前的 effect（通常是组件的渲染函数）注册到该对象的依赖列表中。


## 触发更新：

当响应式数据发生变化时，Vue 会通知所有依赖于该数据的组件或计算属性，触发视图更新。
