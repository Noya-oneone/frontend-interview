# Vue 渲染的整个过程

1. **组件初始化**：创建组件实例，初始化 props/data 并做`响应式处理`（劫持 + 依赖收集准备）。
2. **模板编译**：`template → 渲染函数`，分三步：
   * `parse`：模板字符串解析成模板 AST；
   * `transform`：优化 AST —— 静态节点标记/提升、Patch Flags（Vue3）；
   * `generate`：生成 render 函数代码。
   * 使用构建工具时这一步发生在`编译期`（vue-loader / @vitejs/plugin-vue），运行时版本无需携带编译器。
3. **首次渲染（mount）**：执行 render 函数生成`虚拟 DOM 树`；渲染过程中读取响应式数据完成`依赖收集`；再将 vnode 转成真实 DOM 挂载（触发 beforeMount → mounted）。
4. **更新（patch）**：数据变化 → 触发依赖的渲染 effect → 进入`异步更新队列`（去重、nextTick 批量）→ 重新执行 render 得到新 vnode → `diff` 新旧树 → 最小化更新真实 DOM（beforeUpdate → updated）。
5. **卸载（unmount)**：移除 DOM、清理依赖与事件（beforeUnmount → unmounted）。

## 常见考点

* **render 函数和 template 的关系？** template 最终都会编译成 render 函数，手写 render/JSX 等于跳过编译步骤（也就失去了模板的编译期优化）。
* **为什么数据连续变化视图只更新一次？** 更新 effect 入队去重，微任务里统一 flush —— 这就是 nextTick 的由来。
