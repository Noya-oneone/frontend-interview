# watch VS watchEffect

## 1. 区别

- `watch`：是 Vue 2.x 的 API，用于观察数据的变化。
- `watchEffect`：是 Vue 3.x 的 API，用于观察数据的变化。

## 2. 相同点

- 都是用于观察数据的变化。
- 都可以观察数据的变化，但是有一些细微的差别。

## 3. 不同点

- `watch`：只能观察数据的变化，不能获取到变化后的值。
    * 需要明确指定要观察的数据源和回调函数
    * watch `可以监听多个数据源的变化`
    <!-- * 精确控制和多个数据源
    * 当你需要处理响应式数据的变化，并可能需要对数据的变化进行不同的处理逻辑（如前后对比）时，watch 更加灵活。
    * 在数据变化时，进行一些异步操作或执行清理操作 -->

- `watchEffect`：可以观察数据的变化，并且可以获取到变化后的值。
    * 用于自动追踪响应式数据的变化，并在数据变化时`自动重新运行副作用函数`
    * 副作用函数在初始渲染时执行一次，并在其中引用的响应式数据变化时重新执行
    * 自动追踪副作用函数中`所有响应式数据的变化`
    <!-- * 自动依赖追踪
    * 简化代码
    * 副作用不需要精细控制 -->
    缺点：自动依赖追踪可能导致**不必要的副作用函数执行**，尤其在副作用函数**引用多个响应式数据时**。性能影响可能较大。
watchEffect：无需显式指定监听的数据源，自动追踪回调函数里使用的所有响应式数据，但无法直接获取到数据变化前后的值。
## 4. 示例

```javascript
// watch
const count = ref(0)
watch(count, (newVal, oldVal) => {
  console.log(`count is changed from ${oldVal} to ${newVal}`)
})

// watchEffect
const count = ref(0)
watchEffect(() => {
  console.log(`count is ${count.value}`)
})
```
