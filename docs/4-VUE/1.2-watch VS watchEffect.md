# watch VS watchEffect

## 核心区别

| 特性 | watch | watchEffect |
|------|-------|-------------|
| 依赖追踪 | 需要**明确指定**观察的数据源 | **自动追踪**回调函数中所有响应式数据 |
| 新旧值 | 回调函数可获取 `newVal` 和 `oldVal` | 无法直接获取新旧值 |
| 初始执行 | 默认不执行（可配置 `immediate: true`） | 初始渲染时**立即执行一次** |
| 多数据源 | 可以监听多个数据源的变化 | 自动追踪所有引用的响应式数据 |
| 适用场景 | 需要对比新旧值、精确控制、异步操作 | 简化代码、自动依赖追踪、副作用不需精细控制 |
| 版本 | Vue 2.x / 3.x 都支持 | Vue 3.x 新增 |

## 相同点

- 都用于观察响应式数据的变化
- 都可以执行副作用函数
- 都支持清理操作（onCleanup）

## watchEffect 缺点

自动依赖追踪可能导致**不必要的副作用函数执行**，尤其在副作用函数**引用多个响应式数据时**，性能影响可能较大。

## 示例

```javascript
// watch — 明确指定数据源，可获取新旧值
const count = ref(0)
watch(count, (newVal, oldVal) => {
  console.log(`count changed from ${oldVal} to ${newVal}`)
})

// watchEffect — 自动追踪依赖，初始即执行
const count = ref(0)
watchEffect(() => {
  console.log(`count is ${count.value}`)
})
```
