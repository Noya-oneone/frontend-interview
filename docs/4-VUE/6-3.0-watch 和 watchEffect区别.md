# watch 和 watchEffect区别

* watch
watch 和 watchEffect。它们的主要区别在于**如何追踪依赖和触发回调**。

watch：watch 需要明确指定需要观察的数据源，可以是一个响应式引用（如 ref 或 computed 返回的值），也可以是一个返回响应式数据的函数。watch 的回调函数只有在依赖的数据源发生变化时才会被调用，并且在回调函数中可以获取到新旧值。

### watch 和 watchEffect区别

* watch 提供了更精确的控制，可以指定观察的数据源并获取新旧值
* watchEffect 提供了一种更方便的方式，可以自**动追踪依赖**并在数据变化时**重新执行**

<!-- watch(count, (newValue, oldValue) => {
  console.log(`Count changed from ${oldValue} to ${newValue}`);
}); -->

<!-- watchEffect(() => {
  console.log(`Count is now ${count.value}`);
}); -->
