# v-for & v-if

* `v-for 的优先级高于 v-if`，
* 这意味着 v-for 会先于 v-if 执行。
* 这是因为 Vue.js 内部在`处理指令`时会先处理 v-for，然后再处理 v-if

* v-for 先执行：如果一个元素同时使用了 v-for 和 v-if，Vue.js 会先生成 v-for 列表中的所有元素，然后再根据 v-if 的条件决定是否渲染每个元素。

* 性能考虑：因为 v-for 先执行，所以它可能会生成多个不符合 v-if 条件的元素，影响性能。
为了优化性能，应该`尽量将 v-if 放在 v-for 的外部`，减少不必要的 DOM 元素创建。
