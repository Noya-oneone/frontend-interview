
# computed

* computed 属性的值只会在`其依赖的数据发生变化时重新计算`。
* 它`缓存计算结果，避免重复计算，直到依赖数据变化才会重新计算`。
    * 计算属性会缓存其计算结果，只有在相关依赖变化时才会重新计算。
    * 这样可以提高性能，避免每次访问时都重新执行计算函数。
* 计算属性可以有 getter 和 setter。
    * getter 用于返回计算结果，
    * setter 用于更新计算结果（通常用于双向绑定的场景）。

## 1、初始化：

当组件创建时，Vue 会初始化 computed 属性，并为每个计算属性创建一个 Watcher 实例。
## 2、依赖收集：

当计算属性第一次被访问时，Watcher 会收集该计算属性所依赖的响应式数据（即计算属性中使用的 data 或其他 computed 属性）。
Vue 的响应式系统通过 Dep 对象管理依赖，当响应式数据发生变化时，Dep 会通知所有依赖的 Watcher。


```javascript
class ComputedWatcher {
  constructor(getter) {
    this.getter = getter;
    this.value = undefined;
    this.deps = new Set();
    this.dep = new Dep(); // Vue 的 Dep 对象
  }

  evaluate() {
    this.value = this.getter();
    this.deps.forEach(dep => dep.addWatcher(this));
  }

  depend() {
    if (Dep.target) {
      this.deps.add(Dep.target);
      Dep.target.addDep(this.dep);
    }
  }

  get() {
    this.depend();
    if (this.shouldRecompute) {
      this.evaluate();
    }
    return this.value;
  }
}
```
