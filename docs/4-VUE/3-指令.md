# Vue指令

## 内置指令
* **指令** v-if v-for v-show v-text v-html v-on v-bind v-model
  * **v-cloak**：在 Vue.js 应用加载和渲染的过程中，如果网络速度较慢或者设备性能较差，用户可能会短暂地看到未编译的 Mustache 标签，如 {{ message }}。这会给用户带来不好的体验。v-cloak 指令可以解决这个问题，它可以隐藏未编译的 Mustache 标签，直到 Vue 实例准备完毕。
    v-cloak 指令可以帮助你隐藏未编译的插值表达式，直到 Vue 实例完成编译。它会在 Vue 实例挂载到 DOM 之前保持元素的隐藏状态，一旦挂载完成，v-cloak 指令会自动从元素上移除，元素就会正常显示

  * **v-if & v-show**区别：v-if 是“真正”的条件渲染，因为它会确保条件块在切换时进行正确的销毁和重建，也不会在 if 块中做任何的渲染工作，v-show 则只是简单地基于 CSS 的 display 进行切换。
  * v-if 和 v-for 尽量避免一起 使用，统一标签下v-for 优先级更高，建议用一个计算属性先处理
  * v-for与v-if作用在不同标签时候,是先进行判断,再进行列表的渲染

  * **v-text & v-html**区别：v-text 只会渲染纯文本，而 v-html 会渲染出 HTML 片段，会忽略标签，因此 v-html 适用于渲染富文本。

## 自定义指令
* 自定义指令 custom directive:尽管Vue推崇数据驱动视图的理念，但并非所有情况都适合数据驱动，自定义指令就是一种有效的补充和扩展，不仅用于定义任何的DOM节点操作，并且可复用
  * 全局注册主要是通过Vue.directive方法进行注册
  * v-focus：自定义指令，实现元素获取焦点
  * v-lazy：自定义指令，实现图片懒加载
  * v-drag：自定义指令，实现元素拖拽
  * v-copy：自定义指令，实现元素复制
  * v-highlight：自定义指令，实现元素高亮
  * v-permission：自定义指令，实现权限控制
  * v-debounce：自定义指令，实现防抖
  * v-throttle：自定义指令，实现节流
  * v-click-outside：自定义指令，实现点击元素外面隐藏元素
  * v-resize：自定义指令，实现元素大小改变
  * v-scroll: 滚动到指定视图区域
