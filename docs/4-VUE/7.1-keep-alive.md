# keep-alive

* 用于缓存组件状态，避免重复渲染组件 
* keep-alive 组件可以`包裹在需要缓存的组件`上
* 并通过 `include 和 exclude` 属性来指定哪些组件需要缓存，哪些组件不需要缓存。
* 当切换路由时，组件会缓存，下次再切换回来时，`组件会直接从缓存中取出，而不是重新渲染`。
    * 在切换页面或视图时`保持表单数据的状态`，避免重新输入数据。
    * 保持`复杂组件的状态`，避免每次切换都重新加载和初始化。
    * 保持`每个视图的状态`，避免频繁的请求和渲染

```html
<!-- 其中，component 标签中的 `:is` 属性用于指定需要缓存的组件。 -->
<keep-alive>
  <component :is="view"></component>
</keep-alive>

<!-- 1. include：只缓存 home 和 about 组件。
2. exclude：除了 home 和 about 组件之外，其他组件都缓存。 -->
<keep-alive :include="['home', 'about']">
  <router-view></router-view>
</keep-alive>
```

## 内部工作流程

* `创建实例`：当一个组件被渲染到 <keep-alive> 内部时，它的实例被创建并添加到`缓存列表`中。
* `缓存实例`：当组件从视图中移除时，<keep-alive> 将其`保存在缓存列表`中，而不是销毁它。
* `恢复实例`：当组件重新显示时，<keep-alive> 从缓存列表中恢复组件实例，而不是重新创建一个新的实例。
