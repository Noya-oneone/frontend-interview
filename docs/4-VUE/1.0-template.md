# template VS JSX

## template
* template 语法类似于 HTML，具有直观且易于理解的语法
* 内置指令和语法糖
* 模板与逻辑分离
* 在性能方面，template 具有一些独特的优势：
  * `预编译`：模板在编译时进行预处理，可以提高渲染效率
  <!-- Vue Template 在编译优化、静态提升、内置优化、样式处理和渲染性能方面具有一些性能优势 -->
    * Vue 编译器将模板转换成`高效的渲染函数`，优化了模板的执行性能。这种`编译过程可以进行静态标记和优化，从而减少运行时的计算开销`。
    * 编译器在模板中`自动处理静态节点`，使得这些节点只需要在`初始渲染时创建，而不需要在每次更新时重新处理`。
    * Vue 的编译器能够识别和优化静态内容（如静态标签和内容）。这些静态内容在组件的`生命周期内不会改变`，因此 Vue 可以将这些内容提升到渲染函数之外，从而避免重复计算和渲染。
    * Vue 支持作用域样式（Scoped Styles），使得组件内的样式只作用于当前组件，减少了样式冲突和计算开销。样式的处理和作用域在编译阶段就已优化。


  * `缓存`：模板可以被缓存，避免每次渲染都要重新解析和编译
  * `异步`：模板可以异步解析，可以实现按需加载

## JSX
* JSX 转换为 JavaScript 的过程
* javaScript 代码和条件逻辑来实现，没有内置的指令。
* 模板和逻辑结合在一起，这可能使得组件代码更紧凑
* 对于复杂的组件，逻辑和结构混合可能导致可读性下降。
<!-- 复杂的组件和大量动态更新时，可能会面临性能挑战 -->
<!-- 
在 JSX 中，样式通常需要手动处理，如使用 CSS-in-JS 解决方案。这可能涉及更多的运行时计算，尤其是在处理动态样式时。 -->
