* **Vue Resource 库**  
  * Vue Resource 是一个 Vue.js 的插件，提供了对 **XMLHttpRequest 和 JSONP 的封装**，使得在 Vue.js 中进行 HTTP 请求变得更加简单。它提供了一些高级特性，如拦截器和客户端/服务端的数据序列化
  * Vue Resource 不再是 Vue.js 官方推荐的 HTTP 请求库，官方推荐使用 axios。尽管 Vue Resource 仍然可以使用，但它可能不会得到及时的更新和维护
  * Axios 是一个基于 Promise 的 HTTP 库，可以用在浏览器和 Node.js 环境中。它是 Vue.js 官方推荐的 HTTP 请求库。Axios 与 Vue Resource 相比，功能更加强大，配置也更加灵活。
