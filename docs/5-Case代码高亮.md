## 代码高亮

* 词法分析（Lexing）：
    * 定义词法规则：为每种语言定义词法规则，如关键字、标识符、字符串、注释等。
    * 实现词法分析器：将源代码字符串转换为标记（tokens）。
* 语法分析（Parsing）：
    * 构建`抽象语法树（AST）`：将标记组织成树状结构，表示代码的语法结构（对于复杂的高亮支持可选）。
* 样式定义：`定义 CSS 样式`：为不同的代码元素（如关键字、字符串、注释）定义 CSS 样式。
* 高亮渲染：`生成 HTML`：将标记化的代码转换为带有相应 CSS 类的 HTML
* 懒加载：对于大文件或长代码片段，使用懒加载技术
* 缓存：缓存已解析和高亮的代码，避免重复处理
