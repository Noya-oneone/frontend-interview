# 线上监控与排查工具

> Prometheus / Grafana / Jaeger / Kibana — 线上问题排查四件套

## 一句话总结

| 工具 | 一句话定位 |
|------|---------|
| **Prometheus** | 把系统状态变成数字 |
| **Grafana** | 把数字变成图 — 看"系统现在健不健康" |
| **Jaeger** | 把一次请求拆开来看 — 看"一次请求的旅程" |
| **Kibana** | 把发生过的事翻出来查 — 看"系统发生了什么事" |

## 线上问题排查三大支柱

| 支柱 | 工具 | 你能回答的问题 |
|------|------|-------------|
| **Metrics** | Grafana | 系统现在健不健康？有没有异常趋势？ |
| **Logs** | Kibana | 到底发生了什么错误？细节是什么？ |
| **Traces** | Jaeger | 一次请求到底慢在了哪一跳？ |

## 工具详细对比

| 工具 | 核心定位 | 数据类型 | 主要解决的问题 | 是否存储数据 | 是否负责告警 | 典型搭配 |
|------|---------|---------|-------------|-----------|-----------|---------|
| **Prometheus** | 监控 & 指标采集 | Metrics（时间序列数值） | 系统是否健康？有没有异常趋势？ | ✅ | ✅（Alertmanager） | Grafana |
| **Grafana** | 可视化 & 监控大盘 | Metrics / Logs / Traces（不自产） | 数据怎么"看"？状态是否一目了然？ | ❌ | ✅ | Prometheus / Loki / Tempo |
| **Jaeger** | 分布式追踪 | Traces（Trace / Span） | 一次请求慢在了哪一跳？ | ✅ | ❌ | OpenTelemetry |
| **Kibana** | 日志分析与搜索 | Logs（文本） | 到底发生了什么错误？细节是什么？ | ❌（依赖 ES） | ⚠️（有限） | Elasticsearch |

## 问题场景速查

| 问题场景 | 首选工具 |
|---------|---------|
| CPU / 内存 / QPS 异常 | Prometheus |
| 监控大盘 / 统一视图 | Grafana |
| 接口慢，链路定位 | Jaeger |
| 线上报错，查详细日志 | Kibana |
| 全链路问题排查 | Prometheus + Grafana + Jaeger + Kibana |
