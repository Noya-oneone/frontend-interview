
## 数据类型 （基本数据类型 & 引用数据类型） 

| 特性       | `基本数据`类型    | `引用数据`类型    |
|------------|-----------------|-----------------|
| 存储方式   | 直接存储值      | 存储引用        |
| 赋值行为   | 复制值          | 复制引用        |
| 比较方式   | 按值比较        | 按引用比较      |
| 不可变性   | 值不可变        | 值可变          |


```javascript
// 基本数据类型
let a = 10;
let b = a; // 复制值
b = 20; // 不影响 a
console.log(a); // 10
console.log(b); // 20

// 引用数据类型
let obj1 = { key: 'value' };
let obj2 = obj1; // 复制引用
obj2.key = 'new value'; // 改变 obj2 也会改变 obj1
console.log(obj1.key); // 'new value'
console.log(obj2.key); // 'new value'
```


| 数据类型（`基本数据类型`）  | 描述 |
|-----------|------------------------------|
| `Number`  | 表示整数和浮点数               |
| `BigInt`  | 表示任意精度的整数             |
| `String`  | 表示文本或字符序列             |
| `Boolean` | 表示逻辑值 `true` 或 `false`   |
| `Symbol`  | 表示唯一且不可变的值           |
| `undefined` | 表示未定义的值              |
| `null`    | 表示无值或空值                 |


`数值型` Number、BigInt（BigInt 是在 ECMAScript 2020 (ES11) 中引入的新数据类型，用于处理任意精度的整数）
  * **浮点数溢出/精度问题**：64位浮点数来表示所有的数字，而64位浮点数的精度大约只有15到17位有效数字。因此，当我们进行一些涉及小数的复杂运算时，可能会出现精度丢失的情况。 `bigNumber.js\lodash.js\decimal.js`

  * **== 和 === 区别**：==在比较前会进行类型转换， === 全等符号，类型也要一样 ```2 == '2' // true```

| 特性      | Number                   | BigInt                        |
|-----------|--------------------------|-------------------------------|
| 数据范围  | -2^53 ~ 2^53             | 超过 Number 的范围            |
| 精度      | 有限，可能会丢失精度     | 任意精度整数                  |
| 操作符    | 支持所有算术操作符       | 仅支持部分算术操作符          |
| 性能      | 一般较快                 | 可能较慢                      |
| 用途      | 常规数值计算             | 大整数计算，超高精度需求      |
| 创建方式  | 数字字面量或 `Number` 构造 | 数字字面量后加 `n` 或 `BigInt` 构造 |


`symbol`（唯一性、不可变性、隐秘性）

| 特性        | 描述                                                   |
|-------------|--------------------------------------------------------|
| **唯一性**  | 每个 `Symbol` 值都是唯一的，即使具有相同的描述，也不会相等。|
| **不可变性**| `Symbol` 值是不可变的，一旦创建，值不会改变。          |
| **隐秘性**  | 可以用作对象属性键，避免属性名冲突，不会被枚举或遍历。   |


```javascript
// 唯一性
const sym1 = Symbol('description');
const sym2 = Symbol('description');
console.log(sym1 === sym2); //  false，尽管描述相同，但值不同

// 隐秘性
const obj = {
  [sym1]: 'value1'
};
console.log(obj[sym1]); // 'value1'
// Symbol 属性不会被 for...in 或 Object.keys() 遍历到
console.log(Object.keys(obj)); // []
```


| 对象类型（`引用数据类型`）  | 描述                                              |
|------------|---------------------------------------------------|
| `Object`   | 基本对象类型，所有对象的基类                    |
| `Array`    | 数组类型，存储有序的值集合                        |
| `Function` | 函数对象类型                                      |
| `Date`     | 日期和时间类型                                    |
| `RegExp`   | 正则表达式类型                                    |
| `Map`      | 键值对集合类型                                    |
| `Set`      | 唯一值集合类型                                    |
| `WeakMap`  | 弱引用的键值对集合，键是对象类型                   |
| `WeakSet`  | 弱引用的唯一值集合，值是对象类型                   |
| `Proxy`    | 用于创建代理对象的类型                            |
| `Error`    | 错误对象类型，用于处理异常                        |

> `Reflect`、`Intl`、`Math`、`JSON` 是内置的`命名空间对象`（一组静态方法的集合），不是可实例化的类型。



| 特性     | Map | Set |
|----------|-----|----|
| 数据结构 | 键值对集合                            | 唯一值集合 |
| 键       | 可以是任何数据类型（包括对象）        | 不支持键，只有值|
| 迭代顺序 | 保持插入顺序                          | 保持插入顺序 |
| 访问      | 通过键访问值   | 通过值进行操作 |
| 方法      | `set()`, `get()`, `has()`, `delete()`, `clear()`, `size` | `add()`, `has()`, `delete()`, `clear()`, `size` |
| 用途      | 适用于需要映射关系的场景，如`存储和检索配对`数据 | 适用于需要唯一元素的场景，`如去重 ` |

### WeakMap / WeakSet（高频追问）

* `键（值）只能是对象`，且是`弱引用`：对象没有其他引用时可被垃圾回收，WeakMap/WeakSet 不会阻止回收。
* 因为成员随时可能被回收，所以`不可迭代`（无 forEach/keys/values/entries）、`没有 size`。
* 典型用途：给对象挂`元数据/缓存`而不影响其生命周期 —— 深拷贝的循环引用记录（见 [深拷贝](./3.4-深拷贝%20&%20浅拷贝%20-%20循环引用.md)）、DOM 节点关联数据、私有数据存储。


```javascript
// Map 示例
const map = new Map();
map.set('a', 1);
map.set('b', 2);
console.log(map.get('a')); // 输出 1

// 使用 Map 来计算一个数组中每个元素出现的次数
let arr = ['apple', 'orange', 'apple', 'banana', 'orange', 'banana'];
let count = new Map();
for(let fruit of arr) {
  if(count.has(fruit)) {
    count.set(fruit, count.get(fruit) + 1);
  } else {
    count.set(fruit, 1);
  }
} 

// Set 示例 时间复杂度O(1)
const set = new Set();
set.add(1);
set.add(2);
set.add(2); // 不会添加重复值
console.log(set.has(1)); // 输出 true


// 使用 Set 来数组去重
let arr = [1, 2, 2, 3, 4, 4, 5]; 
let uniqueArr = [...new Set(arr)];
```
