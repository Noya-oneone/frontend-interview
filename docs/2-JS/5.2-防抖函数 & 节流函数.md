# 防抖函数 & 节流函数

## 区别（一句话）

* **防抖（debounce）**：事件触发后等 n 秒再执行，期间再触发就`重新计时` —— `多次触发只执行最后一次`。适合：搜索框输入联想、表单校验、按钮防连点、resize 结束后重算布局。
* **节流（throttle）**：无论触发多频繁，`每 n 秒最多执行一次` —— `稀释执行频率`。适合：滚动监听、鼠标移动、拖拽、高频上报。

记忆：防抖是「等你停下来再做」，节流是「定期做一次」。

## 防抖

```javascript
function debounce(func, wait) {
  let timeout;
  return function (...args) {
    clearTimeout(timeout);              // 期间再触发 → 取消上一次计时
    timeout = setTimeout(() => {
      func.apply(this, args);           // 保留 this 与参数
    }, wait);
  };
}

// 带立即执行选项：leading = true 时首次触发立刻执行，停止 wait 毫秒后才允许下一次
function debounceImmediate(func, wait, immediate = false) {
  let timeout;
  return function (...args) {
    const callNow = immediate && !timeout;
    clearTimeout(timeout);
    timeout = setTimeout(() => {
      timeout = null;
      if (!immediate) func.apply(this, args);
    }, wait);
    if (callNow) func.apply(this, args);
  };
}
```

## 节流

```javascript
// 定时器版：停止触发后还会补最后一次执行（trailing）
function throttle(func, wait) {
  let timeout;
  return function (...args) {
    if (!timeout) {
      timeout = setTimeout(() => {
        timeout = null;
        func.apply(this, args);
      }, wait);
    }
  };
}

// 时间戳版：首次触发立即执行（leading），停止后不补
function throttleByTime(func, wait) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= wait) {
      last = now;
      func.apply(this, args);
    }
  };
}
```

```javascript
window.addEventListener('resize', debounce(() => console.log('resized'), 300));
window.addEventListener('scroll', throttleByTime(() => console.log('scrolling'), 200));
```

## 常见考点

* **为什么要 `func.apply(this, args)`？** 返回的包装函数会被当成事件处理器调用，必须把 this（触发事件的元素）和 event 参数透传给原函数。
* **防抖的缺点？** 持续高频触发时`一直不执行`（如无限滚动中用防抖加载会永远不加载）—— 这种场景该用节流。
* **两个节流版本的差异？** 时间戳版首次立即执行、最后一次可能丢；定时器版首次延迟执行、保留最后一次。完整实现（如 lodash.throttle）用 leading/trailing 选项组合两者。
* 生产环境可直接用 `lodash.debounce / lodash.throttle`，支持 cancel、flush。
