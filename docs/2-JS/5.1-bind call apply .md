# bind call apply

## 对比

| 方法 | 语法 | 执行时机 | 参数传递 |
|--|--|--|--|
| `call` | `fn.call(thisArg, arg1, arg2, ...)` | `立即执行` | 逐个传入 |
| `apply` | `fn.apply(thisArg, [arg1, arg2])` | `立即执行` | `数组`形式传入（a → array） |
| `bind` | `fn.bind(thisArg, arg1, ...)` | `不执行，返回新函数` | 可预置部分参数（偏函数） |

```js
function greet(greeting, name) {
  console.log(`${greeting}, ${name}`);
}

greet.call(null, 'Hi', 'Alice');      // "Hi, Alice"
greet.apply(null, ['Hey', 'Bob']);    // "Hey, Bob"

const greetHello = greet.bind(null, 'Hello'); // 预置第一个参数
greetHello('World');                  // "Hello, World"
```

> `thisArg` 传 `null/undefined` 时：非严格模式下指向全局对象，严格模式下就是传入的值。

## 手写实现（高频手写题）

```js
// call：把函数临时挂到 ctx 上调用，用 Symbol 防属性冲突
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx ?? globalThis;
  ctx = Object(ctx);                    // 基本类型装箱
  const key = Symbol('fn');
  ctx[key] = this;                      // this 即被调用的函数
  const result = ctx[key](...args);
  delete ctx[key];
  return result;
};

// apply：只是参数形式不同
Function.prototype.myApply = function (ctx, args = []) {
  return this.myCall(ctx, ...args);
};

// bind：返回新函数，支持预置参数；兼容 new 调用（new 时忽略绑定的 this）
Function.prototype.myBind = function (ctx, ...preset) {
  const self = this;
  function bound(...args) {
    // new bound() 时 this 是新实例，应放弃 ctx
    return self.apply(this instanceof bound ? this : ctx, [...preset, ...args]);
  }
  bound.prototype = Object.create(self.prototype); // 维持原型链
  return bound;
};
```

## 常见考点

* **bind 两次会怎样？** 只有`第一次生效` —— bind 返回的函数内部 this 已被闭包锁死，再 bind 改不了。
* **典型用途**：`apply` 借用方法（`Math.max.apply(null, arr)`，现代用扩展运算符 `Math.max(...arr)`）；`bind` 固定回调的 this（React class 组件的 `this.handleClick = this.handleClick.bind(this)`）。
* **对箭头函数有效吗？** 无法改变其 this，只能起到预置参数的作用。
