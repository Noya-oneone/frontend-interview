# bind call apply

|方法|语法|功能描述|参数传递方式|
|--|-||--|
|`bind`|`func.bind(thisArg,arg1,arg2,...)`|创建一个新函数，固定`this`和部分参数的值|固定`this`和前置参数|
|`call`|`func.call(thisArg,arg1,arg2,...)`|立即调用函数，指定`this`和`传入的参数`|立即执行函数，参数逐个传入|
|`apply`|`func.apply(thisArg,[arg1,arg2,...])`|立即调用函数，指定`this`和传入的`参数数组`|立即执行函数，参数以数组形式传入|

| 方法   | `this` 指向  | 参数传递方式  | 执行时机 |
|------------|-----------------------------------------|---------------------------|------------------|
| `bind` | 创建新函数时固定 `this` 为 `bind` 的第一个参数 | 固定参数和部分参数  | 不立即执行，返回新函数 |
| `call` | 立即调用函数时 `this` 为 `call` 的第一个参数  | 逐个传入参数| 立即执行 |
| `apply`| 立即调用函数时 `this` 为 `apply` 的第一个参数 | 参数以数组形式传入  

### 示例

```js
functiongreet(greeting,name){
console.log(`${greeting},${name}`);
}

//使用bind
constgreetHello=greet.bind(null,'Hello');
greetHello('World');//输出:"Hello,World"

//使用call
greet.call(null,'Hi','Alice');//输出:"Hi,Alice"

//使用apply
greet.apply(null,['Hey','Bob']);//输出:"Hey,Bob"
```
