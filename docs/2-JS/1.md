# 事件循环手写题：async/await + 定时器输出顺序

```javascript
console.log("script start");

async function async1() {
  await async2();
  console.log("async1 end");
}
async function async2() {
  console.log("async2 end");
}
async1();

setTimeout(function () {
  console.log("setTimeout");
}, 0);

const interval = setInterval(function () {
  console.log("setInterval");
  clearInterval(interval);
}, 1);

new Promise((resolve) => {
  console.log("Promise");
  resolve();
})
  .then(function () {
    console.log("promise1");
  })
  .then(function () {
    console.log("promise2");
  });

console.log("script end");

// script start
// async2 end
// Promise
// script end
// async1 end
// promise1
// promise2
// setTimeout
// setInterval
```

## 逐步拆解

1. **同步阶段**：`script start` → 调用 `async1()`，其中 `async2()` 同步执行打印 `async2 end`；`await` 把后续代码（`async1 end`）挂入`微任务队列`。
2. `setTimeout(0)` 与 `setInterval(1)` 注册`宏任务`；Promise 的 executor 是同步的，打印 `Promise`，`resolve()` 后第一个 `.then` 入微任务队列。
3. 同步代码收尾：`script end`。
4. **清空微任务**：`async1 end` → `promise1` →（promise1 执行完，第二个 then 入队）→ `promise2`。
5. **宏任务**：`setTimeout(0)` 先于 `setInterval(1)` 到期，依次打印 `setTimeout`、`setInterval`（随后被 clear，只执行一次）。

## 关键点

* `await xxx` 之后的代码等价于 `Promise.resolve(xxx).then(后续代码)` —— 后续代码是微任务。
* `async2` 函数体本身是`同步执行`的，只有 await 之后的部分才异步。
* 链式 `.then` 不是一次性全部入队：前一个 then 的回调执行完，下一个 then 的回调才入队。
* 定时器按`到期时间`排序进入宏任务队列；每个宏任务之间都会先清空微任务（详见 [事件循环机制](./12.2-事件循环机制.md)）。
