# try-catch

## try catch能捕获到异步中的东西吗？

* try...catch 可以捕获同步代码中的异常，但**无法直接捕获异步代码中的异常**。对于异步代码中的异常（如 setTimeout、Promise 等），应使用以下方法：

```javascript
try {
    setTimeout(() => {
        throw new Error("error");
    }, 1000);
} catch (err) {
    console.error(err);
}

Promise.reject(new Error("error")).catch(err => console.error(err));

async function test() {
    try {
        await someAsyncFunction();
    } catch (err) {
        console.error(err);
    }
}
```
