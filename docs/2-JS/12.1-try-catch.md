# try-catch

## try catch 能捕获异步代码中的异常吗？

`try...catch` 只能捕获`同步执行期间`抛出的异常。异步回调执行时，try 块早已退出调用栈，异常捕获不到：

```javascript
try {
  setTimeout(() => {
    throw new Error("error");   // ❌ 捕获不到，成为未捕获异常
  }, 1000);
} catch (err) {
  console.error(err);           // 不会执行
}
```

## 各类异步错误的正确捕获方式

```javascript
// 1. 回调内部自行 try...catch
setTimeout(() => {
  try { risky(); } catch (err) { console.error(err); }
}, 1000);

// 2. Promise：用 .catch 链式捕获
Promise.reject(new Error("error")).catch(err => console.error(err));

// 3. async/await：await 把 rejection 还原成同步异常，try...catch 可捕获 ✅
async function test() {
  try {
    await someAsyncFunction();
  } catch (err) {
    console.error(err);
  }
}
```

## 兜底：全局错误监听（监控上报的基础）

```javascript
// 同步错误 / 资源加载错误
window.addEventListener('error', (e) => report(e.error ?? e.message));

// 未被 catch 的 Promise rejection
window.addEventListener('unhandledrejection', (e) => report(e.reason));
```

## 常见考点

* **为什么 await 配 try...catch 就能捕获？** await 会暂停函数、等 Promise 结算；rejected 时在`暂停点同步抛出`异常，恰好处于 try 块的执行期内。
* **`try { return x } finally { ... }` 的执行顺序？** finally 一定执行，且在 return 值已确定之后；finally 里再 return 会`覆盖` try 的返回值（反模式，避免）。
* **catch 参数可省略吗？** ES2019 起支持 `try {} catch {}`（Optional Catch Binding）。
