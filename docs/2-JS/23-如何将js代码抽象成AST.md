# 如何将js代码抽象成AST

## 什么是AST
抽象语法树（Abstract Syntax Tree，AST）是一种树状结构，用来表示源代码的语法结构。它是由一系列节点组成，每个节点代表源代码中的一个元素，例如，一个表达式，一个语句，一个函数定义，一个变量声明等。

## 为什么要抽象成AST
抽象成AST有很多好处，比如：

1. 便于代码的分析和转换：AST可以帮助我们分析代码的结构，并根据需要对其进行修改或转换。
2. 便于代码的优化：AST可以帮助我们进行代码优化，比如代码压缩，代码混淆，代码优化等。
3. 便于代码的生成：AST可以帮助我们生成代码，比如将AST转换成目标代码。

## 如何抽象成AST
抽象成AST有两种方式：

1. 手动构建AST：手动构建AST需要我们自己编写代码，遍历源代码，将源代码中的元素逐个转换成AST中的节点。
2. 第三方库：有很多第三方库可以将源代码转换成AST，比如Esprima，Acorn等。
