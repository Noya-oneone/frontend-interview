# 运算符与表达式

## 逻辑运算符与短路求值（高频考点）

* `&&`：左侧为假值即返回左侧，否则返回右侧 —— `返回的是操作数本身，不是布尔值`。
* `||`：左侧为真值即返回左侧，否则返回右侧 —— 常用作默认值，但 `0 / '' / false` 也会被兜底掉。
* `??`（空值合并，ES2020）：只有左侧为 `null / undefined` 才取右侧 —— 默认值场景优先用它。
* `?.`（可选链，ES2020）：访问路径中出现 `null / undefined` 时短路返回 undefined，不再抛错。

```javascript
const count = 0;
count || 10;   // 10  ⚠️ 0 被误判
count ?? 10;   // 0   ✅ 只挡 null/undefined

user?.address?.city;   // 任一环节为空返回 undefined
user?.getName?.();     // 方法可能不存在时的安全调用
```

## 相等比较

* `==` 比较前做`隐式类型转换`（`2 == '2'` 为 true）；`===` 要求类型与值都相同。实践中`一律用 ===`，只保留 `x == null` 这一个惯用法（同时匹配 null 和 undefined）。
* `Object.is(a, b)`：与 === 基本一致，区别是 `Object.is(NaN, NaN) === true`、`Object.is(0, -0) === false`。

## 位运算符

| 运算符 | 含义 | 前端常见用法 |
|--|--|--|
| `&` / `|` / `^` / `~` | 与 / 或 / 异或 / 取反 | 权限位掩码、`a ^= b` 交换 |
| `<<` / `>>` | 左移 / 带符号右移 | `x << 1` 即乘 2 |
| `>>>` | 无符号右移 | 转 32 位无符号整数 |

注意：位运算把操作数转成 `32 位整数`，大数与小数会被截断，`~~x` / `x | 0` 取整只适用于 32 位范围内。

## for...in vs for...of（高频考点）

| | `for...in` | `for...of` |
|--|--|--|
| 遍历什么 | 对象的`可枚举属性键`（字符串），`包括原型链上的` | 可迭代对象的`值` |
| 适用 | 普通对象（配合 `hasOwnProperty` 过滤） | 数组、字符串、Set、Map、arguments、Generator |
| 数组上使用 | ⚠️ 键是字符串索引、顺序不保证、会遍历到附加属性 | ✅ 推荐 |

## 常见考点

* **`a && b || c` 的求值顺序？** `&&` 优先级高于 `||`；复杂表达式加括号明示意图。
* **`??` 和 `||` 混用为什么报错？** 语法规定不能直接混写（`a || b ?? c` 是 SyntaxError），必须加括号。
* **前置 vs 后置自增**：`++i` 返回自增后的值，`i++` 返回自增前的值。
