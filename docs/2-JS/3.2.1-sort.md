# sort() 方法

## 参数：
a：要比较的第一个元素。
b：要比较的第二个元素。
## 返回值：

负值：如果 a 应该排在 b 前面。
零：如果 a 和 b 的顺序不变。
正值：如果 a 应该排在 b 后面。

## sort() sort有什么缺陷？使用需要注意的点？

* Sort的缺陷主要在于它的`默认排序行为`。
* 它默认将数组元素视为`字符串进行排序`，而不是按照`数字或其他类型的大小进行排序`。

* 这可能导致数字排序出现不符合预期的结果，比如"10"会被排在"2"之前，因为字符串"10"在`字典序上`小于"2"。

* 为了解决这个问题，可以提供一个比较函数作为sort方法的参数，以自定义排序逻辑。但即便如此，也需要注意JavaScript中一些特殊值（如undefined和null）的处理，它们可能会在排序过程中引发问题。

* 所以，使用JsSort时要特别注意其默认行为，并根据需要提供合适的比较函数来确保排序的正确性。
