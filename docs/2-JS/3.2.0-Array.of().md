# Array.of()

Array.of() 把`一组参数值`按顺序组装成数组。

```javascript
Array.of(1, 2, 3);                     // [1, 2, 3]
Array.of(undefined, null, true, 'foo'); // [undefined, null, true, 'foo']
```

## 存在的意义：修正 `Array()` 构造函数的怪癖（高频考点）

`Array()` 的行为随参数个数变化，单个数字参数会被当成 length：

```javascript
Array(7);        // [ <7 个空槽> ]  长度 7 的稀疏数组，不是 [7]！
Array(1, 2, 3);  // [1, 2, 3]

Array.of(7);     // [7]            行为始终一致
Array.of(1, 2, 3); // [1, 2, 3]
```

## 常见考点

* **`Array(3)` 产生的空槽（holes）有什么坑？** 稀疏数组的空槽会被 map/forEach `跳过`：`Array(3).map(() => 1)` 仍是三个空槽。要生成可用的定长数组用 `Array.from({ length: 3 })` 或 `Array(3).fill(0)`。
* **Array.of vs Array.from？** of 处理「参数列表 → 数组」；from 处理「类数组/可迭代对象 → 数组」（见 [Array.from](./3.2.0-Array.from().md)）。
