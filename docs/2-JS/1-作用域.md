# 作用域

## 定义

* 作用域指变量、函数以及对象的`可访问范围`，决定了变量的`可访问性和生命周期`。
* JavaScript 是`词法作用域`（静态作用域）：作用域在`代码书写时`就确定了，取决于函数`定义`的位置，而不是调用的位置。

| 类型 | 范围 | 说明 |
|--|--|--|
| **全局作用域** | 整个程序 | 顶层声明；`var` 声明还会挂到 `window` 上 |
| **函数作用域** | 函数体内 | `var` 声明的变量只在函数内可见 |
| **块级作用域**（ES6） | `{}` 内 | `let / const` 声明；离开块后不可访问，避免变量泄漏 |

```ts
function outer() {
  const a = 1;
  if (true) {
    let b = 2;      // 块级作用域
    var c = 3;      // 函数作用域：提升到 outer 顶部
  }
  // b 不可访问；c 可以
}
```

## 作用域链

* 访问变量时，引擎从`当前作用域`开始`逐层向外查找`，直到找到或到达全局作用域（找不到则 ReferenceError）。
* 找到即停，`不会继续向上` —— 内层同名变量会遮蔽（shadow）外层。
* 作用域链在函数`创建时`就确定并保存在函数内部（规范中的 `[[Environment]]`），这正是闭包的基础。

### 与闭包的关系

* 闭包`利用作用域链`访问外部函数的变量：内层函数持有创建时的词法环境引用。
* 闭包还会`延长变量生命周期`：只要闭包还被引用，它捕获的变量就不会被垃圾回收（详见 [闭包](./1.1-闭包.md)）。

## 总结

* **局部变量**：函数执行完即销毁，无法长久保存与共享。
* **全局变量**：可长期保存，但会造成命名污染，程序结束才销毁。
* **闭包**：折中方案 —— 既能长久保存变量又不污染全局；代价是占用内存、需注意引用释放。
