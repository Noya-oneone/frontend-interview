# JS 加载时间线

* 解析 HTML：浏览器从上到下解析 HTML 文件，遇到 <script> 标签时会暂停解析，并开始下载和执行 JavaScript 文件。

* 下载 JavaScript 文件：浏览器根据 <script> 标签的 src 属性下载外部 JavaScript 文件。如果是内联脚本，则直接处理。

* 执行 JavaScript 文件：
    * `同步脚本`：浏览器在下载完毕后立即执行内联或外部 JavaScript 文件，`并阻塞 HTML 解析`，直到脚本执行完成。
    * `异步脚本`：通过 async 或 defer 属性的脚本文件可以并行下载，并在合适的时机执行，`不会阻塞 HTML 解析`。
    * `重新解析和渲染`：脚本执行后，浏览器可能会重新解析和渲染页面，以反映脚本对 DOM 或样式的修改。
