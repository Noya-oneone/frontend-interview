
## 存储机制

* `localStorage 是 同步 的。它的操作是阻塞的`，
* 也就是说，localStorage 的读取和写入操作会`直接在主线程上完成`，并会阻塞其他脚本的执行直到操作完成。

| 特性            | 存储大小            |
|-----------------|----------------------|
| **Cookie**      | 通常限制为 4KB       用户偏好 |
| **LocalStorage**| 约 5-10MB           用户设置 |
| **SessionStorage**| 约 5-10MB          一次性表单数据 |
| **IndexedDB**   | 大量数据（通常几百 MB 或更多）  例如离线应用数据 |

| 特性            | 生命周期            |
|-----------------|----------------------|
| **Cookie**      | 可设置过期时间，可以是长期的 |
| **LocalStorage**| 永久存储，除非主动删除   |
| **SessionStorage**| 当前会话，浏览器关闭后失效 |
| **IndexedDB**   | 永久存储，除非主动删除  |

| 特性            | 安全性                 |
|-----------------|------------------------|
| **Cookie**      | 易受 XSS 攻击，存储在客户端 |
| **LocalStorage**| 易受 XSS 攻击，存储在客户端 |
| **SessionStorage**| 易受 XSS 攻击，存储在客户端 |
| **IndexedDB**   | 相对安全，支持事务和索引  |

| 特性            | 发送方式              |
|-----------------|------------------------|
| **Cookie**      | 每次 HTTP 请求时都会随请求发送 |
| **LocalStorage**| 不随每次请求发送       |
| **SessionStorage**| 不随每次请求发送      |
| **IndexedDB**   | 不随每次请求发送       |

| 特性            | 数据结构                   |
|-----------------|----------------------------|
| **Cookie**      | 只支持字符串               |
| **LocalStorage**| 只支持字符串               |
| **SessionStorage**| 只支持字符串              |
| **IndexedDB**   | 支持复杂的数据结构和索引   |

| 特性            | 跨域问题               |
|-----------------|------------------------|
| **Cookie**      | 可以设置 `SameSite` 和 `Domain` 属性 |
| **LocalStorage**| 不涉及跨域问题，完全在同源域内   |
| **SessionStorage**| 不涉及跨域问题，完全在同源域内  |
| **IndexedDB**   | 不涉及跨域问题，完全在同源域内   |
