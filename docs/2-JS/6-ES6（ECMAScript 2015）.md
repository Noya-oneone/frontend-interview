
## **ES6（ECMAScript 2015）增加的东西：** 

| 新增特性 | 描述 |
|--|-----|
| `let` 和 `const`   | 块级作用域变量和常量声明。|
| 箭头函数 (`=>`)| 简化函数声明，不绑定 `this`。 |
| 模板字符串 (`${}`) | 支持多行字符串和插值。   |
| 解构赋值 (`{a, b}` 和 `[c, d]`) | 从数组或对象中提取值并赋值。  |
| 扩展运算符 (`...`) | 展开数组或对象。|
| 默认参数   | 为函数参数提供默认值。  |
| 类 (`class`)   | 提供类的定义和继承。|
| 模块化 (`import` 和 `export`)   | 使用 `import` 和 `export` 实现模块化。   |
| Promises   | 处理异步操作的机制。|
| 生成器函数 (`function*` 和 `yield`) | 使用生成器定义和生成迭代器。  |
| Symbol | 创建唯一的标识符。  |
| Set 和 Map | 新增集合和映射数据结构。|
| `Array.prototype.includes`  | 检查数组是否包含某个值。|
| 指数运算符 (`**`)   | 进行幂运算。 |
| `Async/Await`   | 简化异步操作的编写。|
| `Object.entries` 和 `Object.values`  | 获取对象的键值对和所有值。  |
| 字符串填充方法 (`padStart`, `padEnd`) | 填充字符串以满足指定长度。  |
| 共享内存和原子操作 (`Shared Memory` 和 `Atomics`)| 支持并发编程的共享内存和原子操作。  |
| 异步迭代 (`for-await-of`)  | 处理异步迭代器。|
| Rest/Spread 属性   | 对象字面量中的扩展运算符。  |
| `Promise.finally`   | 无论 `Promise` 成功还是失败都执行的代码。   |
| 正则表达式的向后匹配断言 (`Lookbehind`)   | 支持向后匹配的正则表达式断言。  |
| `Array.prototype.flat` 和 `Array.prototype.flatMap`  | 扁平化数组和映射数组。  |
| `Object.fromEntries`| 将键值对数组转换为对象。|
| 字符串填充方法 (`trimStart`, `trimEnd`)   | 去除字符串开头和结尾的空白字符。|
| 可选捕获绑定 (`Optional Catch Binding`)  | 省略 `try...catch` 中的捕获变量。|
| `Symbol.prototype.description`   | 获取 `Symbol` 的描述信息。 |
| 空值合并运算符 (`??`)   | 处理 `null` 和 `undefined` 的默认值。   |
| 可选链操作符 (`?.`)| 安全地访问嵌套对象的属性。 |
| BigInt  | 支持任意精度的整数。   |
| `Promise.allSettled`   | 处理所有 `Promise` 的结果（无论成功还是失败）。|
| `String.prototype.matchAll`  | 返回所有匹配的结果的迭代器。|
| 逻辑赋值运算符 (`&&=`, `||=`, `??=`)  | 简化逻辑运算和赋值操作。   |
| 数字分隔符 (`Numeric Separators`)| 在数字字面量中使用下划线作为分隔符。   |
| `String.prototype.replaceAll`| 替换字符串中的所有匹配项。  |
| `WeakRefs`  | 创建弱引用以防止内存泄漏。 |
| `FinalizationRegistry` | 管理对象生命周期，帮助垃圾回收。   |
| 顶层 `await`   | 在模块顶层直接使用 `await`。   |
| 类字段 (`Class Fields`)| 直接定义类的实例字段和静态字段。   |
| 私有方法和字段 (`Private Methods and Fields`)| 增强类的封装性。  |
| 错误原因 (`Error Cause`)| 在 `Error` 对象中添加 `cause` 属性。   |
| Hashbang 语法 (`#!`)   | 支持可执行文件中的 `#!` 语法。  |
| 导入断言 (`Import Assertions`)  | 确保加载的模块符合预期。  |
