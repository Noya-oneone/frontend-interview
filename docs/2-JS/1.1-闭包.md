# 闭包

## 定义
* 闭包产生的本质当前环境中存在指向父级作用域的引用.
* 闭包是由`函数和函数创建时`的`词法环境`组成的，
  * 闭包是`一个可以访问另一个函数里面变量的函数`，
  * 一般定义为`外层函数中的内层函数`
  * 闭包`允许函数访问其外部函数的作用域`

* 词法环境：闭包包含了创建时的词法环境。`它记住了它的外部函数的作用域`，从而允许在内部函数中访问外部函数的变量。
* 私有变量：闭包可以用来`创建私有变量`，因为外部作用域中的变量`在外部无法直接访问`，`但可以通过闭包函数访问`。
* 函数工厂：闭包可以用于创建函数工厂，生成具有`不同初始状态的函数`。


## 闭包的缺点
* `内存占用`：闭包会`保留其创建时的作用域链，这可能导致内存占用增加`，特别是当闭包对象被长时间持有时。
* `性能考虑`：闭包允许灵活的函数设计，但过度使用可能导致性能问题。合理使用闭包，避免不必要的内存持有

全局对象（GO）：在全局执行上下文中，变量对象就是全局对象（GO），它包含了全局范围内的所有变量和函数声明。
激活对象（AO）：在函数执行上下文中，变量对象被称为激活对象（AO）。它包含了函数内声明的所有变量、参数和内部函数。
当函数被调用时，会创建一个新的执行上下文，并将其压入执行上下文栈中。这个执行上下文会包含一个激活对象（AO），其中存储了函数内部的变量和参数。


## 闭包如何影响垃圾回收

### 延长变量的生命周期：

* 当一个函数创建了一个闭包，且闭包中的函数被`外部引用`时，闭包内的变量不会被立即回收，即使它们在原本的作用域中已经`超出了生命周期`。这是因为闭包保留了对这些变量的引用。

* 垃圾回收机制：垃圾回收器会`跟踪对象的引用情况`。如果闭包中的变量仍然被引用（例如，闭包中的函数被外部持有引用），这些变量及其环境将不会被回收。

一旦闭包中的`函数不再被引用`，闭包环境内的变量`才会被标记为可回收对象`，然后在下一次垃圾回收时被清除。

* 闭包本身并不会直接导致内存泄漏，但不当使用闭包可能间接导致内存泄漏
* 闭包会将其创建时的作用域链保存下来，包括所有在这个作用域链上可访问的变量。这意味着只要闭包存在，这些变量的引用就不会被垃圾回收器回收，即使它们的作用域已经超出了预期的生命周期。
* 如果闭包持有对不再需要的变量或对象的引用，并且这些引用不会被解除，那么这些变量或对象的内存就无法被释放，导致内存泄漏


```javascript
// 如果这个按钮被从 DOM 中移除，但事件监听器没有被手动解除（removeEventListener），这个闭包会一直保留，导致内存泄漏
function attachHandler() {
  let element = document.getElementById('button');
  element.addEventListener('click', function() {
    console.log('Button clicked');
  });
}
// 如果一个闭包被长生命周期的对象（如全局对象）持有，它将一直存在，这会阻止闭包引用的所有变量和对象被垃圾回收。
let cachedFunction;
function createFunction() {
  let largeData = new Array(1000).fill('Some large data');
  cachedFunction = function() {
    console.log(largeData.length);
  };
}
createFunction();
// cachedFunction 依然保持着对 largeData 的引用

// 闭包可能会意外地引用一个全局变量或者因未正确声明变量而导致变量成为全局变量，这样会让变量无法被垃圾回收，导致内存泄漏。
function leakyFunction() {
  leak = 'I am global'; // 未使用 var/let/const 声明
  return function() {
    console.log(leak);
  };
}

```
## 闭包的注意事项
* 及时解除不再需要的引用：在使用事件监听器、定时器或其他异步操作时，确保在适当的时候移除这些引用。
* 谨慎使用全局变量：避免使用全局变量或确保在不再需要时显式地将它们设为 null。
* 合理管理闭包的生命周期：尽量避免让闭包长时间持有大量数据，特别是在数据不再需要时。

```javascript
  function outerFunction() {
    let outerVar = 'I am outer';
    
    function innerFunction() {
      console.log(outerVar); // 访问外部函数的变量
    }
    
    return innerFunction;
  }

const myClosure = outerFunction();
myClosure(); // 输出: I am outer
```


## 闭包应用场景！

### 1、return回一个函数
```javascript
function createCounter() {
  let count = 0;
  return function() {
    return ++count;
  };
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

### 2、函数作为参数
```javascript
function process(array, callback) {
  const result = [];
  for (let i = 0; i < array.length; i++) {
    result.push(callback(array[i]));
  }
  return result;
}
const squared = process([1, 2, 3], function(num) {
  return num * num;
});
console.log(squared); // [1, 4, 9]
```
### 3、IIFE（自执行函数）： 使得 IIFE 能够在其内部“记住”变量，且不会泄漏到外部作用
```javascript
(function() {
  let x = 1;
  console.log(x); // 1
})();
```
### 4、循环赋值： 闭包常用于解决循环变量在异步操作中的问题。

```javascript
for (var i = 0; i < 3; i++) {
  (function(i) {
    setTimeout(function() {
      console.log(i); // 0, 1, 2
    }, 100);
  })(i);
}
```


### 5、使用回调函数就是在使用闭包
```javascript
function getData(url, callback) {
  fetch(url).then(function(response) {
    return response.json();
  }).then(function(data) {
    callback(data);
  });
}
getData('https://api.example.com/data', function(data) {
  console.log(data);
});
```


### 6、节流防抖
```javascript
function debounce(func, delay) {
  let timeout;
  return function() {
    clearTimeout(timeout);
    timeout = setTimeout(func, delay);
  };
}
window.addEventListener('resize', debounce(function() {
  console.log('Window resized');
}, 300));
```


### 7、函数柯里化： 即将一个多参数函数转换为一系列单参数函数的过程。每个函数都“记住”之前的参数并返回一个新函数来接收下一个参数。
```javascript
function add(a) {
  return function(b) {
    return function(c) {
      return a + b + c;
    };
  };
}
console.log(add(1)(2)(3)); // 6
```
