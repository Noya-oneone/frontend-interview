# 闭包

## 定义

* 闭包 = `函数` + `函数创建时的词法环境`。本质是当前环境中存在`指向外层作用域的引用`。
* 通俗说法：`定义在外层函数中的内层函数`，它能访问（并记住）外层函数的变量，即使外层函数已经执行完毕。

```js
function outerFunction() {
  let outerVar = 'I am outer';
  function innerFunction() {
    console.log(outerVar);   // 访问外部函数的变量
  }
  return innerFunction;
}
const myClosure = outerFunction();
myClosure(); // 'I am outer' —— outerFunction 已返回，变量仍可访问
```

* 核心能力：
  * `私有变量`：外部无法直接访问，只能通过闭包暴露的接口读写。
  * `函数工厂`：生成携带不同初始状态的函数。
  * `状态保持`：变量生命周期被延长，跨多次调用共享。

## 闭包与垃圾回收

* 闭包会保留其创建时的作用域引用 —— 只要闭包函数还被外部引用，被捕获的变量就`不会被回收`（生命周期被延长）。
* 闭包本身不是内存泄漏，但`不当使用会间接泄漏`：

```js
// 1. 事件监听器未解绑：元素移除后监听器闭包仍被持有
function attachHandler() {
  const element = document.getElementById('button');
  element.addEventListener('click', () => console.log('clicked'));
  // 元素从 DOM 移除前应 removeEventListener
}

// 2. 长生命周期变量持有闭包 → 闭包捕获的大数据无法释放
let cachedFunction;
function createFunction() {
  const largeData = new Array(100000).fill('data');
  cachedFunction = () => console.log(largeData.length);
}
createFunction(); // largeData 随 cachedFunction 常驻内存

// 3. 漏写声明关键字 → 变量变成全局，永不回收
function leakyFunction() {
  leak = 'I am global'; // 缺 let/const
}
```

注意事项：及时解除不再需要的引用（监听器、定时器）；避免闭包长期持有大对象，不需要时置 `null`。

## 应用场景

### 1. 返回函数（计数器 / 私有状态）

```js
function createCounter() {
  let count = 0;
  return () => ++count;
}
const counter = createCounter();
counter(); // 1
counter(); // 2  count 对外不可见
```

### 2. 回调函数天然是闭包

```js
function getData(url, callback) {
  fetch(url).then(r => r.json()).then(data => callback(data));
  // 回调记住了定义处的变量
}
```

### 3. IIFE（立即执行函数）隔离作用域

```js
(function () {
  let x = 1;      // 不泄漏到外部
  console.log(x);
})();
```

### 4. 循环 + 异步的经典题

```js
// var 无块级作用域，闭包捕获同一个 i → 全打印 3
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 3, 3, 3
}
// 解法一：IIFE 为每次迭代创建独立作用域
for (var i = 0; i < 3; i++) {
  (function (i) {
    setTimeout(() => console.log(i), 100); // 0, 1, 2
  })(i);
}
// 解法二（现代）：let 每次迭代生成新绑定
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 0, 1, 2
}
```

### 5. 防抖 / 节流（timer 保存在闭包里）

```js
function debounce(func, delay) {
  let timeout;                 // 闭包持有的私有状态
  return function (...args) {
    clearTimeout(timeout);
    timeout = setTimeout(() => func.apply(this, args), delay);
  };
}
```

详见 [防抖函数 & 节流函数](./5.2-防抖函数%20&%20节流函数.md)。

### 6. 柯里化：每层函数记住之前的参数

```js
const add = (a) => (b) => (c) => a + b + c;
add(1)(2)(3); // 6
```

## 常见考点

* **闭包的优缺点？** 优点：私有化变量、状态保持、模块化基础。缺点：被捕获变量常驻内存，滥用增加内存压力、引用不清导致泄漏。
* **执行上下文角度解释**：函数调用时创建执行上下文与变量环境；内层函数的 `[[Environment]]` 引用外层的变量环境，外层执行完后该环境因仍被引用而不销毁 —— 这就是闭包。
* **闭包捕获的是变量还是值？** `变量本身（引用）`，不是快照 —— 循环题打印 3,3,3 正是因为三个回调共享同一个 `i`。
