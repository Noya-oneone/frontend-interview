
# Array.from()
* Array.from() 方法用于将类似数组的对象（array-like object）或可迭代对象（iterable object）转换为数组。
* Array.from() 方法还可以接受`第二个参数，作用类似于 map 方法`，用来对每个元素进行处理，将处理后的值放入返回的数组。
* Array.from 的第`三个参数是 thisArg，用于指定映射函数执行时的 this 绑定`。

## 第一个参数

* 第一个参数可以是类似数组的对象（array-like object）或可迭代对象（iterable object），如：Array, Map, Set, String, TypedArray, arguments 对象等。
* 如果参数是一个数组，则返回一个一摸一样的数组。

```javascript
const arrayLike = {
  0: 'a',
  1: 'b',
  2: 'c',
  length: 3
};

const arr = Array.from(arrayLike);
console.log(arr); // ['a', 'b', 'c']
```

## 第二个参数
* 第二个参数（可选）是一个函数，用来对每个元素进行处理，将处理后的值放入返回的数组。
* 该函数调用次数与数组长度相同。
* 第二个参数指定的函数只接受一个参数，即数组中每个元素的值。
```javascript
const arrayLike = {
  0: 1,
  1: 2,
  2: 3,
  length: 3
};

const arr = Array.from(arrayLike, x => x + 1);
console.log(arr); // [2, 3, 4]
```

## 第三个参数
* 第三个参数（可选）是一个对象，用于绑定 `this` 关键字。
* 如果该参数为空，则 `this` 指向全局对象。
* 如果该参数是一个对象，则 `this` 指向该对象。
* 该参数指定的函数的 `this` 绑定，与第三个参数的对象相同。


```javascript
const arrayLike = {
  0: 1,
  1: 2,
  2: 3,
  length: 3
};

const arr = Array.from(arrayLike, function(x) {
  return this.prefix + x;
}, {prefix: 'foo'});
console.log(arr); // ['foo1', 'foo2', 'foo3']
```
