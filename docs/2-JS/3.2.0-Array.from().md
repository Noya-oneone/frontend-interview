
# Array.from()
* Array.from() 方法用于将类似数组的对象（array-like object）或可迭代对象（iterable object）转换为数组。
* Array.from() 方法还可以接受`第二个参数，作用类似于 map 方法`，用来对每个元素进行处理，将处理后的值放入返回的数组。
* Array.from 的第`三个参数是 thisArg，用于指定映射函数执行时的 this 绑定`。

## 第一个参数

* 第一个参数可以是类似数组的对象（array-like object，有 length 和索引即可）或可迭代对象（iterable object），如：Array, Map, Set, String, TypedArray, arguments, NodeList 等。
* 如果参数是一个数组，则返回它的`浅拷贝`（内容相同的新数组）。

```javascript
const arrayLike = {
  0: 'a',
  1: 'b',
  2: 'c',
  length: 3
};

const arr = Array.from(arrayLike);
console.log(arr); // ['a', 'b', 'c']
```

## 第二个参数
* 第二个参数（可选）是一个映射函数，对每个元素处理后放入返回的数组，等价于 `Array.from(x).map(fn)` 但不产生中间数组。
* 该函数接收`两个参数 (element, index)`（与 map 不同，没有第三个「原数组」参数）。
* 经典用法 —— 生成序列：

```javascript
Array.from({ length: 5 }, (_, i) => i * 2); // [0, 2, 4, 6, 8]
```
```javascript
const arrayLike = {
  0: 1,
  1: 2,
  2: 3,
  length: 3
};

const arr = Array.from(arrayLike, x => x + 1);
console.log(arr); // [2, 3, 4]
```

## 第三个参数
* 第三个参数（可选）是一个对象，用于绑定 `this` 关键字。
* 如果该参数为空，则 `this` 指向全局对象。
* 如果该参数是一个对象，则 `this` 指向该对象。
* 该参数指定的函数的 `this` 绑定，与第三个参数的对象相同。


```javascript
const arrayLike = {
  0: 1,
  1: 2,
  2: 3,
  length: 3
};

const arr = Array.from(arrayLike, function(x) {
  return this.prefix + x;
}, {prefix: 'foo'});
console.log(arr); // ['foo1', 'foo2', 'foo3']
```
