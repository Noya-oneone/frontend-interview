# String 常用方法

| 方法| 描述 |
|----------------|--------------|
| `charAt(index)` | 返回指定位置的字符  |
| `charCodeAt(index)`| 返回指定位置字符的 Unicode 编码值 |
| `concat(...strings)`  | 连接一个或多个字符串并返回新字符串  |
| `includes(search, start)`| 判断是否包含指定子字符串 |
| `indexOf(search, start)` | 返回第一次出现指定子字符串的索引 |
| `lastIndexOf(search, start)`| 返回最后一次出现指定子字符串的索引  |
| `localeCompare(other)`| 比较两个字符串，考虑语言环境  |
| `repeat(count)` | 返回一个新字符串，重复指定次数|
| `slice(start, end)`| 提取字符串的一部分并返回新字符串 |
| `split(separator, limit)`| 将字符串分割成数组  |
| `substr(start, length)`  | 提取从指定位置开始的子字符串 |
| `substring(start, end)`  | 提取两个索引之间的子字符串 |
| `toLowerCase()` | 转换字符串中的所有字符为小写  |
| `toUpperCase()` | 转换字符串中的所有字符为大写  |
| `toLocaleLowerCase()`  | 根据本地语言环境转换为小写  |
| `toLocaleUpperCase()`  | 根据本地语言环境转换为大写  |
| `trim()`  | 去除字符串两端的空白字符 |
| `trimStart()`| 去除字符串开头的空白字符 |
| `trimEnd()`  | 去除字符串结尾的空白字符 |
| `padStart(targetLength, padString)` | 将字符串填充到指定长度（前端填充） |
| `padEnd(targetLength, padString)`| 将字符串填充到指定长度（后端填充） |
| `fromCharCode(...codes)` | 从 Unicode 编码值创建字符串  |
| `search(regex)` | 搜索正则表达式并返回匹配项的索引 |
| `replace(search, replace)`  | 替换第一个匹配的子字符串 |
| `replaceAll(search, replacement)` | 返回一个新字符串，其中所有匹配 `search` 的子字符串都被替换为 `replacement`。 |
| `match(regex)`  | 匹配正则表达式并返回结果数组  |
| `matchAll(regexp)`  | 返回一个包含所有匹配 `regexp` 的结果的迭代器。每个匹配结果是一个数组，包含完整的匹配及捕获的组。 |
| `at(index)`| 返回字符串中指定位置的字符。支持负索引，负索引从字符串末尾开始计数。 |
| `codePointAt(index)`| 返回字符串中指定位置字符的 Unicode 编码值。支持负索引，负索引从字符串末尾开始计数。 |
