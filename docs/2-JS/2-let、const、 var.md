* **let、const、 var 区别**：
| 关键字 | 作用域| 可变性 | 声明提升 | 特点 |
|--------|---------------|------------|----------|--------------------------|
| `var`  | 函数作用域| 可变   | 有   | 允许重复声明 |
| `let`  | 块级作用域| 可变   | 无   | 不允许重复声明   |
| `const`| 块级作用域| 不可变 | 无   | 必须初始化，不允许重复声明 |

* `const`： 声明常量、可改变对象，不能改变基本数据类型、const保存的是内存地址
* 要保证 const 声明的对象内属性不可变，可以使用 `Object.freeze()` 方法，使对象变为不可修改的（`深层次的嵌套对象属性`仍需进一步冻结）。-- `递归`
* 暂时性死区：即没有到其赋值前，之前就不能用
