# 深拷贝

* **深拷贝浅拷贝**
  * 当引用类型进行赋值的时候，JavaScript**不允许直接访问内存中的位置**，也**不能直接操作对象中的内存空间**。
  * 操作对象是直接操作对象的引用，而不是整个对象，所以就会出现深拷贝、浅拷贝的问题
  * **浅拷贝**：只复制指向某个对象的指针，而不复制对象本身，相当于是新建了一个对象，该对象`复制了原对象的指针`，
        * 新旧对象还是共用一个内存块
        * 修改其中一个对象，另一个对象也会受影响
  * **深拷贝** ： 是新建一个一模一样的对象，该对象与原对象不共享内存，修改新对象也不会影响原对象
    * `slice、concat、扩展运算符 {...obj}、Object.assign`：都是`浅拷贝` —— 只复制第一层，嵌套对象仍共享引用（一维纯值数组用它们「等效深拷贝」只是因为没有第二层）
    * `JSON.parse(JSON.stringify(obj))`：简易深拷贝，但限制很多（见下）
    * `structuredClone(obj)`：`现代标准答案`，浏览器/Node 17+ 原生深拷贝，支持循环引用、Date、Map、Set、RegExp 等（不支持函数、DOM 节点、原型链）
    * lodash 的 `cloneDeep`：兼容性最好、类型覆盖全，工程兜底选择
    
## 什么是深拷贝？ 

* 深拷贝（Deep Copy）是指创建一个新的对象，其内容与原对象完全相同，包括其所有属性值，但不共享原对象的内存空间。
* 深拷贝的主要用途是为了解决对象共享的问题。当我们修改一个对象时，如果不进行深拷贝，那么其他引用该对象的变量也会受到影响，导致数据不一致。



## 深拷贝实现方法

### 1. JSON.parse(JSON.stringify(obj))

局限（面试必答）：

* `循环引用直接抛 TypeError`。
* `函数、undefined、Symbol` 作为属性值会被`丢弃`（数组中变 null）。
* 类型信息丢失：`Date 变成 ISO 字符串`、`RegExp / Map / Set 变成空对象 {}`、`NaN / Infinity 变成 null`。
* 丢失原型链，全部变回普通对象；序列化 + 反序列化两趟遍历，性能一般。


```javascript
let obj = {a: 1, b: {c: 2}};
let copyObj = JSON.parse(JSON.stringify(obj));

console.log(copyObj); // {a: 1, b: {c: 2}}
console.log(copyObj === obj); // false
console.log(copyObj.b === obj.b); // false
```

JSON.parse() 方法将一个 JSON 字符串转换为一个 JavaScript 对象，JSON.stringify() 方法将一个 JavaScript 对象转换为一个 JSON 字符串。通过这两个方法，我们可以实现深拷贝。

### 2. 递归拷贝 （lodash）

递归拷贝的思路是，
* 如果当前对象是`基本类型`（如字符串、数字、布尔值），则直接返回该对象；
* 如果当前对象是`数组`，则创建一个新的空数组，将数组中的`每个元素递归拷贝到新数组中`；
* 如果当前对象是`对象`，则创建一个新的空对象，将对象中的每`个属性值递归拷贝到新对象中`。

#### weakMap

* `WeakMap 的键只能是对象，不能是原始值（如字符串、数字、布尔值等）`。这与普通的 Map 不同，后者可以使用任何类型的值作为键。
* WeakMap 的`键是弱引用，当没有其他引用指向该键时，会被自动删除`。这与普通的 Map 不同，后者的键是强引用，不会自动删除。
* WeakMap 不能被枚举或迭代 : 也就是说，WeakMap 不提供 forEach、keys、values 或 entries 方法来遍历其内容。
* WeakMap 的键值对`对于外部代码是不可见的`，这使得它在存储私有数据时非常有用。


* 循环引用问题： `new WeakMap()` 可以跟踪已经拷贝过的对象，避免重复拷贝和无限循环。
* 特殊对象拷贝：
    * `Date`：通过创建新实例并使用原时间值。
    * `RegExp`：通过创建新实例并使用原正则表达式的模式和标志。
    * `其他特殊对象（如 Map、Set、WeakMap、WeakSet）`：使用相应的构造函数进行拷贝。
    * `混合数据结构`：编写通用的深拷贝函数，处理各种特殊对象和数据结构。
    * WeakMap 和 WeakSet 不能直接克隆，因为它们的键和值是弱引用，无法直接复制。通常需要重新创建这些对象，并将其使用的对象重新绑定。

### 怎么处理循环引用？

* 循环引用（Circular Reference）指的是在数据结构中，`某个对象直接或间接地引用了它自身`。这种情况在树状结构或图状结构中可能会出现。循环引用常见于复杂的数据结构，如图、树或链表
* `处理循环引用` 是深拷贝（Deep Copy）中的一个挑战，因为简单的递归拷贝可能会导致`无限循环`。
* 要正确处理循环引用，你需要在拷贝过程中`跟踪已经拷贝过的对象`，以避免重复拷贝
* `hash`: 使用 WeakMap 跟踪已经拷贝的对象。WeakMap 的键是对象，值是拷贝的结果。这样可以处理循环引用问题。

* `基本类型和 null`: 基本数据类型（如字符串、数字）和 null 直接返回，因为它们不需要深拷贝。
* `循环引用`: 在开始拷贝之前，`检查 hash 中是否已存在该对象。如果存在，直接返回已拷贝的对象`，避免重复拷贝和无限循环。
* `数组和对象`: 根据对象类型（数组或对象）创建新的实例，然后递归拷贝其属性。
* `属性拷贝`: 递归调用 deepClone 函数拷贝每个属性。

```javascript
function deepClone(obj, hash = new WeakMap()) {
  // 基本类型和 null 直接返回
  if (obj === null || typeof obj !== 'object') return obj;

  // 处理循环引用
  if (hash.has(obj)) return hash.get(obj);

  // 处理数组和对象
  const result = Array.isArray(obj) ? [] : {};

  // 记录已拷贝的对象
  hash.set(obj, result);

  // 递归拷贝属性
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      result[key] = deepClone(obj[key], hash);
    }
  }

  return result;
}
```
