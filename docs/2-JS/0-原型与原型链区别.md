
# 原型与原型链

## 原型
* 每个对象都有一个`内部链`接到另一个对象的引用，这个引用称为原型。
  * `原型`：想象每个 JavaScript 对象都是一个学生。如果一个学生不知道答案，他会问他的导师。导师就是这个学生的原型。
  * 原型对象可以包含该对象可共享的属性和方法
  * 当一个对象试图访问一个属性或方法时，JavaScript 引擎首先会检查该对象本身是否具有这个属性或方法。如果没有，它会继续查找该对象的原型，以此类推，直到找到`属性或方法或者到达原型链的末端`。
  * 可以通过 `constructor.prototype` 或 `Object.getPrototypeOf()` 访问`对象的原型`
    * 属性和方法查找的过程就是沿着原型链进行的。
    * 原型链是由多个对象通过其原型属性相互连接形成的`链式结构`。
  
## 原型链
* 一个对象可以从其原型继承属性和方法。这个链接形成了一个链条，称为原型链。
  * `原型链`：如果导师也不知道答案，导师会问他的导师，这个过程会一直进行下去，直到找到答案或者没有更多的导师可问。这一串导师就形成了一个链条，这就是原型链。
  * `原型链的终点`：原型链最终会指向 null，即 Object.prototype.__proto__ 为 null，表示原型链的结束。在 JavaScript 中，所有对象最终都继承自 `Object 对象`，而 Object.prototype 是原型链的顶端，它的原型是 `null`。当沿着原型链查找属性或方法时，如果到达 Object.prototype 并且还未找到，则返回 undefined，并且不会再继续查找，因为 null 表示没有更高层次的原型。
  * `对象的 __proto__ 属性`：每个JavaScript对象都有一个`__proto__`属性，当JavaScript代码试图`访问一个对象的属性`时，如果该对象自身不包含这个属性，那么它会沿着__proto__链向上查找，直至找到定义该属性的地方，或者到达原型链的尽头
  * `构造函数的 prototype 属性`：指向该构造函数的实例共享的原型对象: `每个函数（构造函数）`都有一个 `prototype` 属性，该属性指向一个对象，这个对象就是`原型`。

## 示例

```javascript
// 通过原型链实现继承，`子类对象可以继承父类对象的属性和方法`。
const animal = {
  eat: function() {
    console.log('Eating...');
  }
};

const dog = Object.create(animal);
dog.bark = function() {
  console.log('Barking...');
};

const myDog = Object.create(dog);
myDog.name = 'Rex';

console.log(myDog.name); // 输出: Rex (从 myDog 对象中找到)
myDog.bark(); // 输出: Barking... (从 dog 对象中找到方法并执行)
myDog.eat();  // 输出: Eating... (从 animal 对象中找到方法并执行)
```
