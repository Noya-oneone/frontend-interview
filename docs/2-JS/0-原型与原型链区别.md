# 原型与原型链

## 原型

* 每个对象都有一个`内部链接`指向另一个对象，这个被指向的对象称为原型（prototype）。
  * 类比：每个对象是一个学生，学生不知道答案时会问导师 —— 导师就是这个学生的原型。
  * 原型对象上的属性和方法可被所有以它为原型的对象`共享`。
* 访问对象属性时，引擎先查对象自身，`没有就沿原型链向上查`，直到找到或到达链的末端（返回 undefined）。

### 三个关键角色（高频考点）

| 角色 | 挂在谁身上 | 指向什么 |
|--|--|--|
| `prototype` | `函数`独有的属性 | 该构造函数创建的实例所共享的原型对象 |
| `__proto__`（标准写法 `Object.getPrototypeOf(obj)`） | 每个对象 | 该对象的原型 |
| `constructor` | 原型对象 | 指回构造函数 |

三者关系：`实例.__proto__ === 构造函数.prototype`，`构造函数.prototype.constructor === 构造函数`。

> `__proto__` 是历史遗留的非标准访问器（已入规范附录），读写原型的标准方法是 `Object.getPrototypeOf / Object.setPrototypeOf`，创建时指定用 `Object.create(proto)`。

## 原型链

* 对象沿原型逐级继承属性和方法，这条链就是原型链。导师问导师的导师，一直问到没有导师可问。
* `终点`：`Object.prototype` 的原型是 `null` —— 查到这里还没找到就返回 `undefined`，不再继续。

```js
// 通过 Object.create 手动搭一条原型链
const animal = { eat() { console.log('Eating...'); } };

const dog = Object.create(animal);
dog.bark = function () { console.log('Barking...'); };

const myDog = Object.create(dog);
myDog.name = 'Rex';

console.log(myDog.name); // 'Rex'      自身属性
myDog.bark();            // 'Barking' 来自 dog
myDog.eat();             // 'Eating'  来自 animal

// 原型链：myDog → dog → animal → Object.prototype → null
```

## 常见考点

* **`instanceof` 的原理？** 沿左操作数的原型链逐级查找，看是否出现右操作数的 `prototype`：

```js
function myInstanceof(obj, Ctor) {
  let proto = Object.getPrototypeOf(obj);
  while (proto) {
    if (proto === Ctor.prototype) return true;
    proto = Object.getPrototypeOf(proto);
  }
  return false;
}
```

* **函数的原型链**：函数也是对象，`fn.__proto__ === Function.prototype`，而 `Function.prototype.__proto__ === Object.prototype` —— 所以「函数最终也继承自 Object」。
* **`Object.__proto__ === Function.prototype`？** 是的，`Object` 本身是构造函数；而 `Function.__proto__ === Function.prototype`（函数由 Function 创造，包括它自己）。
* **`hasOwnProperty` 的作用？** 区分`自身属性`与`原型链继承属性`；`for...in` 会遍历原型链上的可枚举属性，需配合它过滤（或改用 `Object.keys`）。
* **class 和原型什么关系？** `class` 是原型继承的语法糖：方法定义在 `prototype` 上，`extends` 同时接通实例原型链与静态属性链。
