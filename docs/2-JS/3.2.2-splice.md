# splice() 方法

## splice 

splice() 方法通过删除、替换或添加元素来`修改原数组`，返回值是`被删除元素组成的数组`。

1. `start`：起始位置，负数表示从末尾倒数。
2. `deleteCount`（可选）：要删除的数量；省略则`删到末尾`；设为 0 则只插入不删除。
3. `item1, item2, ...`（可选）：要插入的元素，逐个传入（传数组会把整个数组作为一个元素插进去）。

## splice vs slice（易混淆）

| | `splice` | `slice` |
|--|--|--|
| 是否修改原数组 | ✅ 修改 | ❌ 返回新数组 |
| 返回值 | 被删除的元素 | 截取出的片段 |
| 记忆 | splice 有 p —— 破坏性（原地拼接） | slice 切片，只读 |

```javascript
// 删除元素
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 2); // 从索引 2 开始删除 2 个元素
console.log(arr); // 输出: [1, 2, 5]
// 添加元素
const arr = [1, 2, 3, 4];
arr.splice(2, 0, 'a', 'b'); // 从索引 2 开始，删除 0 个元素，添加 'a' 和 'b'
console.log(arr); // 输出: [1, 2, 'a', 'b', 3, 4]
// 替换元素
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 2, 'x', 'y'); // 从索引 2 开始，删除 2 个元素，添加 'x' 和 'y'
console.log(arr); // 输出: [1, 2, 'x', 'y', 5]
// 替换和添加
const arr = [1, 2, 3, 4, 5];
arr.splice(1, 3, 'a', 'b'); // 从索引 1 开始，删除 3 个元素，添加 'a' 和 'b'
console.log(arr); // 输出: [1, 'a', 'b', 5]
```
