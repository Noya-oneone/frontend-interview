# splice() 方法

## splice 

splice() 方法通过删除或替换现有元素或者添加新的元素来修改数组，并以数组形式返回被修改的内容。
1. `第一个参数`：必选，整数，规定添加/删除项目的`位置`，使用负数可从数组末尾开始计数。
2. `第二个参数`：必选，整数，表示要删除的`项目数量`。如果设置为 0，则不删除项目。
3. `第三个参数`：可选，要添加到数组中的元素。如果该参数是一个数组，则该参数的元素将被添加到数组中。

```javascript
// 删除元素
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 2); // 从索引 2 开始删除 2 个元素
console.log(arr); // 输出: [1, 2, 5]
// 添加元素
const arr = [1, 2, 3, 4];
arr.splice(2, 0, 'a', 'b'); // 从索引 2 开始，删除 0 个元素，添加 'a' 和 'b'
console.log(arr); // 输出: [1, 2, 'a', 'b', 3, 4]
// 替换元素
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 2, 'x', 'y'); // 从索引 2 开始，删除 2 个元素，添加 'x' 和 'y'
console.log(arr); // 输出: [1, 2, 'x', 'y', 5]
// 替换和添加
const arr = [1, 2, 3, 4, 5];
arr.splice(1, 3, 'a', 'b'); // 从索引 1 开始，删除 3 个元素，添加 'a' 和 'b'
console.log(arr); // 输出: [1, 'a', 'b', 5]
```
