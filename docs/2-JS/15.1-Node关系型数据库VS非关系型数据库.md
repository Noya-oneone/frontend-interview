# 关系型数据库VS非关系型数据库


* **关系型数据库 RDBMS**  `MySQL, PostgreSQL, Oracle`
    * 关系型数据库以`表格的形式存储数据`，每一行代表一个记录，每一列代表一个字段，每个字段都有唯一的标识符，关系型数据库可以保证`数据的一致性`
    * SQL语言
    * 关系型数据库支持事务，可以确保数据的完整性
    * 可以`水平扩展`，通过增加服务器来提升性能
    * 成本较高，需要购买专业的数据库服务器

* **非关系型数据库 NoSQL** `MongoDB, Redis`
    * 可以存储各种类型的数据，比如`JSON、XML、图形数据`等。
    * 通过`键值查找`的方式查询数据
    * 不支持事务
    * 不支持水平扩展，只能通过垂直扩展来提升性能
    * 成本较低，可以选择云服务
    * Redis 适合存储数据场景
        * `缓存`：快速读取和写入数据，减少数据库负载。
        * `会话管理`：存储用户会话数据，支持高并发访问。 
        * `实时分析`：处理和分析实时数据，如排行榜和推荐系统。
        * `消息队列`：管理任务队列和异步任务处理。
        * `状态跟踪`：监控用户活动、状态变化。
