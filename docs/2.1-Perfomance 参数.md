# 性能优化参数以及工具

### performance
***`FP（FirstPaint）1-2秒`**：从开始加载到浏览器首次绘制像素到屏幕上的时间，也就是页面在屏幕上首次发生视觉变化的时间。
***`FCP（FirstContentfulPaint）1-2.5秒`**：浏览器首次绘制来自DOM的内容的时间。
***`DCL（DOMContentLoaded）1-2秒`**：DOM内容加载完成，即DOM树构建完成，但图片、样式表可能还未加载完成。
***`LCP（LargestContentfulPaint）2.5秒以内`**：页面中最大的图像或文本元素的渲染时间。
***`L(OnloadEvent)5秒以内`**:页面的onload事件触发，页面的所有资源（图片、样式表、脚本等）都已经加载完成。

时间点	参数	描述
0秒	-	开始加载页面
1-2秒	FP (First Paint)	浏览器首次绘制像素到屏幕上的时间
1-2秒	DCL (DOMContentLoaded)	DOM内容加载完成，DOM树构建完成
1-2.5秒	FCP (First Contentful Paint)	首次绘制来自DOM的内容的时间
2.5秒以内	LCP (Largest Contentful Paint)	页面中最大的图像或文本元素的渲染时间
5秒以内	L (Onload Event)	页面onload事件触发，所有资源加载完成

时间轴总结
FP 和 DCL 是在加载的初期阶段。
FCP 通常在 FP 和 DCL 之后，标志着内容的首次呈现。
LCP 是页面内容加载的关键指标，表明用户看到的主要内容。
L (Onload Event) 是整个页面及其资源完全加载的最后标志。

|事件类型|描述|建议时间范围|
|--|--|----|
|黄色(**Scripting**)|JS脚本的执行|<`200ms`|
|紫色(**Rendering**)|样式计算和布局，页面重排|<`100ms`|
|绿色(**Painting**)|页面内容的重绘时间|<`50ms`|
|灰色(**Other**)|其它事件花费的时间|`尽量减少`| 
|白色(**Idle**)|空闲时间|`尽量增加(保持空闲时间)`|

### Lighthouse工具
|指标|描述|建议区间|特点|
|----|---|-|---|
|`FP(FirstPaint)`|浏览器首次绘制**像素**到屏幕上的时间|<`1-2秒`|测量页面视觉反馈的速度|
|`FCP(FirstContentfulPaint)`|浏览器**首次绘制**来自DOM的内容的时间|<`1-2.5秒`|反映页面内容的可见性|
|`DCL(DOMContentLoaded)`|DOM内容加载完成的时间，即**DOM树构建完成**|<`1-2秒`|页面主要内容构建的完成时间|
|`LCP(LargestContentfulPaint)`|页面中`最大的图像`或文本元素的渲染时间|<`2.5秒`|影响用户感知的主要内容加载时间|
|`TTI(TimetoInteractive)`|页面完全互动的时间，即页面**可以响应用户输入的时间**|`<5秒`|评估页面的交互性|
|`TBT(TotalBlockingTime)`|页面加载期间**阻塞用户输入的总时间**|<`300ms`|衡量页面响应能力|
|`CLS(CumulativeLayoutShift)`|页面**布局偏移**的累积值|<`0.1`|反映视觉稳定性|
|`FID(FirstInputDelay)`|用户**首次交互的延迟时间**|<`100ms`|测量页面响应用户输入的速度|

### RAIL模型(NextWork) - 以用户为核心的性能模型
* chorme团队于2015年提出的性能模型，理念是以用户为中心，让用户满意，而不是局限于在任何设备上你的网站的运行速度 
*`response响应`：快速响应用户，应该在**100ms以内**响应用户输入
*`animation动画FPS`：
    * 在响应动画的时候，每一帧应该以`16ms`进行渲染，这样保持动画效果的一致性，避免卡顿（FPS）(**10ms/帧)**
    *`requestAnimationFrame`
        * 请求动画帧是`HTML5新增的API`，
        * 主要用于在浏览器的`下一次重绘之前调用指定的回调函数`。
        * 该方法可以自动根据浏览器的性能情况`控制动画的刷新频率，从而达到60FPS的渲染速度`
        * 如果系统绘制率是60Hz，那么回调函数就会`16.7ms`再被执行一次。
*`idle空闲`：当使用javascript主线程时，应该把任务分到执行**时间小于50ms**的片段中去，这样可以释放线程以进行用户交互
*`load加载`：首次加载在5s以内完成加载，并可以进行用户交互，对于后续加载，建议在**2s以内**完成交互
