## 1. 事件循环

一个事件循环从执行一个宏任务开始，到所有微任务执行完毕、并且页面渲染（如果有的话）完成为止，这个过程即为一个完整的事件循环。

- `同步任务`：在主线程上`按顺序执行`
- `微任务（Microtasks）`：包括 `Promise 的回调`和 `async/await` 中 await 之后的代码，它们会在`当前事件循环`的结束前执行
- `宏任务（Tasks）`：包括 setTimeout 的回调，它们会在`微任务执行完毕后执行`

经典输出顺序题答案：

```
script start、async2 end、Promise、script end
async1 end、promise1、promise2、setTimeout、setInterval
```

完整详解见 [2-JS/12.2-事件循环机制.md](./2-JS/12.2-事件循环机制.md)。

## 2. 手写并发任务调度器（schedule）

限制同时运行的任务数，队列按添加顺序消费：

```js
runTasks() {
  while (this.taskQueue.length > 0 && this.runningTasks < this.maxTasks) {
    // shift() 从队列头取出任务，确保按添加顺序执行
    const taskToRun = this.taskQueue.shift();
    this.runningTasks++;
    // taskToRun 是一个返回 Promise 的函数，完成后递归调度下一个
    taskToRun().finally(() => {
      this.runningTasks--;
      this.runTasks();
    });
  }
}
```

## 3. 青蛙跳台阶（动态规划）

```js
// 每次跳 1 或 2 级：斐波那契
function frogJump(n) {
  if (n === 0) return 1;
  if (n === 1) return 1;

  const dp = new Array(n + 1);
  dp[0] = 1;
  dp[1] = 1;

  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2]; // 动态规划状态转移
  }

  return dp[n];
}

// 变体：每次可跳 1、2、3 级
function jumpFloor(number) {
  let dp = [1, 1, 2];
  for (let i = 3; i <= number; i++) {
    dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3];
  }
  return dp[number];
}
```

## 4. 手写 EventEmitter

```js
class MyEvent {
  constructor() {
    // events 存储所有事件名 → 回调列表的映射
    this.events = {};
  }
  // 绑定事件
  on(eventName, cb, ...args) {
    if (!this.events[eventName]) {
      this.events[eventName] = [];
    }
    this.events[eventName].push({ cb, args });
  }

  // 解绑事件
  off(eventName, cb) {
    if (this.events[eventName]) {
      this.events[eventName] = this.events[eventName].filter(
        (event) => event.cb !== cb
      );
    }
  }

  // 绑定一次性事件
  once(eventName, cb, ...args) {
    const onceWrapper = (...onceArgs) => {
      cb(...onceArgs, ...args);
      this.off(eventName, onceWrapper);
    };
    this.on(eventName, onceWrapper, ...args);
  }

  // 触发事件
  trigger(eventName, ...args) {
    if (this.events[eventName]) {
      this.events[eventName].forEach((event) => {
        event.cb(...args, ...event.args);
      });
    }
  }
}

const eventBus = new MyEvent();

eventBus.on("click", (x, y) => {
  console.log(`clicked at ${x}, ${y}`);
});

eventBus.trigger("click", 10, 20); // output: clicked at 10, 20
```

注意：`off` 传入的必须是 `on` 时的同一个函数引用，传新的匿名函数解绑不掉。

## 5. 事件流

- `event.preventDefault()`：取消事件对象的默认动作（如表单提交），不阻止传播
- `event.stopPropagation()` / `event.cancelBubble = true`：阻止事件冒泡（IE9 以下不支持 stopPropagation）
- `stopImmediatePropagation`：阻止冒泡之外，还阻止该事件目标上其他已注册的监听器执行

三个阶段：

- `事件捕获阶段`：从 document 对象开始，沿 DOM 树向下传递直到目标元素。若父元素以捕获方式注册了事件，点击子元素时会先触发父元素的回调
- `处于目标阶段`：到达触发事件的元素
- `事件冒泡阶段`：从目标元素沿 DOM 树向上传递回 document

`addEventListener` 第三个参数指定注册在捕获（`true`）还是冒泡（`false`，默认）阶段：

```js
// 直接绑定：默认在冒泡阶段触发
document.getElementById("div1").onclick = function () {
  console.log("div1被点击了1");
};
// 事件监听器（冒泡）
document.getElementById("div1").addEventListener("click", function () {
  console.log("div1被点击了2");
}, false);
// 事件捕获
document.getElementById("div1").addEventListener("click", function () {
  console.log("div1被点击了3");
}, true);
```

## 6. defer & async

- `defer`：脚本异步加载，等文档解析完成后再按顺序执行
- `async`：脚本下载完立即执行，执行顺序不确定（适合 Google Analytics、Facebook SDK 这类独立脚本）

## 7. 排序算法复杂度

| 算法 | 最坏时间 | 平均时间 | 最好时间 | 空间 |
|------|----------|----------|----------|------|
| **冒泡排序** | O(n^2) | O(n^2) | O(n) | O(1) |
| **快速排序** | O(n^2) | O(n log n) | O(n log n) | O(log n) |
| **选择排序** | O(n^2) | O(n^2) | O(n^2) | O(1) |
| **插入排序** | O(n^2) | O(n^2) | O(n) | O(1) |
| **归并排序** | O(n log n) | O(n log n) | O(n log n) | O(n) |

## 8. 数据结构速览

- **栈**：后进先出 `LIFO`，仅在栈顶操作 O(1) —— **递归、表达式求值、函数调用管理**（`push`、`pop`、`peek`）
- **队列**：先进先出 `FIFO`，队头删除、队尾插入 O(1) —— **任务调度、消息队列、广度优先搜索**（`enqueue`、`dequeue`、`front`）
- **链表**：线性结构，节点含数据和指针；插入删除 O(1)，搜索 O(n) —— **文件系统、数据库索引、图数据结构**
