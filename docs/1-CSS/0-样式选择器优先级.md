##  样式选择器的优先级

* 内联样式（Inline Styles）：直接在HTML元素上通过style属性设置的样式。
* ID选择器（#id）：通过元素的ID属性来选择的样式。
* 类选择器（.class）、属性选择器（[attribute=value]）和伪类选择器（:hover, :active等）：这些选择器通过元素的类名、属性或伪类状态来选择的样式。
* 元素选择器（如div, p等）和伪元素选择器（::before, ::after等）：通过HTML元素类型或伪元素来选择的样式。
* 如果两个或多个选择器的优先级相同，则`后声明的规则会覆盖先声明的规则`。
* 另外，使用`!important`声明的样式会覆盖没有使用!important的相同或更低优先级的样式，但应谨慎使用以避免样式表难以维护。

div>a // 后代选择器
div+a // 相邻兄弟选择器
div~a // 后续兄弟选择器


减少直接暴露后端服务：前端不直接访问后端API，而是通过BFF作为中间层，这样可以避免后端服务直接暴露在外部，降低攻击面。

API 权限控制：BFF可以根据不同客户端（如Web、移动端）进行定制，实施更精细的权限控制，避免客户端越权访问数据。

身份验证和授权：BFF可以统一管理 OAuth、JWT 等认证流程，确保只有经过认证的请求能够访问后端服务。

敏感数据处理：BFF可以处理敏感数据，在传递给前端之前进行脱敏或加密处理，避免直接暴露用户隐私信息。
