# 样式选择器优先级

## 优先级顺序（从高到低）

1. `!important` 声明（慎用，破坏级联可维护性）
2. 内联样式（`style` 属性）
3. ID 选择器（`#id`）
4. 类选择器（`.class`）、属性选择器（`[type="text"]`）、伪类（`:hover`、`:nth-child`）
5. 元素选择器（`div`、`p`）、伪元素（`::before`、`::after`）
6. 通配符 `*`、组合符（`>`、`+`、`~`、空格）与 `:where()` —— 不贡献优先级

优先级相同时，`后声明的规则覆盖先声明的`；继承来的样式没有优先级，任何直接命中的规则都能覆盖它。

## specificity 计算：(a, b, c) 三元组

| 位 | 统计什么 | 例子 |
|--|--|--|
| a | ID 选择器个数 | `#nav` → (1,0,0) |
| b | 类 / 属性 / 伪类个数 | `.item:hover` → (0,2,0) |
| c | 元素 / 伪元素个数 | `ul li::before` → (0,0,3) |

逐位比较，高位胜出，**不进位**：`(0,11,0)` 依然小于 `(1,0,0)` —— 11 个类打不过 1 个 ID。

```css
#nav .item a        /* (1,1,1) */
.nav .list .item a  /* (0,3,1) —— 输给上面 */
```

### 特殊函数

* `:is(...)` / `:has(...)`：取`参数中优先级最高者`计入。
* `:where(...)`：优先级恒为 0，写基础样式库时便于被业务覆盖。
* `:not(...)` 自身不计，参数照常计。

## 常用组合选择器（易混淆）

```css
div a    /* 后代选择器：div 内所有层级的 a */
div > a  /* 子选择器：仅 div 的直接子级 a */
div + a  /* 相邻兄弟：紧跟在 div 后的第一个 a */
div ~ a  /* 后续兄弟：div 之后的所有同级 a */
```

## 常见考点

* **`a:hover` 为什么要写在 `a:visited` 之后？** LVHA 顺序（link→visited→hover→active），优先级相同靠书写顺序决定生效。
* **如何覆盖 `!important`？** 只能用更高优先级的 `!important`（或提高选择器权重 + important）；根治办法是重构，用级联层 `@layer` 管理优先级。
* **内联样式能被外部样式覆盖吗？** 常规声明不能，`!important` 可以。
* **`@layer`（级联层）**：层的优先级由声明顺序决定且`先于 specificity 比较`，后声明的层胜出，未分层样式最强 —— 现代解法，替代权重竞赛。
