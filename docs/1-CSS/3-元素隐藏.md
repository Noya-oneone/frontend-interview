# 元素隐藏

### 元素隐藏方案

<!-- 不可交互。用户无法点击、选择或与该元素进行任何交互。 -->

- **`display: none`**: 隐藏元素且完全移除其在文档流中的位置，`不占用空间`。
- **`visibility: hidden`**: 隐藏元素但保持其`占用的空间`，位置保持不变。
- **`opacity: 0`**: 将元素设置为完全透明，但`仍然占用空间`，位置保持不变，透明度设置为0。
- **`position: absolute; left: -9999px`**: 将元素移动到视口之外，隐藏而不影响布局。
- **`clip-path: inset(100%)`**: 使用剪裁路径将元素剪裁到不可见区域，用于特殊效果或动画。
- **`transform: scale(0)`**: 使用缩放变换将元素缩小到不可见，但仍占用空间，适合动画效果。
- **`hidden` 属性**: HTML5 属性，用于简单地隐藏元素，具有语义化优点。
