
## 边距重叠（Margin Collapse）是 CSS 中的一种行为，

`当两个或多个相邻的块级元素垂直方向上有相同的边距时`，`它们的边距会自动合并，形成一个单一的边距`。

涉及到`相邻块级元素的垂直边距如何合并`。理解和解决边距重叠问题有助于更精确地控制布局。

| 解决方案   | 描述   | 影响|
|----|----|---|
| **添加内边距（Padding）** | 在相邻元素之间添加内边距，避免边距折叠。| 内边距会增加元素的实际空间，不会触发边距折叠。|
| **添加边框（Border）** | 为元素添加边框，防止边距折叠。  | 边框的存在会阻止相邻元素边距的合并。   |
| **添加空元素**| 在需要的地方插入空的块级元素，创建新的上下文，避免边距折叠。| 空元素不会影响布局，但可以解决边距重叠问题。 |
| **使用 `overflow` 属性** | 为父容器设置 `overflow: hidden/auto/scroll`，阻止边距折叠。| 触发 BFC，避免子元素的边距折叠。 |
| **使用 `display: flow-root`** | 设置元素 `display` 属性为 `flow-root`，创建新的 BFC。 | 防止子元素边距折叠，确保布局稳定。|
| **使用 flexbox 或 grid 布局** | 使用 `display: flex` 或 `display: grid` 避免边距折叠。  | 现代布局模型内，元素间边距不会折叠。  |
