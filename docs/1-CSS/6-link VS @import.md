| 特性 | `link` 方式  | `@import` 方式 |
|---------------|-------------|---------------|
| **位置** | 在 `<head>` 标签内使用。   | 在 CSS 文件内使用。  |
| **加载顺序**  | 提前加载，CSS 文件在页面渲染前加载。 | 延迟加载，`@import` 的 CSS 在主 CSS 加载后加载。|
| **性能** | 加载更快，因为浏览器可以并行加载多个 `link`。 | 加载较慢，`@import` 会阻塞其他 CSS 文件的加载。|
| **支持情况** | 兼容所有现代浏览器和旧版浏览器。| 兼容性较差，较新的浏览器有较好支持。|
| **CSS 文件** | 可以同时引入多个 CSS 文件。| 可以引入多个 CSS 文件，但需要在每个 CSS 文件中使用 `@import`。|
| **书写方式**| `<link rel="stylesheet" href="style.css">` | `@import url("style.css");` |
| **优先级**| `<link>` 标签中的样式优先级由加载顺序决定。 | `@import` 规则中的样式优先级由 CSS 规则决定。|
| **用途**| 推荐用于项目中引入外部 CSS 文件。| 适用于组织和管理复杂的 CSS 文件，但不推荐用于性能关键的情况。|
