# 文本溢出

CSS中的`text-overflow`属性用来设置当文本内容超过容器时，如何处理溢出的文本。

## 语法

```
text-overflow: clip|ellipsis|string;
```

1. `clip`：默认值，表示将文本内容裁剪掉，并显示省略号。
2. `ellipsis`：表示用省略号表示文本内容的溢出。
3. `string`：表示用指定的字符串表示文本内容的溢出。

## 示例

```html
<div class="container">
  <p class="text">Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed non risus. Suspendisse lectus tortor, dignissim sit amet, adipiscing nec, ultricies sed, dolor. </p>
</div>
```


```css
.container {
  width: 200px;
  height: 100px;
  border: 1px solid black;
  overflow: hidden;
}

.text {
  width: 100%;
  height: 100%;
  text-align: center;
  line-height: 100px;
  font-size: 20px;
  color: white;
  text-overflow: ellipsis;
}
```
