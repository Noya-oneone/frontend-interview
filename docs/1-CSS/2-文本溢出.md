# 文本溢出（单行 / 多行省略）

## 单行省略（三件套缺一不可）

`text-overflow` 单独写不生效，必须同时满足：容器`溢出被裁剪` + 文本`不换行`。

```css
.ellipsis {
  overflow: hidden;        /* 1. 裁剪溢出 */
  white-space: nowrap;     /* 2. 禁止换行 */
  text-overflow: ellipsis; /* 3. 溢出显示省略号 */
}
```

`text-overflow` 取值：

| 值 | 效果 |
|--|--|
| `clip`（默认） | 直接在容器边缘裁断，**不显示省略号** |
| `ellipsis` | 用 `…` 表示被裁剪的文本 |

> 前提是元素有确定的宽度约束；在 flex 项目里常见坑：需要给该项目加 `min-width: 0`，否则 flex 项目默认 `min-width: auto` 不允许收缩，省略号出不来。

## 多行省略

```css
.ellipsis-3 {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;   /* 保留 3 行 */
  overflow: hidden;
}
```

* `-webkit-line-clamp` 虽带前缀，但`所有现代浏览器都支持`，是事实标准（标准化名称 `line-clamp` 正在铺开）。
* 老项目兜底方案：定高 + `overflow: hidden`（无省略号），或 JS 截断字符串。

## 常见考点

* **`text-overflow: ellipsis` 为什么不生效？** 排查三件套：没有 `overflow: hidden`？没有 `white-space: nowrap`？容器没有宽度约束（或是被 flex `min-width: auto` 撑开）？
* **省略号能换成别的字符吗？** 规范里有 `text-overflow: "…自定义"` 双值语法，但仅 Firefox 支持，生产别用。
* **如何判断文本真的被截断了（以便只在截断时挂 tooltip）？** 比较 `el.scrollWidth > el.clientWidth`（多行用 scrollHeight/clientHeight）。

```ts
function isTruncated(el: HTMLElement): boolean {
  return el.scrollWidth > el.clientWidth || el.scrollHeight > el.clientHeight;
}
```
