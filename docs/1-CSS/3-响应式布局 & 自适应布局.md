
## 响应式布局 & 自适应布局

* `响应式设计`：使用 rem 和媒体查询 (@media) 来调整根元素的字体大小，从而实现响应式布局，使得页面在不同设备和屏幕尺寸下都能保持良好的可读性和布局。
    * 不需要为每种设备设计单独的布局
    * 一致性：**不同设备上体验一致**
    * 流畅性：**布局流动，自动调整** 

* `自适应布局`：相对于根元素的字体大小。通过调整根元素的字体大小，能够实现页面的自适应布局。
    * 需要设计和**维护多个布局模板**，适应不同设备和屏幕尺寸。
    * 可维护多套样式 （手机端样式 & PC 端样式）、为每种设备设计精确的布局
    * 每种设备有专门设计的布局，适应不同屏幕尺寸
    * **设备检测，条件加载不同的 CSS 样式表，JavaScript 检测设备特性**

* `相对单位`：与 em 单位不同，
    * **rem** 总是相对于`根元素`的字体大小： 在 HTML 中，rem 单位相对于根元素 <html> 的字体大小。例如，如果 <html> 的字体大小是 16px，则 1rem 等于 16px
    * 而 **em** 是相对于`当前元素-父元素`的字体大小。

    PC 端应用：在桌面应用中，设计师和开发者习惯于使用固定的 px 单位来设计详细的 UI 组件，以确保设计的精确度和一致性。
    手机端应用：由于设备的多样性和响应式设计的需求，px 转换为 rem 工具更常被使用，以确保跨设备的一致性和适应性。


```css
html {
  font-size: 16px; /* 默认字体大小 */
}

@media (max-width: 600px) {
  html {
    font-size: 14px; /* 小屏幕上调整字体大小 */
  }
}

@media (min-width: 1200px) {
  html {
    font-size: 18px; /* 大屏幕上调整字体大小 */
  }
}

body {
  font-size: 1rem; /* 根字体大小为 16px */
}

h1 {
  font-size: 2rem; /* 32px */
}

p {
  font-size: 1rem; /* 16px */
}

.container {
  padding: 1.5rem; /* 24px */
}

.button {
  width: 10rem; /* 160px */
  height: 3rem; /* 48px */
}
```
