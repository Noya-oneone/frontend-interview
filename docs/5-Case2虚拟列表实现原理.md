## 虚拟列表实现原理

react-window：高效的虚拟列表和窗口滚动库。
react-virtualized：为大数据集提供虚拟滚动和虚拟化列表。
vue-virtual-scroll-list：用于 Vue 的虚拟滚动列表。
vue-virtual-scroller：高效的虚拟滚动组件，支持多种列表视图。

`transform:translateY()`

* `可见区域渲染`：只渲染当前可见区域的列表项，减少 DOM 节点的数量。
* `动态计算高度`：根据列表的滚动位置和每项的高度，动态计算需要渲染的列表项范围。
* `预加载和复用`：当用户滚动时，预加载即将进入视口的列表项，并回收不再可见的列表项的 DOM 节点。
* `虚拟滚动`：通过改变列表容器的滚动位置来创建滚动效果，实际 DOM 只包含可视区域的内容。

* 对于不定高（动态高度）虚拟列表，即每个列表项的高度不同，虚拟列表的实现更加复杂，因为需要处理每个项的实际高度。
`getBoundingClientRect() 或 offsetHeight` 获取高度。
* 累计高度：计算所有项的总高度以确定列表的总高度，并用于计算滚动位置。
* 窗口滚动：监听窗口滚动事件，并计算当前滚动位置。
* 预加载：使用占位元素来保持未渲染项的空间，以避免布局跳动
