# UseMemo

* Used Memory，实际使用的内存量，是计算机系统报告的某一进程、应用程序或系统组件所实际占用的物理内存。
* 其原理可以从操作系统的**内存管理机制**中理解
* `Used Memory` 是通过操作系统的内存管理机制，实时监控并报告某个进程或系统组件`实际占用的物理内存量`

| Hook| 使用场景| 特点|
|-------------|------------------------------|----------------------------|
| `useState`| 需要在函数组件中使用状态时| 简单的状态管理，返回状态值和更新函数 |
| `useEffect` | 需要在组件渲染后执行副作用操作（如数据获取）| 类似于生命周期方法（componentDidMount、componentDidUpdate、componentWillUnmount），可以返回清理函数 |
| `useContext`| 需要在组件中使用上下文时| 简化了在组件树中传递数据，不需要手动传递 props|
| `useReducer`| 需要复杂状态逻辑或多个子状态相互关联时| 类似于 Redux 的 reducer，适用于复杂状态管理|
| `useMemo` | 需要性能优化，避免不必要的计算或渲染时| **缓存计算结果，只有依赖项改变时才重新计算**|
| `useCallback`| 需要性能优化，避免不必要的回调函数重新创建时| 缓存函数实例，只有依赖项改变时才重新创建|
| `useRef`| 需要访问 DOM 元素或保持变量在重新渲染间的持久性时 | 提供对 DOM 元素的直接访问，不会引发重新渲染|
| `useImperativeHandle` | 需要自定义暴露给父组件的实例值时 | 自定义引用值，结合 `forwardRef` 使用 |
| `useLayoutEffect`| 需要在所有 DOM 变更后同步执行操作时 | 类似于 `useEffect`，但会在浏览器绘制之前执行|
| `useDebugValue`| 需要为自定义 Hook 添加调试标签时| 提供自定义 Hook 的调试信息，在 React 开发者工具中显示 |
