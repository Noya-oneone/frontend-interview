## Fiber React 16

Fiber 是 **React 16** 引入的一种新的调度机制，它的主要目标是使 React **可以在渲染过程中被打断**，从而提高应用的响应速度。Fiber 本质上是一个虚**拟堆栈帧**，每个 Fiber 对象对应一个 React 组件的实例，并保存了该组件的类型、状态、属性等信息。

Fiber 的工作流程主要分为两个阶段：**Reconciliation（协调）阶段和 Commit（提交）**阶段。

**Reconciliation 阶段**：在这个阶段，React 会通过 diff 算法比较新旧两棵 Fiber 树，找出需要更新的节点。这个阶段可以被打断，如果有更高优先级的任务（如用户交互）发生，React 可以暂停当前的渲染任务，**先去执行更高优先级的任务**。

`Commit 阶段`：在这个阶段，React 会将 Reconciliation 阶段找出的需要更新的节点应用到 DOM 上。**这个阶段不能被打断**，一旦开始就必须执行到完。
