# GZIP （减少传输数据量：压缩后的数据体积更小，减少了带宽占用。）

## 什么是GZIP

* GZIP是一种数据压缩技术，它利用`Lempel-Ziv-Welch算法`对数据进行压缩。
* GZIP 是一种用于`文件压缩和解压缩的算法`，它是一种开放标准，由IETF（Internet Engineering Task Force，因特网工程任务组）的RFC 1952定义。
    * 字典编码（LZ77）: 来查找和消除重复的字符串
        * 该算法通过`滑动窗口技术扫描数据流`，找到重复的数据片段，并用指向之前`数据位置的引用`替代这些片段
        * 例如，字符串 ABABAB 可以被压缩成 AB(0,2)(2,2)，其中 (0,2) 和 (2,2) 分别表示重复的子串。
    * 哈夫曼编码（Huffman coding）: 是一种`无损压缩算法`
        * 通过用`较短的位`表示`频率较高`的字符
        * 用`较长的位`表示`频率较低`的字符，从而减少整体数据量。
        例如，对于字符频率分布 {A: 5, B: 3, C: 2}，可以将 A 编码为 0，B 编码为 10，C 编码为 11。

* 当`服务器`开启 GZIP 压缩后，服务器会在`响应头`中添加 `Content-Encoding: gzip`，并使用 GZIP 算法对响应数据进行压缩。
* `客户端`浏览器在接收到压缩数据后，根据响应头信息，使用 `GZIP 解压缩算法` 还原数据

## 压缩过程

* 1、`请求阶段`： 客户端在`请求头`中添加 `Accept-Encoding: gzip`，表示它支持 GZIP 压缩。
* 2、`服务器响应阶段`：服务器检测到客户端支持 GZIP 后，将响应数据用 GZIP 算法压缩，并在`响应头`中添加 `Content-Encoding: gzip`。
* 3、`客户端解压阶段`：客户端浏览器接收到压缩数据后，根据 `Content-Encoding` 头信息，使用 GZIP 解压缩算法解压数据，并呈现给用户。

## 压缩效果

* 主要用于压缩 `Web 页面中的静态资源和部分动态内容`

| 文件类型    | 原始大小 | 压缩后大小 | 压缩率    |
|-------------|----------|------------|----------|
| HTML        | 100KB    | 30KB       | 70%      |
| CSS         | 50KB     | 15KB       | 70%      |
| JavaScript  | 200KB    | 60KB       | 70%      |
| JSON        | 80KB     | 20KB       | 75%      |
| XML         | 120KB    | 30KB       | 75%      |
| SVG         | 40KB     | 15KB       | 62.5%    |
