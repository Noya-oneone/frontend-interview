# 全面屏适配方案

* 为了实现全面屏适配，通常需要考虑不同屏幕尺寸、设备刘海（notch）、状态栏等问题。

## 使用 SafeAreaView

* React Native 提供了 SafeAreaView 组件，确保内容不会被刘海或圆角屏遮挡。它会自动适应设备的安全区域。

```jsx
import { SafeAreaView } from 'react-native';

const App = () => (
  <SafeAreaView style={{ flex: 1 }}>
    {/* Your content goes here */}
  </SafeAreaView>
);

```

## 第三方库：react-native-safe-area-context (处理刘海屏)

* 对于更复杂的场景，可以使用 react-native-safe-area-context 库，它提供了更灵活的安全区处理方式，特别是适配 iPhone 刘海屏等情况。

```bash
npm install react-native-safe-area-context
```

```jsx
import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context';

const App = () => (
  <SafeAreaProvider>
    <SafeAreaView style={{ flex: 1 }}>
      {/* Your content */}
    </SafeAreaView>
  </SafeAreaProvider>
);
```

## 第三方库：react-native-iphone-x-helper (处理刘海屏)

* 第三方库 react-native-iphone-x-helper 提供了一些辅助函数，可以方便地获取刘海屏的状态。

```bash
npm install react-native-iphone-x-helper
```

```jsx
import { isIphoneX } from'react-native-iphone-x-helper';

const App = () => {
  const isIphoneX = useIsIphoneX();

  return (
    <SafeAreaView style={{ flex: 1 }}>
      {/* Your content */}
    </SafeAreaView>
  );
};
```

## 使用 Dimensions 获取屏幕尺寸

* 通过 Dimensions API 获取屏幕宽度和高度，根据不同设备动态调整布局。

```jsx
import { Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');
```

## 状态栏适配: 使用 StatusBar 组件来自定义状态栏样式，确保不会影响页面内容显示

```jsx
import { StatusBar } from 'react-native';

const App = () => (
  <>
    <StatusBar barStyle="dark-content" />
    {/* Other content */}
  </>
);
```
