# 项目经历与亮点


### 全职项目
1. **Klarna APP H5 开发**
    - 将 H5 融入 APP 体系，采用 JS Bridge 进行通信，保证 H5 在 APP 里面的运行效率。
    - 对接 GraphQL 接口，使用 vue3.0 技术栈。
2. **Klarna 运营后台开发**
    - 实现单点登陆、BFF 数据转发、TF 脚本配置 Jenkins 流水线。
    - 运用 docker 部署前端和 node 中间层，采用 React18 技术。
3. **基建 - H5 三方登录与 SPM 埋点包开发**
    - 集成第三方登录，实现 Google、Facebook、AppleID 等主流第三方登录功能。
    - 开发 SPM 埋点包，能够精确追踪用户行为，为数据分析提供有力支持，广泛应用于圣诞节、复活节、KDDD 活动、万圣节等特定节日和活动，使用 Vue3.0。
4. **基建 CLI**
    - 开发星辰闪烁 CLI（VUE），引入 eslint、stylelint、commitlint、prettier、husky 保证项目代码风格规范统一。
    - 引入 Jest、testing - library/react 搭建单元测试框架，封装公共测试模块，编写单元测试、快照测试，能快速生成一个文件夹，提高开发代码效率。
5. **项目性能优化**
    - 基于 lighthouse，实现 web 页跑分服务，提升用户体验。
    - 采用强弱缓存 cache - control、拆包、冗余代码 tree - shaking 减小包体积、组件按需加载（element）、预加载、CDN、骨架屏、SSR 等方式提高网站性能。
    - 分数详情描述
6. **星月集团 ERP 平台**
    - 该项目以企业管理软件 ERP 系统和生产执行系统 MES 为核心，结合集成门窗厂房的产线改造建设和设备采购，同时建设 CRM、SCM、DMS、WMS、DAS、PLM、APS、OA 等子系统进行无缝对接。
    - 负责带领 5 个前端一起完成这个 ERP 系统，推动上线多个迭代版本。
7. **基建 - TableForm 表单封装**
    - 基于 Element UI，进行表格表单二次封装，通过引入 search.json 和 table.json 两个配置文件，为表单提供动态化配置能力。
    - 在 Bestdealer 中台项目中成功应用，有效减少了重复性工作，加速了项目开发进度。
    - 项目具体提升效率
