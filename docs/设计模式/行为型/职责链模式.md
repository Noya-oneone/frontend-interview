# 职责链模式

## 定义
* 职责链模式（Chain of Responsibility Pattern）：使`多个对象都有机会处理请求，从而避免请求的发送者和接收者之间的耦合关系`
* 将这些对象`连成一条链，并沿着这条链传递该请求，直到有一个对象处理它为止`。

* 也叫责任链模式，它是一种行为型设计模式，使多个对象都有机会处理请求，从而避免请求的发送者和接收者之间的耦合关系。该模式创建了一个链条，使得每个对象都有机会处理请求，直到链中的某个对象处理它为止。
* 	通过请求第一个条件，会持续执行后续的条件，直到返回结果为止

## 优点
* 降低耦合度：职责链模式使得一个对象无需知道链的结构，只需知道该对象处理请求的下一个对象即可。
* 简化对象：职责链模式简化了对象之间的连接，使得对象不必相互了解，从而使其更加灵活。
* 增强给对象指派职责：职责链模式可以使得一个对象对请求的处理不再局限于自己，而是将请求沿着链传递给下一个对象，直到有对象处理它为止。

## 缺点
* 过多的链会造成性能问题：由于每个对象都要检查链上的每个对象，因此，过多的链会造成性能问题。
* 请求可能会一直沿着链传递，直到处理：如果没有一个对象处理该请求，该请求将一直沿着链传递，直到链末端被处理。


## 适用场景
* 有多个对象可以处理请求，具体哪个对象处理由链中的哪个对象决定。
* 你想在不影响其他对象的情况下，动态地改变链中的处理者。
* 你想在不增加额外的复杂性和代码的情况下，对系统进行部分行为的控制。

## 实现方式
1. 创建一个抽象的Handler类，该类声明了一个处理请求的接口handleRequest()。
2. 创建多个具体的Handler子类，每个子类负责处理特定的请求。
3. 创建一个Chain类，该类声明了一个链的头部和尾部，并提供一个方法addHandler()来添加一个新的处理者到链中。
4. 在Chain类中，创建一个私有变量head，该变量指向链的头部。
5. 在Chain类中，创建一个方法handleRequest()，该方法遍历链上的每个处理者，直到有一个处理者处理该请求。
6. 在每个具体的Handler子类中，实现handleRequest()方法，该方法检查该请求是否与自己处理的请求类型匹配，如果匹配，则处理该请求；否则，将请求传递给链中的下一个处理者。
7. 在客户端代码中，创建Chain类的对象，并向其添加多个Handler子类的对象，然后调用handleRequest()方法来处理请求。

## 实例
假设我们有一家餐馆，需要根据顾客的年龄来定制菜品。我们可以设计一个职责链模式，使得不同的年龄段的顾客都有不同的菜品。

首先，我们创建抽象的Handler类：

```js
class Handler {
  constructor(successor) {
    this.successor = successor;
  }

  handleRequest(request) {
    if (this.canHandle(request)) {
      return this.handle(request);
    } else if (this.successor) {
      return this.successor.handleRequest(request);
    } else {
      throw new Error('没有处理该请求的对象');
    }
  }

  canHandle(request) {
    return false;
  }

  handle(request) {
    throw new Error('未实现');
  }
}
```


接下来，我们创建三个具体的Handler子类，每个子类负责处理不同年龄段的顾客：

```js
class ChildHandler extends Handler {
  canHandle(request) {
    return request.age < 18;
  }

  handle(request) {
    console.log('儿童套餐');
  }
}

class TeenagerHandler extends Handler {
  canHandle(request) {
    return request.age >= 18 && request.age < 30;
  }

  handle(request) {
    console.log('青少年套餐');
  }
}

class AdultHandler extends Handler {
  canHandle(request) {
    return request.age >= 30;
  }

  handle(request) {
    console.log('成人套餐');
  }
}
```


最后，我们创建Chain类，并向其添加三个Handler子类的对象：

```js
class Chain {
  constructor() {
    this.head = null;
  }

  addHandler(handler) {
    if (!this.head) {
      this.head = handler;
    } else {
      let current = this.head;
      while (current.successor) {
        current = current.successor;
      }
      current.successor = handler;
    }
  }

  handleRequest(request) {
    return this.head.handleRequest(request);
  }
}
```

客户端代码如下：

```js
const chain = new Chain();
chain.addHandler(new ChildHandler(new TeenagerHandler(new AdultHandler())));

chain.handleRequest({ age: 15 }); // 儿童套餐
chain.handleRequest({ age: 25 }); // 青少年套餐
chain.handleRequest({ age: 35 }); // 成人套餐
```
