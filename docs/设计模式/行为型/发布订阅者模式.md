# 发布订阅者模式

* 发布订阅者模式（Publisher/Subscriber Pattern）是一种行为型设计模式
* 它定义了一种一对多的依赖关系，让多个观察者对象同时监听某一主题对象。这个主题对象在状态上发生变化时，会通知所有观察者对象，使它们能够自动更新自己。


## 对比

* 观察者模式侧重于目标对象与观察者之间的`一对多关系`，发布订阅模式注重于通过事件通道进行消息的发布和订阅
    * `观察者模式`：通知机制是直接的，主体对象（Subject）负责`管理观察者`，并在状态变化时主动通知所有观察者。观察者必须实现更新接口以接收通知。
    * `发布订阅模式`：通知是通过消息中心进行的，发布者和订阅者彼此独立，消息中心在接收到事件时，负责向所有订阅者广播消息。订阅者通过订阅消息中心的某个事件来接收通知。

## js 示例

```javascript
// 发布者
class Publisher {
  constructor() {
    this.subscribers = [];
  }

  subscribe(subscriber) {
    this.subscribers.push(subscriber);
  }

  unsubscribe(subscriber) {
    const index = this.subscribers.indexOf(subscriber);
    if (index!== -1) {
      this.subscribers.splice(index, 1);
    }
  }

  notify(message) {
    this.subscribers.forEach(subscriber => {
      subscriber.update(message);
    });
  }
}


// 订阅者
class Subscriber {
  constructor(name) {
    this.name = name;
  }

  update(message) {
    console.log(`${this.name} received message: ${message}`);
  }
}


// 示例
const publisher = new Publisher();
const subscriber1 = new Subscriber('Subscriber 1');
const subscriber2 = new Subscriber('Subscriber 2');


publisher.subscribe(subscriber1);
publisher.subscribe(subscriber2);


publisher.notify('New message'); // Subscriber 1 received message: New message
// Subscriber 2 received message: New message

publisher.unsubscribe(subscriber2);

publisher.notify('New message 2'); // Subscriber 1 received message: New message 2
```
