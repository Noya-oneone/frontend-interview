# 命令模式

* 命令模式（Command Pattern）是一种行为设计模式，它使你能将一个请求封装为一个对象，从而使你可用不同的请求对客户进行参数化；对请求排队或记录请求日志，以及支持可撤销的操作。
* 命令模式是一种对象行为型模式，其别名为动作（Action）模式或事务（Transaction）模式。

命令模式的主要优点是：

1. 降低了系统的耦合度。命令模式使得请求调用者和请求接收者之间解耦。
2. 新的命令可以很容易地加入到系统中。由于增加新的具体命令类不影响其他类，因此增加新功能就变得很容易。


命令模式的主要缺点是：

1. 使用命令模式可能会导致某些系统有过多的具体命令类。因为针对每一个命令都需要设计一个具体命令类，这将增加系统的复杂性。
2. 如果某些命令的实现有一些共同的操作，那么可以考虑将其提取出来并集成到一个公共父类中。
3. 系统的使用者需要了解命令的具体类，这对系统的使用不太方便。


命令模式适用场景：

1. 系统需要将请求调用者和请求接收者解耦，使得调用者和接收者不直接交互。
2. 系统需要在不同的时间指定、排队和执行请求。
3. 系统需要支持命令的撤销和恢复操作。
4. 系统需要将一组操作组合在一起，即支持宏命令。


命令模式结构：

- Command（抽象命令类）：声明一个执行操作的接口。
- ConcreteCommand（具体命令类）：实现抽象命令类的 execute() 方法，负责调用请求接收者的相关操作。
- Invoker（调用者）：负责创建一个具体命令对象并调用其 execute() 方法。
- Receiver（请求接收者）：负责具体操作的执行。
- Client（客户端）：创建 Invoker 对象并设置相应的命令对象。


## 实例

假设我们要设计一个电视机的控制系统，该系统可以实现对电视机的各种操作，如打开、关闭、调节音量、调节屏幕亮度等。

我们可以设计一个命令接口 `Command` 如下：

```js
interface Command {
  execute(): void;
  undo(): void;
  redo(): void;

}
```

然后，我们可以设计一个具体命令类 `ConcreteCommand` 如下：

```js
class OpenCommand implements Command {
  private readonly receiver: Receiver;

  constructor(receiver: Receiver) {
    this.receiver = receiver;
  }

  execute(): void {
    this.receiver.open();
  }

  undo(): void {
    this.receiver.close();
  }

  redo(): void {
    this.execute();
  }
}


class CloseCommand implements Command {
  private readonly receiver: Receiver;

  constructor(receiver: Receiver) {
    this.receiver = receiver;
  }

  execute(): void {
    this.receiver.close();
  }

  undo(): void {
    this.receiver.open();
  }

  redo(): void {
    this.execute();
  }
}


class VolumeUpCommand implements Command {
  private readonly receiver: Receiver;

  constructor(receiver: Receiver) {
    this.receiver = receiver;
  }

  execute(): void {
    this.receiver.volumeUp();
  }

  undo(): void {
    this.receiver.volumeDown();
  }

  redo(): void {
    this.execute();
  }
}


class VolumeDownCommand implements Command {
  private readonly receiver: Receiver;

  constructor(receiver: Receiver) {
    this.receiver = receiver;
  }

  execute(): void {
    this.receiver.volumeDown();
  }

  undo(): void {
    this.receiver.volumeUp();
  }

  redo(): void {
    this.execute();
  }
}
```


接着，我们可以设计一个请求接收者 `Receiver` 如下：

```js
class Television {
  private isOn: boolean = false;
  private volume: number = 0;
  private brightness: number = 0;

  open(): void {
    this.isOn = true;
    console.log('打开电视机');
  }

  close(): void {
    this.isOn = false;
    console.log('关闭电视机');
  }

  volumeUp(): void {
    this.volume++;
    console.log(`调节音量为 ${this.volume}`);
  }

  volumeDown(): void {
    this.volume--;
    console.log(`调节音量为 ${this.volume}`);
  }

  brightnessUp(): void {
    this.brightness++;
    console.log(`调节屏幕亮度为 ${this.brightness}`);
  }

  brightnessDown(): void {
    this.brightness--;
    console.log(`调节屏幕亮度为 ${this.brightness}`);
  }
}
```


最后，我们可以设计一个调用者 `Invoker` 如下：


```js
class RemoteControl {
  private history: Command[] = [];
  private currentCommand: Command | null = null;

  setCommand(command: Command): void {
    if (this.currentCommand) {
      this.history.push(this.currentCommand);
    }
    this.currentCommand = command;
  }

  buttonWasPressed(): void {
    if (this.currentCommand) {
      this.currentCommand.execute();
      this.history.push(this.currentCommand);
      this.currentCommand = null;
    }
  }

  undoButtonWasPressed(): void {
    if (this.history.length > 0) {
      const command = this.history.pop();
      if (command) {
        command.undo();
        this.currentCommand = command;
      }
    }
  }

  redoButtonWasPressed(): void {
    if (this.history.length > 0) {
      const command = this.history[this.history.length - 1];
      if (command) {
        command.redo();
        this.currentCommand = command;
      }
    }
  }
}
```


这样，我们就完成了一个电视机控制系统的设计。
