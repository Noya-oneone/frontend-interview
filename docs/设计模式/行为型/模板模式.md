# 模板模式

* 模板模式（Template Method Pattern）是一种行为型设计模式
* 用于定义一个操作中的算法骨架，将一些`步骤的实现延迟到子类中`。
* 模板模式允许子类在不改变算法结构的情况下，重新定义算法中的某些特定步骤。
* 它主要用于重用代码的同时，确保算法的整体结构不变。

## 优点

* 封装不变部分，扩展可变部分
* 提取公共代码，便于维护
* 行为由父类控制，子类实现

## 缺点

* 多层继承下，代码可能过于复杂
* 增加了类的个数，增加了系统的复杂度


## 适用场景

* vue & react 生命周期钩子

```js
// 抽象类
class Template {
    // 模板方法，定义了算法骨架
    templateMethod() {
        this.step1();
        this.step2();
        this.step3();
    }

    step1() {
        console.log('Step 1: Default implementation');
    }

    step2() {
        console.log('Step 2: Default implementation');
    }

    step3() {
        console.log('Step 3: Default implementation');
    }
}

// 具体类 A
class ConcreteClassA extends Template {
    step1() {
        console.log('ConcreteClassA Step 1');
    }

    step2() {
        console.log('ConcreteClassA Step 2');
    }

    // step3 使用默认实现
}

// 具体类 B
class ConcreteClassB extends Template {
    step1() {
        console.log('ConcreteClassB Step 1');
    }

    step3() {
        console.log('ConcreteClassB Step 3');
    }

    // step2 使用默认实现
}

// 使用示例
const instanceA = new ConcreteClassA();
instanceA.templateMethod();
// 输出:
// ConcreteClassA Step 1
// ConcreteClassA Step 2
// Step 3: Default implementation

const instanceB = new ConcreteClassB();
instanceB.templateMethod();
// 输出:
// ConcreteClassB Step 1
// Step 2: Default implementation
// ConcreteClassB Step 3
```
