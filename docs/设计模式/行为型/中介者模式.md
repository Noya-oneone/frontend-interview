# 中介者模式

## 定义
* 中介者模式（Mediator Pattern）是一种行为型设计模式，
* 用于定义一个中介对象来封装一组对象之间的交互。通过中介者对象，各个对象不直接通信，而是通过中介者进行通信。
* 中介者模式可以减少对象之间的耦合，提高系统的可维护性和可扩展性。

## 实际案例

* `UI 组件协作`：在复杂的用户界面中，多个 UI 组件需要协作处理`用户输入`。中介者模式可以将这些组件的`交互逻辑集中在一个中介者中`，从而简化组件间的交互。

* `聊天系统`：在聊天应用中，用户之间的消息传递可以通过一个`中介者（服务器）`来处理。用户之间不直接通信，而是通过服务器转发消息。

* `中介者模式在游戏中的应用`：在游戏开发中，游戏对象（如玩家、敌人、道具等）之间的交互可以通过中介者进行管理，控制游戏逻辑和事件的处理。 （中央系统）


## 优点

* 减少耦合：通过中介者对象，减少了对象之间的直接通信，使得对象之间的耦合度降低。
* 集中控制：所有对象的交互逻辑集中在中介者中，使得系统更易于管理和扩展。
* 提高灵活性：可以动态改变对象之间的交互方式，而无需修改对象本身的实现。



## 缺点
* 中介者复杂：中介者可能变得过于复杂，处理大量的对象交互逻辑。
* 可能违反单一职责原则：中介者承担了过多的职责，可能导致其变得复杂，违反了单一职责原则。

## js 示例
```javascript
// 定义中介者类
class Mediator {
  constructor() {
    this.colleagues = [];
  }
  addColleague(colleague) {
    this.colleagues.push(colleague);
  }
  notify(sender, message) {
    this.colleagues.forEach(colleague => {
      if (colleague !== sender) {
        colleague.receive(message);
      }
    });
  }
}

// 定义同事类
class Colleague {
  constructor(name, mediator) {
    this.name = name;
    this.mediator = mediator;
    this.mediator.addColleague(this);
  }
  send(message) {
    this.mediator.notify(this, message);
  }
  receive(message) {
    console.log(`${this.name} received message: ${message}`);
  }
}

// 实例化中介者和同事
const mediator = new Mediator();
const colleague1 = new Colleague('colleague1', mediator);
const colleague2 = new Colleague('colleague2', mediator);


// 发送消息
colleague1.send('hello');
// colleague2 received message: hello
```
