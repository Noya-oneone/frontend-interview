# 原型模式

## 定义

* 原型模式（Prototype Pattern）是用于`创建重复的对象`，同时又能保证性能。
* 这种类型的设计模式属于`创建型模式`，它提供了一种创建对象的最佳方式。

* 在这种模式中，一个原型实例被创建后，可以复制生成多个同样的对象。
* 这种模式是通过`拷贝原型对象`来创建新的对象，而`不是通过对原型对象进行复杂的new操作来创建对象`。
* 原型模式在 JavaScript 中是一种非常强大且灵活的创建对象的方式。通过`原型链和 Object.create 方法`，你可以有效地`实现对象的共享和继承`。理解和正确使用原型模式，可以帮助你提高代码的效率和可维护性。然而，也需要注意其带来的潜在副作用，确保代码的稳定性和可调试性。

## 优点

- 性能优良：原型模式是一种创建对象`最快的方式`，因为它只需要复制已有对象，不需要反复创建对象。
- 节省资源：通过共享对象的原型，减少了重复创建相似对象的资源消耗。
- 灵活性：可以动态地修改原型对象的属性和方法，从而影响所有继承自原型的对象。

## 缺点

- 克隆复杂对象时，性能问题：当需要`克隆比较复杂的对象`时，原型模式的性能较差，因为它需要逐个属性进行复制。
- 调试困难：通过原型链继承的属性和方法可能会导致调试和理解代码时的困难，特别是当继承链较长时。
- 耦合性：如果不小心修改了原型对象的属性或方法，可能会影响所有继承该原型的对象，导致意外的副作用。


## 适用场景

- 资源优化场景：由于原型模式提供了简化的创建对象过程，使得程序运行更加高效。
- 类初始化需要复杂对象场景：由于原型模式可以克隆复杂对象，因此在类初始化时使用原型模式非常合适。
- 性能和安全要求的场景：对于需要频繁创建复杂对象，原型模式提供的性能优势可以提高程序的运行效率。

## 实现

```javascript
// 原型对象
const prototype = {
    greet() {
        console.log('Hello!');
    },
    sayName(name) {
        console.log(`My name is ${name}`);
    }
};

// 创建一个新对象，并继承原型对象
function createObject(proto) {
    function F() {}
    F.prototype = proto;
    return new F();
}

// 使用原型创建新对象
const obj1 = createObject(prototype);
obj1.greet();  // 输出: Hello!
obj1.sayName('Alice');  // 输出: My name is Alice

```
