# 组合模式
* 组合模式（Composite Pattern）是一种结构型设计模式
* 用于将对象组合成树形结构，以表示部分-整体层次结构。
* 组合模式允许客户端统一地对待单个对象和对象集合，从而实现对部分和整体的统一操作。

## 适用场景
* `文件系统`：文件系统中的目录和文件可以使用组合模式来表示。`目录是容器对象，文件是叶子对象`。可以对目录和文件进行统一的操作，如遍历、删除等。
* `组织结构`：在企业组织结构中，部门和员工可以使用组合模式来表示。`部门是容器对象，员工是叶子对象`。可以对部门和员工进行统一的操作，如打印组织结构。
* `图形绘制`：图形绘制软件中的图形元素可以使用组合模式来表示。`图形组是容器对象，单个图形元素是叶子对象`。可以对图形组和图形元素进行统一的操作，如绘制、移动等。

## 优点
简化客户端代码：客户端代码可以统一地处理单个对象和对象集合，无需关注具体对象的类型。
支持树形结构：适用于需要树形结构的场景，可以方便地添加和删除子组件。
高扩展性：增加新的叶子或容器对象不会影响现有代码，遵循开闭原则。

## 结构

* `组件（Component）`：定义了叶子和容器对象的`公共接口，并声明了叶子对象和容器对象所共有的操作`。
* `叶子（Leaf）`：实现了组件接口，并表示`树中的终端节点`，没有子节点。
* `容器（Composite）`：实现了组件接口，并可以持有子组件（叶子或其他容器）。负责`对其子组件的操作`。
* ` 客户端（Client）`：使用组件对象（叶子或容器），对其进行操作，不需要关心具体的对象类型。

## js实现

```javascript
class Component {
  constructor() {
    this.children = [];
  }

  add(component) {
    this.children.push(component);
  }

  remove(component) {
    const index = this.children.indexOf(component);
    if (index !== -1) {
      this.children.splice(index, 1);
    }
  }

  getChild(index) {
    return this.children[index];
  }

  operation() {
    throw new Error('Component is an abstract class');
  }
}

class Leaf extends Component {
  operation() {
    console.log('Leaf operation');
  }
}

class Composite extends Component {
  operation() {
    this.children.forEach(child => child.operation());
  }
}

const root = new Composite();
const composite1 = new Composite();
const composite2 = new Composite();
const leaf1 = new Leaf();
const leaf2 = new Leaf();

root.add(composite1);
root.add(composite2);
composite1.add(leaf1);
composite1.add(leaf2);

root.operation(); // Leaf operation, Leaf operation
```
