
## CSS 性能优化
* 防止CSS阻塞渲染

## 关键CSS内联在底部
* 将关键的、用于初始渲染的 CSS 直接内联在 HTML 文件的 <head> 中
    * 浏览器会并行加载 CSS，而不会延迟页面的首次渲染。


* 减少初次加载的外部请求数量，加快首屏渲染速度。
其余的 CSS 文件可以延迟加载或放在页面底部加载。
<style>
  /* 关键CSS，直接内联 */
  body { margin: 0; padding: 0; font-family: Arial, sans-serif; }
  /* 其他重要的首屏样式 */
</style>

## 异步加载非关键 CSS
使用 `rel="preload"` 或 rel="preload" 来异步加载非关键 CSS。加载完成后，`通过 JavaScript 动态切换为 rel="stylesheet"`。

<link rel="preload" href="styles.css" as="style" onload="this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="styles.css"></noscript>

## 减少和合并 CSS 文件
减少外部 CSS 文件的数量，将多个 CSS 文件合并成一个，减少 HTTP 请求次数。
可以通过构建工具（如 Webpack、Gulp）进行 CSS 文件合并和压缩。

## 使用媒体查询
<link rel="stylesheet" href="print.css" media="print">
<link rel="stylesheet" href="mobile.css" media="only screen and (max-width: 600px)">

## 使用 defer 和 async 加载 JS
虽然 defer 和 async 是针对 JavaScript 的，但确保 JS 不阻塞渲染同样重要。加载 JS 时阻止它阻塞 CSS 的加载和渲染。

## 平常优化手段
* 避免使用 @import 规则，因为它会阻塞渲染，应使用 link 标签的 rel="stylesheet" 来替代。
* 避免使用 @font-face 规则，因为它会阻塞渲染，应使用字体文件直接嵌入 HTML 文件中。
* 避免使用 `CSS 表达式`，因为它会阻塞渲染。
* 避免使用 CSS `选择器嵌套过深`，因为它会影响性能。
* 避免使用 `!important`，因为它会影响代码的可读性和可维护性。

## 原子CSS
* 原子CSS 是一种新的 CSS 语法，它允许开发者将多个 CSS 规则合并成一个规则。
* 原子CSS 允许开发者将多个 CSS 规则合并成一个规则，并通过 `@apply` 规则将其应用到多个元素上。
* 原子CSS 还可以避免使用 !important 规则，并允许开发者更好地控制样式。
