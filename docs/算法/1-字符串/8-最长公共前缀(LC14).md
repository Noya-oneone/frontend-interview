# 最长公共前缀（LeetCode 14）

* 算法题：查找字符串数组中的`最长公共前缀`，不存在则返回 `''`。
* 例：`['flower','flow','flight']` → `'fl'`；`['dog','racecar','car']` → `''`。

* `横向扫描`：拿第一个字符串当基准，逐个与后面的字符串求公共前缀，前缀只会越来越短。

## 横向扫描 - 时间复杂度：O(总字符数)，空间复杂度：O(1)

```js
function longestCommonPrefix(strs) {
  if (!strs.length) return '';
  let prefix = strs[0];
  for (let i = 1; i < strs.length; i++) {
    while (!strs[i].startsWith(prefix)) {
      prefix = prefix.slice(0, -1); // 不匹配就缩短前缀
      if (!prefix) return '';
    }
  }
  return prefix;
}

console.log(longestCommonPrefix(['flower', 'flow', 'flight'])); // 'fl'
console.log(longestCommonPrefix(['dog', 'racecar', 'car'])); // ''
```

## 纵向扫描（逐列比较）- 时间复杂度：O(总字符数)

```js
function longestCommonPrefix2(strs) {
  if (!strs.length) return '';
  for (let col = 0; col < strs[0].length; col++) {
    const ch = strs[0][col];
    for (let i = 1; i < strs.length; i++) {
      // 某列出现不一致，公共前缀到上一列为止
      if (col === strs[i].length || strs[i][col] !== ch) {
        return strs[0].slice(0, col);
      }
    }
  }
  return strs[0];
}

console.log(longestCommonPrefix2(['flower', 'flow', 'flight'])); // 'fl'
```

## 取巧解法：排序后只比首尾

* 按字典序排序后，`第一个`和`最后一个`字符串差异最大，它们的公共前缀就是全体的公共前缀。

```js
function longestCommonPrefix3(strs) {
  if (!strs.length) return '';
  const sorted = [...strs].sort();
  const first = sorted[0];
  const last = sorted[sorted.length - 1];
  let i = 0;
  while (i < first.length && first[i] === last[i]) i++;
  return first.slice(0, i);
}

console.log(longestCommonPrefix3(['flower', 'flow', 'flight'])); // 'fl'
```
