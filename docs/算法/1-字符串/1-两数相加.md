# 两数相加

* 两个大树相加

1. 两数相加

给出两个**非空**的链表，每个链表包含**至少**一个节点。

将两个链表合并为一个新的链表，要求合并后的链表依然有序。

返回合并后的链表。

**示例1:**

```
输入: 1->2->4, 1->3->4
输出: 1->1->2->3->4->4
```

**示例2:**

```
输入: 0, 0
输出: 0
```

**说明:**

- 链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`

javascript 代码如下：

```javascript
/**
 * Definition for singly-linked list.
 * function ListNode(val) {
 *     this.val = val;
 *     this.next = null;
 * }
 */
/**
 * @param {ListNode} l1
 * @param {ListNode} l2
 * @return {ListNode}
 */
var addTwoNumbers = function(l1, l2) {
    let dummy = new ListNode(0);
    let curr = dummy;
    let carry = 0;
    while (l1 || l2 || carry) {
        let sum = (l1? l1.val : 0) + (l2 ? l2.val : 0) + carry;
        carry = sum >= 10 ? 1 : 0;
        curr.next = new ListNode(sum % 10);
        curr = curr.next;
        if (l1) l1 = l1.next;
        if (l2) l2 = l2.next;
    }
    return dummy.next;
};
```

<!-- 字符串解法 -->

```javascript
/**
 * @param {string} num1
 * @param {string} num2
 * @return {string}
 */
var addStrings = function(num1, num2) {
    let carry = 0;
    let result = '';
    let i = num1.length - 1;
    let j = num2.length - 1;
    while (i >= 0 || j >= 0 || carry) {
        let sum = (i >= 0 ? parseInt(num1[i]) : 0) + (j >= 0 ? parseInt(num2[j]) : 0) + carry;
        carry = sum >= 10 ? 1 : 0;
        result = (sum % 10) + result;
        i--;
        j--;
    }
    return result;
};
```
