# 版本号比较（LeetCode 165）

* 算法题：比较两个版本号 `version1` 和 `version2`：`v1 > v2` 返回 `1`，`v1 < v2` 返回 `-1`，否则返回 `0`。
* 前端高频：npm 依赖版本、App/SDK 版本门槛判断（如「iOS 端 ≥ 5.3.0 才启用新功能」）几乎必考。
* 例：`1.01` vs `1.001` → `0`（每段按整数比较，忽略前导零）；`1.0` vs `1.0.0` → `0`（缺失段视为 0）。

## 分段比较 - 时间复杂度：O(max(m, n))，空间复杂度：O(m + n)

```js
function compareVersion(version1, version2) {
  const v1 = version1.split('.');
  const v2 = version2.split('.');
  const len = Math.max(v1.length, v2.length);
  for (let i = 0; i < len; i++) {
    const a = parseInt(v1[i] ?? '0', 10); // 缺失段补 0
    const b = parseInt(v2[i] ?? '0', 10);
    if (a > b) return 1;
    if (a < b) return -1;
  }
  return 0;
}

console.log(compareVersion('1.01', '1.001')); // 0
console.log(compareVersion('1.0', '1.0.0')); // 0
console.log(compareVersion('0.1', '1.1')); // -1
console.log(compareVersion('5.3.1', '5.3')); // 1
```

## 常见追问

* 版本号数组排序？直接把比较函数交给 `sort`：

```js
const versions = ['1.45.0', '1.5', '6', '3.3.3.3.3.3.3', '2.0.1'];
versions.sort(compareVersion);
console.log(versions); // ['1.5', '1.45.0', '2.0.1', '3.3.3.3.3.3.3', '6']
```

* 带 `-beta.1` / `-rc.2` 等预发布标签怎么办？按 [semver](https://semver.org/lang/zh-CN/) 规范：预发布版本`低于`对应正式版本，标签再逐段比较（数字段按数值、字母段按 ASCII）。生产环境直接用 [semver 库](https://www.npmjs.com/package/semver) 的 `semver.gt/lt/eq`。
