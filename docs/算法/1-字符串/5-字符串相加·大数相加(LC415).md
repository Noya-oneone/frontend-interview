# 字符串相加 / 大数相加（LeetCode 415）

* 算法题：给定两个字符串形式的非负整数 `num1` 和 `num2`，返回它们的和（字符串形式），`不能`直接用 `BigInt` 或把字符串转成整数。
* 前端高频：JS 的 `Number` 超过 `Number.MAX_SAFE_INTEGER`（2^53 - 1）会丢精度，所以大数运算必须按位模拟。

* 核心思想：`从末位开始逐位相加`，维护进位 `carry`，模拟竖式加法。

## 逐位模拟 - 时间复杂度：O(max(m, n))，空间复杂度：O(1)（不算输出）

```js
function addStrings(num1, num2) {
  let i = num1.length - 1;
  let j = num2.length - 1;
  let carry = 0;
  let res = '';
  while (i >= 0 || j >= 0 || carry > 0) {
    const a = i >= 0 ? +num1[i] : 0;
    const b = j >= 0 ? +num2[j] : 0;
    const sum = a + b + carry;
    res = (sum % 10) + res; // 当前位
    carry = Math.floor(sum / 10); // 进位
    i--;
    j--;
  }
  return res;
}

console.log(addStrings('123', '989')); // '1112'
console.log(addStrings('9007199254740993', '9007199254740993')); // '18014398509481986'
console.log(9007199254740993 + 9007199254740993); // 18014398509481984（精度丢失！）
```

## 对照：BigInt 写法（面试先问能不能用）

```js
const addBig = (a, b) => (BigInt(a) + BigInt(b)).toString();
console.log(addBig('9007199254740993', '9007199254740993')); // '18014398509481986'
```
