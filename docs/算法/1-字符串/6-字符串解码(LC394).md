# 字符串解码（LeetCode 394）

* 算法题：给定编码字符串，规则为 `k[encoded_string]`，表示方括号内的字符串重复 `k` 次，返回解码结果。
* 例：`3[a]2[bc]` → `aaabbbcc` 不对，是 `aaabcbc`；`3[a2[c]]` → `accaccacc`。
* 前端高频：模板字符串解析、嵌套结构展开，考察`栈`的运用。

* 核心思想：遇到 `[` 把「当前累积的字符串 + 重复次数」压栈；遇到 `]` 弹栈拼接。

## 栈 - 时间复杂度：O(输出长度)，空间复杂度：O(嵌套深度)

```js
function decodeString(s) {
  const stack = []; // 存 [之前累积的字符串, 重复次数]
  let cur = ''; // 当前层已解析的字符串
  let num = 0; // 当前层正在读的数字
  for (const ch of s) {
    if (ch >= '0' && ch <= '9') {
      num = num * 10 + +ch; // 数字可能是多位数
    } else if (ch === '[') {
      stack.push([cur, num]); // 进入新一层，保存现场
      cur = '';
      num = 0;
    } else if (ch === ']') {
      const [prev, k] = stack.pop(); // 回到上一层
      cur = prev + cur.repeat(k);
    } else {
      cur += ch;
    }
  }
  return cur;
}

console.log(decodeString('3[a]2[bc]')); // 'aaabcbc'
console.log(decodeString('3[a2[c]]')); // 'accaccacc'
console.log(decodeString('2[abc]3[cd]ef')); // 'abcabccdcdcdef'
console.log(decodeString('10[a]')); // 'aaaaaaaaaa'
```

## 易错点

* 数字可能是`多位数`（如 `10[a]`），必须 `num * 10 + 当前位` 累积。
* 嵌套时必须`保存现场`（外层字符串 + 次数）再进入内层，这正是栈的语义。
* 递归解法同样可行：遇到 `[` 递归解析到配对的 `]`，本质是用调用栈代替显式栈。
