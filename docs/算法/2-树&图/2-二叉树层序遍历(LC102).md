# 二叉树层序遍历（LeetCode 102）

* 算法题：返回二叉树`按层`从左到右的遍历结果（二维数组，每层一个子数组）。
* 前端高频：DOM 树按层遍历、组件树广度优先搜索、`vDOM diff` 的层级比较都用同一个模板。

* 核心思想：`BFS + 队列`，每轮先记录`当前层的节点数`，把这一层整体出队、下一层整体入队。

## BFS 队列 - 时间复杂度：O(n)，空间复杂度：O(n)

```js
function levelOrder(root) {
  if (!root) return [];
  const res = [];
  let queue = [root];
  while (queue.length) {
    const next = [];
    const level = [];
    for (const node of queue) {
      level.push(node.val);
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    res.push(level);
    queue = next; // 整层替换，避免 shift() 的 O(n) 开销
  }
  return res;
}

const tree = {
  val: 3,
  left: { val: 9, left: null, right: null },
  right: {
    val: 20,
    left: { val: 15, left: null, right: null },
    right: { val: 7, left: null, right: null },
  },
};
console.log(levelOrder(tree)); // [[3], [9, 20], [15, 7]]
```

## DFS 递归版（带层号）

```js
function levelOrder2(root) {
  const res = [];
  const dfs = (node, depth) => {
    if (!node) return;
    (res[depth] ||= []).push(node.val); // 第一次到达该层时建数组
    dfs(node.left, depth + 1);
    dfs(node.right, depth + 1);
  };
  dfs(root, 0);
  return res;
}

const tree2 = {
  val: 3,
  left: { val: 9, left: null, right: null },
  right: {
    val: 20,
    left: { val: 15, left: null, right: null },
    right: { val: 7, left: null, right: null },
  },
};
console.log(levelOrder2(tree2)); // [[3], [9, 20], [15, 7]]
```

## 常见变体

* `锯齿形`层序遍历（LeetCode 103）：偶数层 `level.reverse()`。
* `右视图`（LeetCode 199）：每层取最后一个。
* DOM 场景：`node.children` 代替 `left/right`，遍历整棵 DOM 树统计层级/节点数。
