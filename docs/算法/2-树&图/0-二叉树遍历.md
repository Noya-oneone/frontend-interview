# 二叉树&图

## 树的遍历

* 访问根节点的顺序就是树的遍历顺序。
* 树的遍历有三种方式：前序遍历、中序遍历、后序遍历。

### 树的基本结构

```javascript
class TreeNode {
  constructor(val) {
    this.val = val;
    this.left = null;
    this.right = null;
  }
}
```

### 前序遍历

```javascript
// 1. 访问根节点
// 2. 前序遍历左子树
// 3. 前序遍历右子树
function preOrder(root) {
  if (root === null) {
    return;
  }
  console.log(root.val);
  preOrder(root.left);
  preOrder(root.right);
}
```


### 中序遍历

```javascript
// 1. 前序遍历左子树
// 2. 访问根节点
// 3. 前序遍历右子树
function inOrder(root) {
  if (root === null) {
    return;
  }
  inOrder(root.left);
  console.log(root.val);
  inOrder(root.right);
}
```

### 后序遍历

```javascript
// 1. 前序遍历左子树
// 2. 前序遍历右子树
// 3. 访问根节点
function postOrder(root) {
  if (root === null) {
    return;
  }
  postOrder(root.left);
  postOrder(root.right);
  console.log(root.val);
}
```
