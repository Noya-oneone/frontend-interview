# 树和图的搜索方式

* 深度优先搜索（DFS）和广度优先搜索（BFS）是`图和树`遍历的两种基本算法
    * **深度优先搜索 DFS**：结点的`处理顺序是完全相反的顺序`，就像它们被添加到`栈`中一样，它是`后进先出`。所以深度优先搜索一般使用`栈`实现
        * 路径查找
    * **广度优先搜索BFS**：它的特点是越是`接近根结点`的结点将越早地遍历 （`队列`）
        * 最短路径

* V 是`顶点的数量`，E 是`边的数量`
* 对于图的每个顶点和每条边，DFS 都会遍历一次，因此时间复杂度是顶点数和边数之和 `O(V + E) `
* BFS 也会遍历每个顶点和每条边一次，因此时间复杂度是顶点数和边数之和 `O(V + E) `

| 算法 | 时间复杂度 | 空间复杂度 | 最坏情况
|------|------------|------------|---------｜
| `DFS深度优先搜索`   | O(V + E)   | O(V)   | O(V)，最坏情况下需要存储所有`顶点的栈空间`（对于递归实现）
| `BFS广度优先搜索`  | O(V + E)   | O(V)   | O(V)，最坏情况下需要存储所有`顶点的队列空间`

| 特性 | 深度优先搜索 (DFS) | 广度优先搜索 (BFS) |
|------------------|------------------------|------------------------------|
| **遍历方式**  | 先沿一个方向走到底，再回溯  | 逐层遍历，先访问邻居节点|
| **数据结构**  | 栈（递归调用`栈`或显式栈）| `队列`  |
| **实现方式**  | 递归或迭代 | 迭代  |
| **路径查找**  | 适合查找所有路径| 适合查找最短路径  |
| **空间复杂度**| O(V)，最坏情况下需要存储所有节点的栈空间 | O(V)，最坏情况下需要存储所有节点的队列 |
| **时间复杂度**| O(V + E)，遍历所有节点和边   | O(V + E)，遍历所有节点和边 |
| **节点处理顺序**  | LIFO（后进先出）| FIFO（先进先出）  |
| **适用场景**  | 适合解决如迷宫、连通分量等问题   | 适合解决如最短路径、层次遍历等问题 |
| **优先级**| 深度优先，可能会优先找到深层的解  | 广度优先，优先找到离起点最近的解   |
| **回溯**  | 需要，探索到叶子节点后回溯| 不需要，逐层推进   |
| **实现复杂度**| 相对简单，递归实现常用| 相对简单，迭代实现常用 |
