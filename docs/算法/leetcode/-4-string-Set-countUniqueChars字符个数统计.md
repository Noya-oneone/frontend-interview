# -4-string-Set-countUniqueChars字符个数统计

```javascript
//   编写一个函数，计算字符串中含有的不同字符的个数。字符在ASCII码范围内(0~127，包括0和127)，换行表示结束符，不算在字符里。
//   字符的ASCII码范围是0~127，不在范围内的不作统计。
//   多个相同的字符只计算一次 例如，对于字符串abaca而言，有a、b、c三种不同的字符，因此输出3。
//   输入描述： 输入一行没有空格的字符串。
//   输出描述： 输出 输入字符串 中范围在(0~127，包括0和127)字符的种数。
//   示例1： 输入：abcde 输出：5

// 使用哈希表或类似的数据结构（如 Set）可以有效地解决需要去重和快速查找的问题。
// 在这个字符统计的场景中，Set 实现了哈希表的特性，从而简化了代码并提高了效率。
// Set 在 JavaScript 中是基于哈希表的特性实现的

// Set 的特性
// 唯一性：Set 自动去重，只允许存储唯一的值。这是哈希表的一个基本特性，因为每个键只能对应一个值。
// 快速查找：在 Set 中，查找元素的时间复杂度平均为 O(1)，这是由于其底层实现使用了哈希表。
// 无序性：Set 的元素没有固定的顺序，虽然在插入时保持插入顺序，但不保证任何特定的顺序。

// 哈希表的工作原理
// 哈希表通过一个哈希函数将键映射到数组的索引。使用哈希表的主要优势在于：
// 快速的插入、删除和查找操作，通常为常数时间。
// 解决冲突的机制（如链表法或开放定址法）使得多个键可以映射到相同的索引。
// 总结
// Set 是一种使用哈希表实现的集合类型，利用哈希表的特性来提供高效的去重和查找功能。
// 因此，Set 在许多情况下可以看作是哈希表的一种应用。

function countUniqueChars(str) {
  const uniqueChars = new Set(); // 使用 Set 存储唯一字符

  for (let char of str) {
    const charCode = char.charCodeAt(0); // 获取字符的 ASCII 码
    if (charCode >= 0 && charCode <= 127) {
      // 检查 ASCII 范围
      uniqueChars.add(char); // 添加到 Set 中，自动去重
    }
  }

  return uniqueChars.size; // 返回唯一字符的数量
}

// 示例调用
const input = "abcde"; // 输入字符串
console.log(countUniqueChars(input)); // 输出：5

```
