# -14-HJ27.查找兄弟单词

```javascript
// # HJ27.查找兄弟单词

// 描述： 定义一个兄弟单词为：交换该单词字母顺序（可以交换任意次），而不添加、删除、修改原有的字母就能生成的单词，兄弟单词要求和原来的单词不同，例如ab和ba是兄弟单词，ab和ab就不是；，现在给你n个单词，另外再给你一个单词x,让你寻找x的兄弟单词里，按字典排序后的第k个单词是什么？
// 注意： 字典中可能有重复单词
// 数据范围： 1<=n<=1000,输入的字符串长度满足1<=len(str)<=10,1<=k<=n
// 输入描述： 输入只有一行，先输入字典中单词的个数n，再输入n个单词作为字典单词，然后输入一个单词x，最后输入整数k
// 输出描述： 第一行输出查找到x的兄弟单词的个数m，第二行输出查找到的按照字典顺序排序后的第k个兄弟单词，没有符合的不用输出
// 示例:1：
// 输入：
// 3 abc bca cab abc 1
// 输出：
// 2
// bca
// 示例2：
// 输入：
// 6 cab ad abcd cba abc bca abc 1
// 输出：
// 3
// bca
// 说明：abc的兄弟单词有cab cba bca，所以输出3，经字典序排列后，变为bca cab cba，所以第1个字典序兄弟单词为bca

const readline = require("readline");

// 创建接口实例
const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout,
});

rl.on("line", (line) => {
  const input = line.split(" ");
  const n = parseInt(input[0]);
  const words = input.slice(1, n + 1);
  const x = input[n + 1];
  const k = parseInt(input[n + 2]);

  // 定义一个函数用来判断是否为兄弟单词
  const isBrotherWord = (word1, word2) => {
    if (word1 === word2) return false;
    if (word1.length !== word2.length) return false;
    return word1.split("").sort().join("") === word2.split("").sort().join("");
  };

  // 查找兄弟单词
  const brotherWords = words.filter((word) => isBrotherWord(word, x));

  // 按字典序排序
  brotherWords.sort();

  // 输出兄弟单词的个数
  console.log(brotherWords.length);

  // 输出第 k 个兄弟单词
  if (brotherWords.length >= k) {
    console.log(brotherWords[k - 1]);
  }

  rl.close();
});

```
