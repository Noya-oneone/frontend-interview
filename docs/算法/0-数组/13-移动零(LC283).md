# 移动零（LeetCode 283）

* 算法题：给定数组 `nums`，将所有 `0` 移动到数组`末尾`，同时保持非零元素的`相对顺序`，必须`原地`操作（不能拷贝新数组）。
* 例：`[0,1,0,3,12]` → `[1,3,12,0,0]`。

* `双指针（快慢指针）`：慢指针 `slow` 指向下一个非零元素应放的位置，快指针 `fast` 扫描全数组。

## 双指针 - 时间复杂度：O(n)，空间复杂度：O(1)

```js
function moveZeroes(nums) {
  let slow = 0;
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      [nums[slow], nums[fast]] = [nums[fast], nums[slow]]; // 交换，零被换到后面
      slow++;
    }
  }
  return nums;
}

console.log(moveZeroes([0, 1, 0, 3, 12])); // [1, 3, 12, 0, 0]
console.log(moveZeroes([0, 0, 1])); // [1, 0, 0]
```

## 变体写法：先覆盖再补零

```js
function moveZeroes2(nums) {
  let slow = 0;
  for (const n of nums) {
    if (n !== 0) nums[slow++] = n; // 非零元素依次前移
  }
  while (slow < nums.length) nums[slow++] = 0; // 剩余位置补零
  return nums;
}

console.log(moveZeroes2([0, 1, 0, 3, 12])); // [1, 3, 12, 0, 0]
```

## 常见追问

* 为什么不能用 `filter + concat`？题目要求`原地`修改，空间复杂度必须 O(1)。
* 交换版 vs 覆盖版：交换版写操作更少（只在非零时交换），覆盖版逻辑更直白。
