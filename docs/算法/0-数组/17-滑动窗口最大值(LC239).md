# 滑动窗口最大值（LeetCode 239）

* 算法题：给定数组 `nums` 和窗口大小 `k`，窗口从左到右滑动，返回`每个窗口内的最大值`。
* 例：`nums = [1,3,-1,-3,5,3,6,7], k = 3` → `[3,3,5,5,6,7]`。
* 前端场景：滚动监控指标（FPS/内存）取区间峰值、图表数据降采样。

* `单调队列`：队列里只保留「还有机会成为最大值」的元素下标，从队头到队尾对应值`单调递减`，队头永远是当前窗口最大值。

## 单调队列 - 时间复杂度：O(n)，空间复杂度：O(k)

```js
function maxSlidingWindow(nums, k) {
  const deque = []; // 存下标，对应值单调递减
  const res = [];
  for (let i = 0; i < nums.length; i++) {
    // 队尾比当前值小的都不可能再是最大值，弹出
    while (deque.length && nums[deque[deque.length - 1]] <= nums[i]) {
      deque.pop();
    }
    deque.push(i);
    // 队头滑出窗口范围则移除
    if (deque[0] <= i - k) deque.shift();
    // 窗口形成后开始记录
    if (i >= k - 1) res.push(nums[deque[0]]);
  }
  return res;
}

console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)); // [3, 3, 5, 5, 6, 7]
console.log(maxSlidingWindow([1], 1)); // [1]
```

## 暴力解法（对照）- 时间复杂度：O(n*k)

```js
function maxSlidingWindow2(nums, k) {
  const res = [];
  for (let i = 0; i + k <= nums.length; i++) {
    res.push(Math.max(...nums.slice(i, i + k)));
  }
  return res;
}

console.log(maxSlidingWindow2([1, 3, -1, -3, 5, 3, 6, 7], 3)); // [3, 3, 5, 5, 6, 7]
```

## 关键点

* 队列里存`下标`而不是值：既能比大小，又能判断是否滑出窗口。
* 每个元素最多入队、出队各一次，所以整体是 O(n)。
