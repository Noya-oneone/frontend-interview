# 接雨水（LeetCode 42）

* 算法题：给定 `n` 个非负整数表示柱子高度，求下雨后能`接多少水`。
* 例：`[0,1,0,2,1,0,1,3,2,1,2,1]` → `6`。

* 核心思想：每个位置能接的水 = `min(左边最高, 右边最高) - 当前高度`。
* `双指针`：不预处理左右最高数组，用两个指针从两端向中间收缩，谁矮先处理谁。

## 双指针 - 时间复杂度：O(n)，空间复杂度：O(1)

```js
function trap(height) {
  let left = 0;
  let right = height.length - 1;
  let leftMax = 0; // 左侧已扫描的最高柱
  let rightMax = 0; // 右侧已扫描的最高柱
  let water = 0;
  while (left < right) {
    if (height[left] < height[right]) {
      // 左边矮：水量由 leftMax 决定（右边一定有更高的挡板）
      leftMax = Math.max(leftMax, height[left]);
      water += leftMax - height[left];
      left++;
    } else {
      rightMax = Math.max(rightMax, height[right]);
      water += rightMax - height[right];
      right--;
    }
  }
  return water;
}

console.log(trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])); // 6
console.log(trap([4, 2, 0, 3, 2, 5])); // 9
```

## 动态规划（预处理左右最高）- 时间复杂度：O(n)，空间复杂度：O(n)

```js
function trap2(height) {
  const n = height.length;
  if (n === 0) return 0;
  const leftMax = [height[0]];
  const rightMax = new Array(n);
  rightMax[n - 1] = height[n - 1];
  for (let i = 1; i < n; i++) leftMax[i] = Math.max(leftMax[i - 1], height[i]);
  for (let i = n - 2; i >= 0; i--) rightMax[i] = Math.max(rightMax[i + 1], height[i]);
  let water = 0;
  for (let i = 0; i < n; i++) {
    water += Math.min(leftMax[i], rightMax[i]) - height[i];
  }
  return water;
}

console.log(trap2([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])); // 6
```
