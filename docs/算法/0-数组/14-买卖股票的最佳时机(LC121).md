# 买卖股票的最佳时机（LeetCode 121）

* 算法题：数组 `prices` 表示某股票每天的价格，只能`买卖一次`（先买后卖），求能获取的`最大利润`；无利润则返回 `0`。
* 例：`[7,1,5,3,6,4]` → `5`（第 2 天买入 1，第 5 天卖出 6）。

* 核心思想：遍历时维护`历史最低价 minPrice`，当天卖出的最大利润 = `当前价 - 历史最低价`，取全局最大。

## 一次遍历 - 时间复杂度：O(n)，空间复杂度：O(1)

```js
function maxProfit(prices) {
  let minPrice = Infinity; // 到目前为止的最低买入价
  let maxProfit = 0;
  for (const price of prices) {
    minPrice = Math.min(minPrice, price);
    maxProfit = Math.max(maxProfit, price - minPrice);
  }
  return maxProfit;
}

console.log(maxProfit([7, 1, 5, 3, 6, 4])); // 5
console.log(maxProfit([7, 6, 4, 3, 1])); // 0（一直跌，不交易）
```

## 常见追问

* `可以买卖多次`（LeetCode 122）？贪心：把所有`上涨区间`的差价累加。

```js
function maxProfit2(prices) {
  let profit = 0;
  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
  }
  return profit;
}

console.log(maxProfit2([7, 1, 5, 3, 6, 4])); // 7（1→5 赚 4，3→6 赚 3）
```
