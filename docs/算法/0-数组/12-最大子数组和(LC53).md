# 最大子数组和（LeetCode 53）

* 算法题：给定整数数组 `nums`，找出一个具有最大和的`连续子数组`（至少包含一个元素），返回其最大和。
* 例：`[-2,1,-3,4,-1,2,1,-5,4]` → `6`（子数组 `[4,-1,2,1]`）。

* `动态规划（Kadane 算法）`：面试标准答案，一次遍历。
* 核心思想：以第 `i` 个元素结尾的最大子数组和 `dp[i] = max(nums[i], dp[i-1] + nums[i])`——前面的累加和为负就`果断丢弃`，从当前元素重新开始。

## 动态规划（Kadane）- 时间复杂度：O(n)，空间复杂度：O(1)

```js
function maxSubArray(nums) {
  let cur = nums[0]; // 以当前元素结尾的最大和
  let max = nums[0]; // 全局最大和
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]); // 前缀为负则重新开始
    max = Math.max(max, cur);
  }
  return max;
}

console.log(maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4])); // 6
console.log(maxSubArray([5, 4, -1, 7, 8])); // 23
console.log(maxSubArray([-1])); // -1
```

## 常见追问

* 如果要`返回子数组本身`？记录 `cur` 重置时的起点下标即可。
* 全是负数怎么办？Kadane 天然支持（返回最大的那个负数），前提是初始值取 `nums[0]` 而不是 `0`。
