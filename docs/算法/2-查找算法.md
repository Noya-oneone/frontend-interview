# 查找算法 线性查找、哈希查找、二分查找

| 查找方法       | 最坏时间复杂度 | 平均时间复杂度 | 最好时间复杂度 | 空间复杂度 |
|----------------|----------------|----------------|----------------|------------|
| **线性查找**   | O(n)           | O(n)           | O(1)           | O(1)       |
| **哈希查找**   | O(n)           | O(1)           | O(1)           | O(n)       |
| **二分查找**   | O(log n)       | O(log n)       | O(log n)       | O(1)       |


## 线性查找 （时间复杂度：O(n)，空间复杂度：O(1)）
* `小型数据集`：数据量较小，线性查找的性能不会成为瓶颈。
* `无序数据`：当数据无序时、线性查找的效率较高。
* `不支持随机访问的数据结构`：如链表，线性查找能遍历链表中的每个元素。
* 说明：线性查找简单直接，但效率低，不适合大型数据集。
```javascript
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) {
      return i;
    }
  }
  return -1;
}
```

## 哈希查找 （时间复杂度：O(1)，空间复杂度：O(n)）

* 哈希查找是一种`基于键值`对的查找算法
* `大型数据集`：需要处理大量数据，哈希表能提供快速的查找性能。
* `需要高效查找的场景`：需要频繁查找、插入和删除数据的场景，哈希查找可以提供平均常数时间复杂度。
* `需要支持快速插入和删除操作`：哈希表允许快速的插入和删除操作。
* 说明：虽然哈希查找在平均情况下表现非常好，但需要`处理哈希冲突`，且空间复杂度较高。

```javascript
function hashSearch(arr, target) {
  const hash = {};
  for (let i = 0; i < arr.length; i++) {
    hash[arr[i]] = i;
  }
  return hash[target] || -1;
}
``` 

## 二分查找 （时间复杂度：O(log n)，空间复杂度：O(1)）

* 二分查找是一种`折半查找算法`，即每次查找都将数组分为两部分，缩小查找范围。
* `大型有序数组`或列表：数据已经排序，二分查找能显著提高查找速度。
* 需要`频繁查找`的场景：对有序数据进行频繁查找时，二分查找能提供较好的性能。
* 说明：高效，`但前提是数据必须是有序的，否则不能使用`。对于有序数据，提供对数时间复杂度的查找。

```javascript
function binarySearch(arr, target) {
  let left = 0;
  let right = arr.length - 1;
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) {
      return mid;
    } else if (arr[mid] < target) {
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }
  return -1;
}
```
