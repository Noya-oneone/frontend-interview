# 冒泡排序 & 快速排序 & 插入排序 & 选择排序 & 归并排序

**排序算法：**： 冒泡排序、插入排序、选择排序、快速排序、归并排序
| 排序算法       | 最坏时间复杂度 | 平均时间复杂度 | 最好时间复杂度 | 空间复杂度 |
|----------------|----------------|----------------|----------------|------------|
| **冒泡排序**   | O(n^2)         | O(n^2)         | O(n)           | O(1)       |
| **快速排序**   | O(n^2)         | O(n log n)     | O(n log n)     | O(log n)   |
| **选择排序**   | O(n^2)         | O(n^2)         | O(n^2)         | O(1)       |
| **插入排序**   | O(n^2)         | O(n^2)         | O(n)           | O(1)       |
| **归并排序**   | O(n log n)     | O(n log n)     | O(n log n)     | O(n)       |

* `O(n^2)` 在较大的 `n` 值下比 `O(n log n)` 要大
* 数据量`较小`适合：插入排序、冒泡排序、选择排序
* 数据量`较大`适合：快速排序、归并排序


## 冒泡排序 （时间复杂度：O(n^2)、空间复杂度：O(1)）
冒泡排序（Bubble Sort）是一种简单的排序算法。它重复地走访过要排序的数列，`一次比较两个元素`，如果他们的顺序错误就把他们交换过来。走访数列的工作是重复地进行`直到没有再需要交换`，也就是说该数列已经排序完成。

1. 外层循环控制遍历次数，即数组长度减去1。
2. 内层循环控制比较次数，即数组长度减去外层循环次数。
3. 内层循环比较相邻的两个元素，如果前者大于后者，则交换位置。
4. 最后返回排序后的数组。

```javascript
function bubbleSort(arr) {
  const len = arr.length;
  for (let i = 0; i < len - 1; i++) {
    for (let j = 0; j < len - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
  return arr;
}
```

## 快速排序

* 时间复杂度：O(nlogn)，它的平均时间复杂度为O(nlogn)，最坏时间复杂度为O(n^2)
* 空间复杂度：O(logn)

1. 选取数组第一个元素作为基准值。
2. 遍历数组，将小于基准值的元素放入左边数组，大于基准值的元素放入右边数组。
3. 递归左边数组和右边数组，直到数组长度为1。
4. 合并左边数组、基准值、右边数组，返回排序后的数组。

```javascript
function quickSort(arr) {
  if (arr.length <= 1) {
    return arr;
  }
  const pivot = arr[0];
  const left = [];
  const right = [];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < pivot) {
      left.push(arr[i]);
    } else {
      right.push(arr[i]);
    }
  }
  return [...quickSort(left), pivot,...quickSort(right)];
}
```

## 选择排序 （ 时间复杂度：`O(n^2)`、 空间复杂度：`O(1)`）

1. 外层循环控制遍历次数，即数组长度减去1。
2. 内层循环找到最小值索引，并与当前索引交换位置。
3. 最后返回排序后的数组。

```javascript
function selectionSort(arr) {
  const len = arr.length;
  for (let i = 0; i < len - 1; i++) {
    let minIndex = i;
    for (let j = i + 1; j < len; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j;
      }
    }
    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
    }
  }
  return arr;
}
```

## 插入排序 （ 时间复杂度：`O(n^2)`、 空间复杂度：`O(1)`）

1. 外层循环控制遍历次数，即数组长度减去1。
2. 内层循环找到当前元素应该插入的位置，并将当前元素插入到该位置。
3. 最后返回排序后的数组。

```javascript
function insertionSort(arr) {
  const len = arr.length;
  for (let i = 1; i < len; i++) {
    const current = arr[i];
    let j = i - 1;
    while (j >= 0 && arr[j] > current) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = current;
  }
  return arr;
}
```

## 归并排序 （时间复杂度：O(nlogn)、空间复杂度：O(n)）
1. 递归分解数组，直到数组长度为1。
2. 合并两个有序数组，返回排序后的数组。
```javascript
function mergeSort(arr) {
  if (arr.length <= 1) {
    return arr;
  }
  const mid = Math.floor(arr.length / 2);
  const left = arr.slice(0, mid);
  const right = arr.slice(mid);
  return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right) {
  const result = [];
  let i = 0;
  let j = 0;
  while (i < left.length && j < right.length) {
    if (left[i] < right[j]) {
      result.push(left[i]);
      i++;
    } else {
      result.push(right[j]);
      j++;
    }
  }
  return result.concat(left.slice(i)).concat(right.slice(j));
}
```



快速排序和归并排序区别： 

* 快速排序是一种分治法的排序算法，它的平均时间复杂度为O(nlogn)，最坏时间复杂度为O(n^2)，空间复杂度为O(logn)。
* 归并排序是一种递归的排序算法，它的平均时间复杂度为O(nlogn)，最坏时间复杂度为O(nlogn)，空间复杂度为O(n)。
