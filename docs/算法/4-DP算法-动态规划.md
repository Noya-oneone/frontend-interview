# 动态规划 DP算法

## 什么是动态规划

动态规划（Dynamic Programming，DP）是一种在数学、管理科学、计算机科学、经济学、生物学、控制论、优化理论、人工智能、语言学、数理逻辑、计算理论、地理学、信息论、计算数学、信号处理、控制工程、工程技术、电气工程、计算机科学等领域中使用的，用来解决复杂问题的一种方法。

动态规划的基本思想是将复杂问题分解为子问题，先求解子问题，再组合子问题的解得到原问题的解。动态规划常用于求解最优化问题，即寻找最优解的问题。

动态规划的三个步骤：

1. 定义子问题：将原问题分解为若干个子问题，子问题之间具有重叠性。
2. 递归定义子问题的解：用递归公式定义子问题的解，即子问题的解依赖于子问题的解。
3. 组合子问题的解：通过递归公式，将子问题的解组合成原问题的解。


动态规划的优点：

1. 最优子结构：动态规划解决的问题具有最优子结构，即问题的最优解包含了子问题的最优解。
2. 重叠子问题：动态规划对子问题的解进行缓存，避免重复计算，从而减少计算量。
3. 状态转移方程：动态规划的状态转移方程是一种递归公式，用来描述子问题与原问题之间的关系。
4. 时间复杂度：动态规划的时间复杂度与子问题的个数成正比，即 O(n^2)、O(n^3) 等。

动态规划的缺点：

1. 空间复杂度：动态规划的空间复杂度与子问题的个数成正比，即 O(n^2)、O(n^3) 等。
2. 子问题的重叠性：动态规划的子问题之间具有重叠性，导致空间浪费。
3. 序列型问题：动态规划适用于序列型问题，即子问题之间存在一定的顺序关系。


动态规划的适用场景：

1. 最短路径问题：动态规划可以解决最短路径问题，如求解一个图中两点之间的最短路径。
2. 背包问题：动态规划可以解决背包问题，如求解背包问题中的物品放置问题。
3. 最大子数组问题：动态规划可以解决最大子数组问题，如求解一个数组中的连续子数组的最大和。
4. 股票交易问题：动态规划可以解决股票交易问题，如求解买卖股票的最大收益。
5. 数学问题：动态规划可以解决数学问题，如求解最大公约数、最小公倍数等。

### 代码举例

#### 最长公共子序列

```javascript
function longestCommonSubsequence(str1, str2) {
  const m = str1.length;
  const n = str2.length;
  const dp = new Array(m + 1).fill(0).map(() => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (str1[i - 1] === str2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }

  let index = dp[m][n];
  const result = new Array(index).fill('');

  let i = m;
  let j = n;
  while (i > 0 && j > 0) {
    if (str1[i - 1] === str2[j - 1]) {
      result[index - 1] = str1[i - 1];
      i--;
      j--;
      index--;
    } else if (dp[i - 1][j] > dp[i][j - 1]) {
      i--;
    } else {
      j--;
    }
  }

  return result.join('');
}
```
