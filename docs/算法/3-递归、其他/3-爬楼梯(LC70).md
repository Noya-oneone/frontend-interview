# 爬楼梯（LeetCode 70）

* 算法题：每次可以爬 `1` 或 `2` 个台阶，爬到第 `n` 阶共有多少种方法？
* 本质就是`斐波那契数列`：到第 `n` 阶的方法 = 到第 `n-1` 阶（再爬 1 步）+ 到第 `n-2` 阶（再爬 2 步）。
* 与 [2-递归-frogJump-NC68.青蛙跳台阶](./2-递归-frogJump-NC68.青蛙跳台阶.md) 同题，是 DP 入门的标准面试题。

## 动态规划（滚动变量）- 时间复杂度：O(n)，空间复杂度：O(1)

```js
function climbStairs(n) {
  if (n <= 2) return n;
  let prev = 1; // f(1)
  let cur = 2; // f(2)
  for (let i = 3; i <= n; i++) {
    [prev, cur] = [cur, prev + cur];
  }
  return cur;
}

console.log(climbStairs(2)); // 2（1+1、2）
console.log(climbStairs(3)); // 3（1+1+1、1+2、2+1）
console.log(climbStairs(10)); // 89
```

## 递归 + 记忆化 - 时间复杂度：O(n)

* 朴素递归是 O(2^n)，会大量重复计算子问题，必须加缓存。

```js
function climbStairs2(n, memo = new Map()) {
  if (n <= 2) return n;
  if (memo.has(n)) return memo.get(n);
  const res = climbStairs2(n - 1, memo) + climbStairs2(n - 2, memo);
  memo.set(n, res);
  return res;
}

console.log(climbStairs2(10)); // 89
```

## 常见追问

* 每次可以爬 `1~m` 阶？`f(n) = f(n-1) + f(n-2) + ... + f(n-m)`，内层再套一个循环。
* 爬楼梯的`最小花费`（LeetCode 746）？状态转移改成 `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`。
