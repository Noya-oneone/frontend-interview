# 环形链表（LeetCode 141）

* 算法题：判断链表中`是否有环`（尾节点的 next 指回了链表中的某个节点）。
* 前端场景：检测`循环引用`（`JSON.stringify` 遇循环引用会抛错）、原型链/依赖图成环检测，思路相通。

* `快慢指针（Floyd 判圈）`：快指针一次走 2 步，慢指针一次走 1 步；若有环，快指针必然`追上`慢指针。

## 快慢指针 - 时间复杂度：O(n)，空间复杂度：O(1)

```js
function hasCycle(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true; // 相遇即有环
  }
  return false; // fast 走到 null 说明无环
}

// 构造测试链表：3→2→0→-4，-4 指回 2
const n1 = { val: 3, next: null };
const n2 = { val: 2, next: null };
const n3 = { val: 0, next: null };
const n4 = { val: -4, next: null };
n1.next = n2;
n2.next = n3;
n3.next = n4;
n4.next = n2; // 成环
console.log(hasCycle(n1)); // true

const straight = { val: 1, next: { val: 2, next: null } };
console.log(hasCycle(straight)); // false
```

## Set 解法 - 时间复杂度：O(n)，空间复杂度：O(n)

```js
function hasCycle2(head) {
  const seen = new Set();
  for (let p = head; p; p = p.next) {
    if (seen.has(p)) return true;
    seen.add(p); // Set 存节点引用本身
  }
  return false;
}

const a = { val: 1, next: null };
const b = { val: 2, next: null };
a.next = b;
b.next = a; // 成环
console.log(hasCycle2(a)); // true
```

## 常见追问

* 找`入环节点`（LeetCode 142）？相遇后把其中一个指针放回头部，两指针都改为一次走 1 步，再次相遇处即入环点（数学推导：头到入环点距离 = 相遇点沿环到入环点距离）。
* 为什么快指针走 2 步而不是 3 步？走 2 步保证相对速度为 1，一定能在环内追上；步长更大可能「跳过」慢指针，需要更多圈数才相遇。
