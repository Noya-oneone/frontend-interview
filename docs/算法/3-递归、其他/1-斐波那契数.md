# 斐波那契数

斐波那契数 （通常用 F(n) 表示）形成的序列称为 斐波那契数列 。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：

F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
给定 n ，请计算 F(n) 。

```javascript
// 优点: 代码简单直观。
// 缺点: 时间复杂度为 O(2^n)，随着 n 的增大，效率非常低。
var fib = function(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
};
```
```javascript
// 动态规划
// 优点: 时间复杂度为 O(n)，空间复杂度为 O(n)，效率较高。
// 缺点: 代码相对简单，不够直观。
function fib(n) {
    if (n <= 1) return n;
    
    let dp = [0, 1];
    
    for (let i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    
    return dp[n];
}

// 示例
console.log(fib(10)); // 输出 55

```

```javascript
// 仅存储前两个数
// 优点: 时间复杂度为 O(n)，空间复杂度降至 O(1)，仅需常量级别的额外空间。
// 缺点: 代码相对动态规划略微复杂一点。
function fib(n) {
    if (n <= 1) return n;
    
    let prev1 = 0, prev2 = 1;
    
    for (let i = 2; i <= n; i++) {
        let current = prev1 + prev2;
        prev1 = prev2;
        prev2 = current;
    }
    
    return prev2;
}

// 示例
console.log(fib(10)); // 输出 55
```
