# 反转链表（LeetCode 206）

* 算法题：反转单链表，返回新的头节点。
* 例：`1→2→3→4→5` → `5→4→3→2→1`。
* 链表第一题，考察指针操作基本功；数据结构见 [1-链表List](../../数据结构/1-链表List.md)。

## 迭代（三指针）- 时间复杂度：O(n)，空间复杂度：O(1)

```js
function reverseList(head) {
  let prev = null;
  let cur = head;
  while (cur) {
    const next = cur.next; // 先存下一个，防断链
    cur.next = prev; // 反转指向
    prev = cur; // prev、cur 各前进一步
    cur = next;
  }
  return prev; // 循环结束时 prev 是新头
}

// 工具函数：数组 ↔ 链表，方便本地验证
const toList = (arr) => arr.reduceRight((next, val) => ({ val, next }), null);
const toArray = (head) => {
  const res = [];
  for (let p = head; p; p = p.next) res.push(p.val);
  return res;
};

console.log(toArray(reverseList(toList([1, 2, 3, 4, 5])))); // [5, 4, 3, 2, 1]
```

## 递归 - 时间复杂度：O(n)，空间复杂度：O(n)（调用栈）

```js
function reverseList2(head) {
  if (!head || !head.next) return head;
  const newHead = reverseList2(head.next); // 先反转后面的部分
  head.next.next = head; // 让下一个节点指回自己
  head.next = null; // 断开原来的正向指针
  return newHead;
}

const list = { val: 1, next: { val: 2, next: { val: 3, next: null } } };
const reversed = reverseList2(list);
console.log(reversed.val, reversed.next.val, reversed.next.next.val); // 3 2 1
```

## 常见追问

* 反转`区间` [left, right]（LeetCode 92）？加`虚拟头节点 dummy`，先走到 left 前一个，再做区间头插。
* `K 个一组`翻转（LeetCode 25）？每 K 个做一次区间反转，不足 K 个保持原序。
