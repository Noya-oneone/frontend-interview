# 合并两个有序链表（LeetCode 21）

* 算法题：将两个`升序`链表合并为一个新的升序链表并返回。
* 例：`1→2→4` + `1→3→4` → `1→1→2→3→4→4`。
* 与 [8-合并两个有序数组](../0-数组/8-合并两个有序数组.md) 对应，是`归并排序`的合并步骤。

## 迭代（虚拟头节点）- 时间复杂度：O(m+n)，空间复杂度：O(1)

```js
function mergeTwoLists(l1, l2) {
  const dummy = { val: -1, next: null }; // 虚拟头，省去处理「谁当头」的分支
  let tail = dummy;
  while (l1 && l2) {
    if (l1.val <= l2.val) {
      tail.next = l1;
      l1 = l1.next;
    } else {
      tail.next = l2;
      l2 = l2.next;
    }
    tail = tail.next;
  }
  tail.next = l1 || l2; // 接上剩余部分
  return dummy.next;
}

const toList = (arr) => arr.reduceRight((next, val) => ({ val, next }), null);
const toArray = (head) => {
  const res = [];
  for (let p = head; p; p = p.next) res.push(p.val);
  return res;
};

console.log(toArray(mergeTwoLists(toList([1, 2, 4]), toList([1, 3, 4]))));
// [1, 1, 2, 3, 4, 4]
```

## 递归 - 时间复杂度：O(m+n)，空间复杂度：O(m+n)

```js
function mergeTwoLists2(l1, l2) {
  if (!l1) return l2;
  if (!l2) return l1;
  if (l1.val <= l2.val) {
    l1.next = mergeTwoLists2(l1.next, l2);
    return l1;
  }
  l2.next = mergeTwoLists2(l1, l2.next);
  return l2;
}

const build = (arr) => arr.reduceRight((next, val) => ({ val, next }), null);
const print = (head) => {
  const res = [];
  for (let p = head; p; p = p.next) res.push(p.val);
  return res;
};
console.log(print(mergeTwoLists2(build([1, 2, 4]), build([1, 3, 4]))));
// [1, 1, 2, 3, 4, 4]
```

## 常见追问

* 合并 `K` 个有序链表（LeetCode 23）？两两归并（分治）O(N log K)，或用`最小堆`每次取 K 个头中最小的。
* `虚拟头节点`的意义？统一「插到头部」和「插到中间」的逻辑，避免对第一个节点做特判——链表题通用技巧。
