# 实现颜色转换rgba（255.255.255）#FFF转换的多种思路


* `padStart` 常用于需要将字符串`填充到指定长度`的场景，例如将数字转为固定长度的字符串，常见于日期、时间、十六进制数等格式化。

```javascript

function rgbaToHex(r, g, b, a = 1) {
    const toHex = n => n.toString(16).padStart(2, '0').toUpperCase();
    return `#${toHex(r)}${toHex(g)}${toHex(b)}` + (a < 1 ? toHex(Math.round(a * 255)) : '');
}
// 示例
console.log(rgbaToHex(255, 255, 255)); // #FFFFFF
```
