# 图Graph

## 图的定义

图（Graph）是由顶点（Vertex）和边（Edge）组成的集合。

## 图的表示

图的表示有两种：

- 邻接矩阵表示法
- 邻接表表示法

### 邻接矩阵表示法

邻接矩阵表示法是用一个二维数组来表示图的顶点和边。

- 顶点的个数为n，则邻接矩阵的维度为n x n。
- 如果顶点i和顶点j之间有边，则邻接矩阵中第i行第j列的元素为1，否则为0。

### 邻接表表示法

邻接表表示法是用一个数组来表示图的顶点和边。

- 顶点的个数为n，则邻接表的长度为n。
- 数组中的每个元素是一个链表，链表中的每个元素是一个邻接顶点。

## 图的遍历

图的遍历是指从图的某一顶点出发，依次访问图中所有顶点的方法。

图的遍历有两种：

- 深度优先搜索（DFS）
- 广度优先搜索（BFS）

### 深度优先搜索（DFS）

深度优先搜索（DFS）是一种从图的某一顶点出发，按照图的邻接关系，沿着路径深度优先遍历图的算法。

- 步骤：
  1. 选择一个未访问过的顶点作为起始顶点。
  2. 访问该顶点。
  3. 依次访问该顶点的邻接顶点，如果邻接顶点未被访问过，则递归调用DFS函数。
  4. 重复步骤2-3，直到所有顶点都被访问过。

### 广度优先搜索（BFS）

广度优先搜索（BFS）是一种从图的某一顶点出发，按照图的邻接关系，沿着路径宽度优先遍历图的算法。

- 步骤：
  1. 选择一个未访问过的顶点作为起始顶点。
  2. 访问该顶点。
  3. 将该顶点的邻接顶点加入队列。
  4. 重复步骤2-3，直到队列为空。
  5. 若队列为空，则说明图中所有顶点都被访问过。

## 图的应用

图的应用有很多，如：

- 路径问题
- 最小生成树问题
- 最短路径问题
- 网络流问题
- 图的划分问题
- 图的着色问题
- 图的连通性问题
- 图的匹配问题
- 图的生成问题
