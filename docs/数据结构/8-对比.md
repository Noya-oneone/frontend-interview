# 数据结构对比

空间复杂度都是O(n)

## 栈、队列、列表的区别
**栈**：后进先出 O(1)，仅在栈顶操作 `LIFO`  -- **递归、表达式求值、函数调用管理**  `push`, `pop`, `peek`
**队列**：先进先出 O(1)，队头删除，队尾插入 `FIFO` -- **任务调度、消息队列、广度优先搜索** `enqueue`, `dequeue`, `front`
**链表**：线性数据结构，每个节点包含数据和指针。 插入和删除为O(1)，搜索为O(n) -- **文件系统、数据库索引、图数据结构**
* `单向链表`：只有一个指针指向下一个节点，从头到尾遍历。
* `双向链表`：有两个指针指向前一个节点和下一个节点，从头到尾和从尾到头都可以遍历。
* `循环链表`：最后一个节点的指针指向头节点，从头到尾和从尾到头都可以遍历。
**堆**：基于树的特殊数据结构，用于实现优先队列。 插入和删除为O(log n)，获取最值为O(1) -- **最小生成树算法**
**列表**：线性数据结构，每个元素都有唯一的索引。 插入和删除为O(1)，搜索为O(n) -- **数组、链表、动态数组、频繁插入、删除和访问操作** `insert`, `remove`, `get`, `size`


| 特性  | 单向链表 (Singly Linked List) | 双向链表 (Doubly Linked List)  |
|-|-|-|
| **定义**  | 每个节点包含一个数据域和一个指向下一个节点的指针。   | 每个节点包含一个数据域、一个指向下一个节点和一个指向前一个节点的指针。 |
| **主要特性**  | 只能单向遍历。 | 可以双向遍历。|
| **操作**  | 插入、删除和搜索操作。   | 插入、删除和搜索操作。  |
| **优点**  | 节点结构简单，占用内存较少。 | 可以双向遍历，操作更灵活。  |
| **缺点**  | 不能逆向遍历，操作不灵活。  | 节点结构复杂，占用内存较多。|
| **示例代码**  | ```javascript\nclass ListNode {\nconstructor(value) {\nthis.value = value;\nthis.next = null;\n}\n}\n\nclass SinglyLinkedList {\nconstructor() {\nthis.head = null;\n}\n// 插入节点等操作...\n}\n``` | ```javascript\nclass ListNode {\nconstructor(value) {\nthis.value = value;\nthis.next = null;\nthis.prev = null;\n}\n}\n\nclass DoublyLinkedList {\nconstructor() {\nthis.head = null;\nthis.tail = null;\n}\n// 插入节点等操作...\n}\n``` |

* **时间复杂度**：
在计算机科学中，时间复杂度是一个函数，它定量描述了**算法的运行时间**。例如 O(n), O(logn), O(n^2) 等。

* **空间复杂度**：空间复杂度是一个函数，它定量描述了一个**算法在运行过程中临时占用的存储空间大小**。例如 O(n), O(logn), O(1) 等。




## 二叉树最大深度 （o(n)、o(n)）

```javascript
function maxDepth(root) {
if (root === null) {
return 0;
}
const leftDepth = maxDepth(root.left);
const rightDepth = maxDepth(root.right);
return Math.max(leftDepth, rightDepth) + 1;
}
```
