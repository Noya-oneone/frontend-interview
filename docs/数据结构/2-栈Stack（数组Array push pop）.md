# 栈（Stack）

* 栈（Stack）是一种线性数据结构，它遵循后进先出（Last In First Out，LIFO）的原则。
* 栈是一种容器，可以存放任意类型的数据，并遵循先进后出（First In Last Out，FILO）的原则。
* 栈的操作有两种：入栈（push）和出栈（pop）。
* 添加是添加到栈顶，删除是删除栈顶。

想象你有一个装满了盘子的架子，你只能从架子的顶部放入或取出盘子：

架子：代表栈结构。
盘子：代表栈中的元素。
如果你要放一个新盘子，你只能放在顶部；如果你要取一个盘子，也只能从顶部取。这就是后进先出（LIFO）原则，意味着最后放上去的盘子是最先被取下的。栈的这种特性非常适合管理函数调用的顺序，因为最后一个调用的函数会最先结束。
