# Flex 布局

## 核心概念

* Flexbox 是 CSS3 的一维布局方案，高效地对容器中的元素进行`对齐与空间分配`。
* 设为 Flex 布局以后，子元素的 `float、clear、vertical-align` 属性将失效。
* 容器默认存在两根轴：`主轴（main axis）`和`交叉轴（cross axis）`，主轴方向由 `flex-direction` 决定（默认 `row`，水平）。
  * 主轴的开始位置叫 main start，结束位置叫 main end；
  * 交叉轴的开始位置叫 cross start，结束位置叫 cross end。

```css
.box { display: flex; }         /* 块级 flex 容器 */
.box { display: inline-flex; }  /* 行内 flex 容器 */
```

## 容器属性（6 个）

* `flex-direction`：决定主轴的方向（项目的排列方向）
  * `row`（默认）：水平，起点在左端
  * `row-reverse`：水平，起点在右端
  * `column`：垂直，起点在上沿
  * `column-reverse`：垂直，起点在下沿
* `flex-wrap`：一条轴线排不下时如何换行
  * `nowrap`（默认）：不换行（项目会被压缩）
  * `wrap`：换行，第一行在上方
  * `wrap-reverse`：换行，第一行在下方
* `flex-flow`：`flex-direction` + `flex-wrap` 的简写，默认 `row nowrap`
* `justify-content`：项目在`主轴`上的对齐方式
  * `flex-start`（默认）| `flex-end` | `center`
  * `space-between`：两端对齐，项目之间间隔相等
  * `space-around`：每个项目两侧间隔相等（视觉上两端间隔是中间的一半）
  * `space-evenly`：所有间隔完全相等
* `align-items`：项目在`交叉轴`上的对齐方式
  * `stretch`（默认）：项目未设高度或为 auto 时，拉伸占满容器
  * `flex-start` | `flex-end` | `center`
  * `baseline`：按项目第一行文字的基线对齐
* `align-content`：`多根轴线`（换行后形成多行）的对齐方式，只有一行时不起作用
  * `stretch`（默认）| `flex-start` | `flex-end` | `center` | `space-between` | `space-around`

另有 `gap / row-gap / column-gap` 设置项目间距，避免用 margin hack：

```css
.box { display: flex; gap: 16px; }
```

## 项目属性（6 个）

* `order`：排列顺序，`数值越小越靠前`，默认 0
* `flex-grow`：`放大比例`，默认 0（有剩余空间也不放大）
* `flex-shrink`：`缩小比例`，默认 1（空间不足时等比缩小；设 0 可禁止压缩）
* `flex-basis`：分配剩余空间之前项目的`基准大小`，默认 auto；同时设置时`优先级高于 width`
* `flex`：`flex-grow flex-shrink flex-basis` 的简写，默认 `0 1 auto`
* `align-self`：允许单个项目有不一样的交叉轴对齐方式，`覆盖 align-items`，默认 auto

### flex 简写的常见取值（高频考点）

| 写法 | 展开 | 含义 |
|--|--|--|
| `flex: 1` | `1 1 0%` | 基准 0，剩余空间按比例分；多个 `flex:1` 项目`等宽` |
| `flex: auto` | `1 1 auto` | 基准为内容尺寸，再分剩余空间；内容多的项目更宽 |
| `flex: none` | `0 0 auto` | 不放大不缩小，尺寸固定 |
| `flex: 0 1 auto` | 默认值 | 不放大，可缩小 |

## 常见考点

* **`flex: 1` 和 `flex: auto` 的区别？** 差在 `flex-basis`：前者是 `0%`（无视内容，等分空间），后者是 `auto`（先按内容占位，再分剩余空间）。
* **定宽列被压缩怎么办？** 空间不足时 `flex-shrink: 1` 默认生效，给定宽列加 `flex-shrink: 0`。
* **`justify-content` 与 `align-items` 分别沿哪根轴？** 主轴 / 交叉轴；`flex-direction: column` 时两者作用方向互换。
* **垂直居中一行搞定**：`display: flex; justify-content: center; align-items: center;`（详见 [垂直居中的多种方案](./2-垂直居中的多种方案.md)）
