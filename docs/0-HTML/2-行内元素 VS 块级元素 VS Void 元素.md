# 行内元素 VS 块级元素 VS Void 元素

## 行内元素 VS 块级元素

| 特性 | 行内元素（Inline） | 块级元素（Block） |
|--|--|--|
| **显示特性** | 在同一行内显示，不会独占整行 | 独占一行，后续内容在新行开始 |
| **常见元素** | `<span>`、`<a>`、`<strong>`、`<em>`、`<code>` | `<div>`、`<p>`、`<h1>`、`<ul>`、`<table>` |
| **宽高** | 宽高由内容决定，`设置 width / height 无效` | 可设置宽高，默认宽度撑满父元素 |
| **margin / padding** | `水平方向有效`；垂直方向的 margin 无效，垂直 padding 视觉上撑开但`不影响周围元素的布局` | 四个方向都有效 |
| **包含关系** | 一般只容纳文本或其他行内元素 | 可以容纳行内元素和其他块级元素 |
| **典型用途** | 文本片段的样式化 | 页面结构与布局 |

### 例外：可替换元素（高频追问）

`<img>`、`<input>`、`<video>` 等是`行内可替换元素`（replaced element）：虽然是行内级别，但内容由外部资源决定，**可以设置宽高**，表现接近 `inline-block`。「行内元素不能设宽高」这条规则只适用于非替换元素。

### display 三兄弟对比

| | `block` | `inline` | `inline-block` |
|--|--|--|--|
| 独占一行 | ✅ | ❌ | ❌ |
| 可设宽高 | ✅ | ❌ | ✅ |
| 垂直 margin/padding 生效 | ✅ | ❌ | ✅ |

## Void 元素（空元素）

Void 元素`没有内容、没有闭合标签`（写 `<br/>` 的自闭合斜杠在 HTML 中是可选的、会被忽略）。

| 元素 | 描述 |
|--|--|
| `<br>` | 换行符 |
| `<hr>` | 水平分隔线 |
| `<img>` | 嵌入图像 |
| `<input>` | 用户输入控件 |
| `<meta>` | 文档元数据 |
| `<link>` | 关联外部资源（通常在 `<head>` 中） |
| `<base>` | 所有相对 URL 的基准 URL |
| `<area>` | 图像映射中的可点击区域 |
| `<col>` | 表格列属性（在 `<colgroup>` 内使用） |
| `<embed>` | 嵌入外部内容 |
| `<source>` | `<video>` / `<audio>` / `<picture>` 的资源 |
| `<track>` | 音视频的文本轨道（如字幕） |
| `<wbr>` | 建议的单词内换行位置 |

> `<command>`、`<keygen>`、`<param>` 已从标准中废弃，不要再用。

## 常见行内元素

| 元素 | 描述 |
|--|--|
| `<a>` | 超链接 |
| `<span>` | 无语义的行内容器 |
| `<strong>` / `<b>` | 加粗；`<strong>` 有「重要」语义，`<b>` 纯视觉 |
| `<em>` / `<i>` | 斜体；`<em>` 有「强调」语义，`<i>` 纯视觉 |
| `<code>` / `<kbd>` / `<samp>` / `<var>` | 代码 / 键盘输入 / 程序输出 / 变量 |
| `<mark>` | 高亮标记 |
| `<q>` / `<cite>` | 短引用 / 作品标题 |
| `<s>` / `<u>` / `<small>` | 删除线 / 下划线 / 小号文本 |
| `<sub>` / `<sup>` | 下标 / 上标 |
| `<time>` | 时间或日期 |
| `<label>` | 表单控件的标签 |

## 常见块级元素

| 元素 | 描述 |
|--|--|
| `<div>` | 无语义的块级容器 |
| `<p>` | 段落 |
| `<h1>` ~ `<h6>` | 标题，层级递减 |
| `<ul>` / `<ol>` / `<li>` | 无序 / 有序列表及列表项 |
| `<dl>` / `<dt>` / `<dd>` | 描述列表 / 术语 / 描述 |
| `<header>` / `<footer>` / `<main>` / `<nav>` / `<aside>` | 语义化布局标签 |
| `<article>` / `<section>` | 独立内容 / 主题分组 |
| `<figure>` / `<figcaption>` | 媒体内容及其标题 |
| `<form>` / `<fieldset>` | 表单 / 表单控件分组 |
| `<table>` / `<thead>` / `<tbody>` / `<tfoot>` / `<tr>` / `<td>` / `<th>` | 表格族 |
| `<blockquote>` / `<pre>` | 长引用 / 预格式化文本 |
| `<address>` / `<details>` / `<summary>` | 联系信息 / 可折叠内容及其标题 |

## 常见考点

* **行内元素设置 `margin-top` 会生效吗？** 不会（非替换元素）；水平方向的 margin / padding 有效。
* **`<img>` 是行内还是块级？** 行内级别的`可替换元素`，可设宽高；图片底部的空隙来自基线对齐，用 `vertical-align: bottom` 或 `display: block` 消除。
* **HTML5 的元素分类**：新标准不再按 inline/block 二分，而是按`内容模型`（Flow / Phrasing / Interactive…）分类；inline/block 只是 CSS `display` 的默认值。
