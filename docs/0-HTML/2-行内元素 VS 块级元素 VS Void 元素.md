
## 行内元素 VS 块级元素
| 特性| 行内元素（Inline Elements） | 块级元素（Block-Level Elements）|
|----------------|-----------------------|-------------|
| **定义**       | 元素在页面中呈现为行内的一部分，不会打断行。       | 元素在页面中占据一整行，前后通常会有换行。|
| **显示特性**   | 元素在同一行内显示，不会独占整行。                | 元素会独占一行，后续内容会在新行开始显示。       |
| **常见元素** | `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`, `<input>` | `<div>`, `<p>`, `<h1>`, `<ul>`, `<ol>`, `<table>` |
| **宽度和高度** | 行内元素的宽度和高度由内容决定，无法设置宽度和高度。 | 块级元素的宽度和高度可以设置，默认宽度为父元素的100%。|
| **内外边距**   | 内外边距（margin 和 padding）不会影响到周围元素的流。 | 内外边距会影响到元素周围的其他元素，形成间隔。   |
| **排版**  | 通常用于样式化文本或小块内容。 | 用于构建页面的结构和布局。                      |
| **影响布局**   | 不影响页面的整体布局，主要用于内部样式和小的格式化。 | 影响整体布局，定义了页面的主要结构。|


# 空void 元素 (空void 元素是指没有内容的元素)

| 元素     | 描述                                      |
|----------|-------------------------------------------|
| `<area>` | 定义在图像映射中的可点击区域。              |
| `<base>` | 定义所有相对 URL 的基准 URL。              |
| `<br>`   | 插入换行符。                              |
| `<col>`  | 设定表格列的属性（在 `<colgroup>` 内使用）。 |
| `<command>` | 定义一个命令，用户可以点击执行。          |
| `<embed>` | 嵌入外部内容（如插件）。                   |
| `<hr>`   | 插入水平线。                              |
| `<img>`  | 嵌入图像。                                |
| `<input>`| 定义用户输入字段。                        |
| `<keygen>` | 生成密钥对（已弃用，不再推荐使用）。       |
| `<link>` | 定义与文档关联的资源（通常在 `<head>` 中使用）。 |
| `<meta>` | 定义文档的元数据。                        |
| `<param>` | 定义 `<object>` 元素的参数。              |
| `<source>` | 定义 `<video>` 和 `<audio>` 元素的资源。  |
| `<track>` | 定义 `<video>` 和 `<audio>` 元素的文本轨道（如字幕）。 |
| `<wbr>`  | 提示浏览器在单词内换行的建议位置。         |


## 行内元素
| 元素       | 描述                                          |
|------------|---------------------------------------------|
| `<a>`      | 定义超链接。                                  |
| `<b>`      | 使文本加粗，但没有语义。                      |
| `<br>`     | 插入换行符。                                  |
| `<cite>`   | 引用作品的标题，如书籍、电影等。              |
| `<code>`   | 显示计算机代码。                              |
| `<em>`     | 使文本斜体，并表示强调。                      |
| `<i>`      | 使文本斜体，但没有语义。                      |
| `<img>`    | 嵌入图像。                                    |
| `<input>`  | 定义输入字段。                                |
| `<kbd>`    | 定义用户输入的键盘操作。                      |
| `<label>`  | 定义输入控件的标签。                          |
| `<mark>`   | 标记文本以高亮显示。                          |
| `<q>`      | 定义短的内联引用。                            |
| `<s>`      | 表示文本已删除或不再适用。                    |
| `<samp>`   | 定义程序输出的样本。                          |
| `<small>`  | 使文本小号。                                  |
| `<span>`   | 定义行内样式或文档中的一部分。                |
| `<strong>` | 表示重要性或强调，通常显示为加粗。            |
| `<sub>`    | 定义下标文本。                                |
| `<sup>`    | 定义上标文本。                                |
| `<time>`   | 定义时间或日期。                              |
| `<u>`      | 使文本下划线。                                |
| `<var>`    | 定义变量。                                    |

## 块级元素
| 元素        | 描述                                      |
|-------------|-------------------------------------------|
| `<address>` | 定义文档的联系信息。                      |
| `<article>` | 定义独立的内容区域，如文章。              |
| `<aside>`   | 定义内容的侧边部分，通常用于附加信息。    |
| `<blockquote>` | 用于表示长引用。                        |
| `<body>`    | 定义 HTML 文档的主体部分。                |
| `<div>`     | 定义文档中的分区或块，通常用于布局。      |
| `<dl>`      | 定义描述列表。                            |
| `<dt>`      | 定义描述列表中的术语。                    |
| `<dd>`      | 定义描述列表中的描述。                    |
| `<fieldset>`| 用于分组表单控件。                        |
| `<figcaption>` | 定义 `<figure>` 元素的标题。              |
| `<figure>`  | 定义包含媒体或图像的独立内容。            |
| `<footer>`  | 定义文档或部分的页脚。                    |
| `<form>`    | 定义用户输入表单。                        |
| `<h1> - <h6>` | 定义标题，`<h1>` 为最高级，`<h6>` 为最低级。 |
| `<header>`  | 定义文档或部分的页眉。                    |
| `<hgroup>`  | 用于组合标题。                            |
| `<main>`    | 定义文档的主要内容。                      |
| `<nav>`     | 定义导航链接部分。                        |
| `<ol>`      | 定义有序列表。                            |
| `<p>`       | 定义段落。                                |
| `<pre>`     | 定义预格式化文本，保持空格和换行。        |
| `<section>` | 定义文档中的节或区域。                    |
| `<table>`   | 定义表格。                                |
| `<tfoot>`   | 定义表格的页脚部分。                      |
| `<thead>`   | 定义表格的头部。                          |
| `<tbody>`   | 定义表格的主体。                          |
| `<tr>`      | 定义表格中的行。                          |
| `<td>`      | 定义表格中的单元格。                      |
| `<th>`      | 定义表格中的表头单元格。                  |
| `<ul>`      | 定义无序列表。                            |
| `<li>`      | 定义列表中的项。                          |
| `<div>`     | 定义一个块级区域，通常用于布局。          |
| `<main>`    | 定义文档的主要内容。                      |
| `<details>` | 定义可折叠的详细内容。                    |
| `<summary>` | 定义 `<details>` 元素的可见标题。         |
