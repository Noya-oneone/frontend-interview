
# iframe

| 优点 | 描述 |
|-----|-----|
| **隔离内容** | `<iframe>` 可以将嵌入的页面与主页面隔离，减少了页面间的干扰。       |
| **实现嵌套功能** | 允许在一个页面中嵌入外部网页或应用，适用于显示广告、地图等内容。   |
| **增强模块化** | 可以将不同的功能模块（如视频播放器、地图、广告）放在独立的 iframe 中，便于管理和维护。|
| **独立的安全性** | 嵌套的 iframe 可以限制其对父页面的访问，增加安全性。     |
| **支持第三方服务**| 适合集成第三方服务和内容（如社交媒体、广告网络）。        |

| 缺点  | 描述|
|------|------|
| **性能问题**   | 多个 `<iframe>` 可能导致页面加载变慢，影响页面性能。     |
| **安全隐患**   | 不安全的外部内容可能引发 XSS 攻击或其他安全问题。        |
| **影响 SEO**   | 嵌入的内容通常不会被搜索引擎抓取或索引，可能影响 SEO 排名。        |
| **跨域问题**   | 如果 `<iframe>` 中的内容与主页面来自不同域，可能会遇到跨域访问限制。|
| **样式难以控制** | 控制嵌套页面的样式可能比较困难，需要额外的 CSS 和 JavaScript 管理。|
