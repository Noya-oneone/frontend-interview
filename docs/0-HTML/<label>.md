# <label>标签

| 特性| 描述 |
|----|------|
| **定义标签** | 为表单控件提供描述性的标签，帮助用户理解控件的作用。|
| **提高可用性** | 标签可以与表单控件绑定，使用户点击标签时，相关控件获得焦点，提升表单的可用性。|
| **语义化** | `<label>` 标签增加了表单控件的语义信息，有助于屏幕阅读器用户理解表单内容。|
| **绑定控件**   | 可以通过 `for` 属性将标签与控件绑定，绑定控件的 ID 作为 `for` 属性值。|
| **增强访问性** | 使表单更加无障碍，符合 Web 内容无障碍指南（WCAG）的要求。|
| **增强交互性** | 当点击 `<label>` 标签时，相应的控件会获得焦点或被选中，改进用户交互体验。


<label for="username">Username:</label>
<input type="text" id="username" name="username">

* 点击标签时，关联的表单控件会获得焦点，减少了用户的操作步骤。
