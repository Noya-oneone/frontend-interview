# CSS Grid 布局

## 一、基本概念

Grid 是二维布局系统，同时控制行和列。Flexbox 是一维的（行或列），Grid 适合整体页面布局。

```css
.container {
  display: grid;
}
```

| 概念 | 说明 |
|------|------|
| Grid Container | 设置 `display: grid` 的元素 |
| Grid Item | Container 的直接子元素 |
| Grid Line | 网格线（行线 + 列线） |
| Grid Track | 两条相邻网格线之间的空间（一行或一列） |
| Grid Cell | 行线和列线围成的最小单元 |
| Grid Area | 一个或多个 Cell 组成的矩形区域 |

## 二、容器属性

### 2.1 定义网格

```css
.container {
  /* 3 列：200px、自适应、200px */
  grid-template-columns: 200px 1fr 200px;

  /* 3 行：自动、200px、自动 */
  grid-template-rows: auto 200px auto;
}
```

**常用值：**

| 值 | 说明 |
|-----|------|
| `200px` | 固定宽度 |
| `1fr` | 剩余空间等分 |
| `auto` | 内容自适应 |
| `minmax(100px, 1fr)` | 最小 100px，最大 1fr |
| `repeat(3, 1fr)` | 重复 3 列等宽 |
| `repeat(auto-fill, minmax(200px, 1fr))` | 自动填充，响应式 |
| `repeat(auto-fit, minmax(200px, 1fr))` | 自动适配，空列会折叠 |

### 2.2 间距

```css
.container {
  gap: 10px;              /* 行列间距相同 */
  row-gap: 10px;          /* 行间距 */
  column-gap: 20px;       /* 列间距 */
}
```

### 2.3 对齐

```css
.container {
  /* 所有 item 在 cell 内的水平对齐 */
  justify-items: start | end | center | stretch;

  /* 所有 item 在 cell 内的垂直对齐 */
  align-items: start | end | center | stretch;

  /* 整个网格在容器内的水平对齐 */
  justify-content: start | end | center | stretch | space-between | space-around | space-evenly;

  /* 整个网格在容器内的垂直对齐 */
  align-content: start | end | center | stretch | space-between | space-around | space-evenly;
}
```

### 2.4 区域模板

```css
.container {
  grid-template-areas:
    "header header header"
    "sidebar main aside"
    "footer footer footer";
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.aside   { grid-area: aside; }
.footer  { grid-area: footer; }
```

## 三、子项属性

### 3.1 定位

```css
.item {
  grid-column: 1 / 3;     /* 从第 1 条列线到第 3 条列线（跨 2 列） */
  grid-row: 1 / 2;        /* 从第 1 条行线到第 2 条行线 */
}

/* 简写 */
.item {
  grid-column: 1 / span 2; /* 从第 1 列开始，跨 2 列 */
}
```

### 3.2 单个 item 对齐

```css
.item {
  justify-self: start | end | center | stretch; /* 水平 */
  align-self: start | end | center | stretch;   /* 垂直 */
}
```

## 四、Grid vs Flexbox

| 维度 | Flexbox | Grid |
|------|---------|------|
| 方向 | 一维（行或列） | 二维（行和列同时） |
| 适用 | 导航栏、按钮组、单行/列排列 | 页面布局、卡片网格、仪表盘 |
| 对齐 | 主轴 + 交叉轴 | 行轴 + 列轴 |
| 顺序 | `order` 属性 | 网格线定位 |
| 嵌套 | 常嵌套使用 | 通常一层搞定 |

**口诀：** 组件内部用 Flex，页面整体用 Grid。

## 五、高频面试题

### Q1: auto-fill vs auto-fit 区别？

```css
/* auto-fill：有空间就创建空列 */
grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));

/* auto-fit：空列会折叠为 0，已有列拉伸填满 */
grid-template-columns: repeat(auto-fit, minmax(100px, 1fr));
```

**区别：** 当子项不够填满一行时，auto-fill 保留空列占位，auto-fit 让已有列拉伸填满。

### Q2: 用 Grid 实现响应式卡片布局？

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
```

一行代码实现：宽度 ≥ 250px 自动换行，等宽排列。

### Q3: 用 Grid 实现经典三栏布局？

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "left   main   right"
    "footer footer footer";
  min-height: 100vh;
}
```
