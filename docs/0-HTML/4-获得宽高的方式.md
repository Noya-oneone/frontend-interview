# 获得宽高的方式

## 元素尺寸三件套

| 属性 | 包含范围 | 典型用途 |
|--|--|--|
| `clientWidth / clientHeight` | content + padding，**不含**边框和滚动条 | 可视内容区尺寸 |
| `offsetWidth / offsetHeight` | content + padding + border + 滚动条，**不含** margin | 元素布局占位尺寸 |
| `scrollWidth / scrollHeight` | 内容总尺寸，**包括溢出**不可见的部分 | 判断是否可滚动、是否滚动到底 |

```ts
// 判断是否滚动到底部（±1 容差处理小数像素）
const isBottom = el.scrollTop + el.clientHeight >= el.scrollHeight - 1;
```

## getBoundingClientRect()

返回元素相对于`视口`的位置与尺寸（`x / y / top / left / right / bottom / width / height`）。

```ts
const rect = el.getBoundingClientRect();
rect.width;   // border-box 尺寸，且是可能带小数的精确值
rect.top;     // 相对视口顶部的距离（随滚动变化）
```

* 与 `offsetWidth` 的关键区别：**rect 会受 CSS `transform: scale()` 影响**，`offsetWidth` 返回的是布局尺寸、不受 transform 影响；rect 返回小数，offset 系列取整。
* `getClientRects()` 返回所有盒子的矩形集合，适用于跨行的行内元素（一行一个矩形）。

## getComputedStyle()

```ts
const style = getComputedStyle(el);
style.width;   // 如 "320.5px"，字符串，需 parseFloat
```

返回最终计算样式（样式表 + 内联 + 继承合成的结果），能拿到未显式设置的属性值；`display: none` 的元素用 offset/client 读到的是 0，computed style 仍可读到声明值。

## 窗口 / 视口尺寸

| 属性 | 含义 |
|--|--|
| `window.innerWidth / innerHeight` | 视口尺寸，**含滚动条** |
| `document.documentElement.clientWidth / clientHeight` | 视口尺寸，**不含滚动条** |
| `window.outerWidth / outerHeight` | 浏览器窗口整体尺寸（含工具栏、边框） |

## 监听尺寸变化：ResizeObserver

```ts
const ro = new ResizeObserver((entries) => {
  for (const entry of entries) {
    console.log(entry.contentRect.width, entry.contentRect.height);
  }
});
ro.observe(el);
```

* `ResizeObserver` 专门监听`元素`尺寸变化（`window.onresize` 只能监听窗口）。
* `MutationObserver` 监听的是 **DOM 结构 / 属性变化**，并不能直接监听尺寸变化，不要混用。

## 常见考点

* **读取这些属性会触发什么？** 会`强制同步布局（reflow）`。在循环里交替「读布局属性 + 写样式」会造成布局抖动（layout thrashing），应先批量读、再批量写，或用 `requestAnimationFrame`。
* **`offsetWidth` vs `getBoundingClientRect().width`？** 前者整数、不受 transform 影响；后者小数、受 transform 缩放影响。
* **如何拿到隐藏元素（`display:none`）的尺寸？** offset/client 均为 0；可临时改为 `visibility: hidden; display: block` 测量，或改用 `position: absolute` 移出视野。
