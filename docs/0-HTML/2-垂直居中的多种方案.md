# 垂直居中的多种方案

## 一、Flexbox（最推荐）

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

**适用：** 几乎所有场景。一行搞定，支持不定宽高。

---

## 二、Grid

```css
.parent {
  display: grid;
  place-items: center;
}
```

**适用：** 同 Flexbox，更简洁。`place-items` 是 `align-items` + `justify-items` 简写。

---

## 三、absolute + transform

```css
.parent { position: relative; }
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

**适用：** 不定宽高。`translate(-50%, -50%)` 基于自身尺寸偏移。

---

## 四、absolute + margin: auto

```css
.parent { position: relative; }
.child {
  position: absolute;
  top: 0; right: 0; bottom: 0; left: 0;
  margin: auto;
  width: 200px;
  height: 100px;
}
```

**适用：** 已知宽高。四个方向设为 0 + `margin: auto` 让浏览器自动分配边距。

---

## 五、absolute + 负 margin

```css
.parent { position: relative; }
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 200px;
  height: 100px;
  margin-top: -50px;   /* 高度的一半 */
  margin-left: -100px; /* 宽度的一半 */
}
```

**适用：** 已知宽高。需要手动计算，不如 transform 灵活。

---

## 六、line-height（纯文本）

```css
.parent {
  height: 100px;
  line-height: 100px;
  text-align: center;
}
```

**适用：** 单行文本垂直居中。`line-height` = `height` 即可。多行无效。

---

## 七、table-cell

```css
.parent {
  display: table-cell;
  vertical-align: middle;
  text-align: center;
}
```

**适用：** 兼容老浏览器（IE8+）。现代项目不推荐。

---

## 八、对比总结

| 方案 | 定宽高 | 不定宽高 | 多行文本 | 兼容性 | 推荐度 |
|------|--------|---------|---------|--------|--------|
| Flexbox | ✅ | ✅ | ✅ | IE10+ | ⭐⭐⭐⭐⭐ |
| Grid | ✅ | ✅ | ✅ | IE 不支持 | ⭐⭐⭐⭐⭐ |
| absolute + transform | ✅ | ✅ | ✅ | IE9+ | ⭐⭐⭐⭐ |
| absolute + margin:auto | ✅ | ❌ | ✅ | IE8+ | ⭐⭐⭐ |
| absolute + 负margin | ✅ | ❌ | ✅ | IE6+ | ⭐⭐ |
| line-height | ✅（需定高） | ❌ | ❌ | 全兼容 | ⭐⭐ |
| table-cell | ✅ | ✅ | ✅ | IE8+ | ⭐⭐ |

---

## 九、高频面试回答模板

> **面试官：** 说说 CSS 垂直居中的方案？

**回答：**
1. 首选 **Flexbox**（`display: flex; justify-content: center; align-items: center`），支持不定宽高，兼容性好
2. Grid 更简洁（`place-items: center`）
3. 不定宽高也可以用 **absolute + transform**
4. 已知宽高用 **absolute + margin: auto**（四方向 0）
5. 单行文本用 **line-height = height**
6. 老项目兼容 IE8 用 **table-cell**
