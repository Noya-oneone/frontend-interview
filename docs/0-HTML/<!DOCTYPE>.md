# <!DOCTYPE>

严格模式和混杂模式的区分方法，他们的意义是什么？Doctype 作用


## 定义

* <!DOCTYPE> 声明用于定义 HTML 文档的类型和版本，`告诉浏览器以什么标准来解析和渲染页面`

| 特性 | 描述 |
|-|-|
| **定义** | `<!DOCTYPE>` 是文档类型声明，用于指定 HTML 或 XHTML 文档的类型和版本。|
| **作用**| 确保浏览器使用正确的渲染模式来解析和显示网页。|
| **标准模式** | `<!DOCTYPE html>` 使浏览器以标准模式渲染页面，遵循最新的 HTML5 标准。|
| **混杂模式** | 没有 `<!DOCTYPE>` 声明，或声明不完整时，浏览器可能进入混杂模式或怪异模式，渲染效果可能不一致。 |
| **历史背景** | 不同的 HTML 版本和 XHTML 版本有不同的 `<!DOCTYPE>` 声明。|
| **HTML5** | `<!DOCTYPE html>` 是 HTML5 的标准声明，简化了文档类型定义。|
| **XHTML 1.0** | `<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">` |
| **HTML 4.01** | `<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">`|
| **作用总结** | 帮助浏览器确定文档的解析模式，确保网页在不同浏览器中的一致性和标准化渲染。|


## 严格模式与混杂模式

| 特性         | 严格模式（Standards Mode） | 混杂模式（Quirks Mode）            |
|--|--|--|
| **定义**     | 遵循最新的 W3C 标准。                  | 兼容旧版浏览器和旧网页行为。       |
| **触发条件** | 有有效的 `<!DOCTYPE>` 声明。           | 没有或无效的 `<!DOCTYPE>` 声明。   |
| **渲染规则** | 按最新标准渲染。                       | 模拟旧版浏览器的渲染行为。         |
| **兼容性**   | 一致渲染，确保跨浏览器兼容性。          | 可能导致不同浏览器表现不一致。     |
| **意义**     | 确保现代网页的一致性和标准化。          | 支持遗留系统和旧网站。             |

## HTML VS XHTML

* 定义: HTML 是基础的标记语言，用于网页的结构和内容。XHTML 是 HTML 的 XML 版本，更加严格。
* XHTML 作为 XML 的一种应用，强制要求严格的语法规则，使得标记语言更加一致和规范，减少了因浏览器兼容性问题导致的页面渲染差异。

| 特性         | HTML5 | XHTML 1.0 |
|--|--|--|
| **定义**| HTML5 是最新版本的 HTML 标准。 | XHTML 1.0 是 W3C 推出的 XML 版本的 HTML 标准。 |
| **兼容性**   | 兼容所有现代浏览器。 | 兼容部分浏览器。 |
| **意义**     | 最新 HTML5 标准，更加规范化。 | 兼容性更好，适用于 XML 格式。 |
