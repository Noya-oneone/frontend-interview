# 状态码

## 1xx 信息性状态码
* 100 Continue
    * `请求者应当继续提出请求`，服务器返回此代码表示已收到请求的第一部分，客户端应继续发送其余的请求。
* 101 Switching Protocols
    * `服务器切换协议`，服务器将遵从客户的请求转换到另外一种协议。
* 102 Processing
    * `服务器处理请求`，服务器已收到请求，但未完成处理。

## 2xx 成功状态码
* 200 OK
    * `204` 表示服务器成功处理了请求，但没有返回任何内容（删除更新操作）
    * `206`：分块传输，用于断点续传，返回部分内容。

## 3xx 重定向状态码
* 301 Moved Permanently
    * 状态码表示`请求的资源已被永久移动到新位置`，服务器会返回新的位置（通常在 Location 响应头中）。
    * 浏览器会自动将请求重定向到新的位置。
    * 这在 `SEO（搜索引擎优化）`中非常重要，因为它告诉搜索引擎`资源的新位置`，以便搜索引擎可以更新其索引。
* 302 Found
    * 临时重定向： `未登录用户跳转到登录页面`
    * 服务器返回此状态码表示请求的资源临时从不同的 URI 响应请求。
    * 这在用户刚刚登录网站，但还没有完成登录操作时非常有用。
    * 浏览器会自动将请求重定向到新的位置。
* 304 Not Modified
    * 状态码表示`资源未被修改`，服务器返回此状态码时，不会返回任何资源内容。
    * 浏览器会继续使用所保存的缓存数据。
    * 这在缓存数据有效期内，可以节省带宽和时间。

## 4xx 客户端错误状态码
* 400 Bad Request
    * `参数有问题`，比如缺少参数、参数类型错误、参数值超出范围等。
* 401 Unauthorized
    * `未登录`或`未授权`，服务器要求用户进行身份验证。
* 403 Forbidden
    * `禁止访问`，服务器拒绝访问用户请求的资源。 （内网IP）
* 404 Not Found
    * `请求的资源不存在`，服务器无法找到请求的资源。
* 408 Request Timeout：
    * 客户端`在规定的时间内没有发送完整的请求`，可能由于`丢包`导致部分数据未能到达服务器。

## 5xx 服务器错误状态码
* 500 Internal Server Error
    * `服务器内部错误`，服务器遇到错误，无法完成请求。
    * 服务器在处理请求时遇到未预料的情况，可能由于`丢包`导致服务器在处理请求过程中遇到问题。
* 502 Bad Gateway
    * 服务器作为网关或代理时`从上游服务器`接收到无效响应，可能由于网络丢包导致的响应不完整或错误。
* 503 Service Unavailable
    * `服务器超负载或维护`，服务器当前无法处理请求，过载或维护。
    * Nginx 转发服务器停机，维护中的时候，升级的时候
* 504 Gateway Timeout
    * 网关超时，服务器等待客户端发送请求，超时后，服务器返回超时错误。
