# 网络协议概览

## 分层与常见协议

| 层（TCP/IP 模型） | 常见协议 | 说明 |
|--|--|--|
| 应用层 | HTTP/HTTPS、DNS、WebSocket、SMTP/IMAP/POP3、FTP、gRPC | 面向业务语义 |
| 传输层 | TCP、UDP（QUIC 构建其上） | 端到端传输，见 [TCP & UDP & QUIC](./6-%20传输层%20TCP%20&%20UDP%20&%20QUIC.md) |
| 网络层 | IP（v4/v6）、ICMP | 寻址与路由（ping 用的就是 ICMP） |
| 链路/物理层 | Ethernet、Wi-Fi | 相邻节点间传输 |

完整七层对照见 [OSI 七层模型](./OSI7层模型.md)。

## DNS 协议（重点）

* 作用：`把域名解析为 IP 地址`。默认走 `UDP 53 端口`（响应过大或区域传输用 TCP；新一代 DoH/DoT 走 HTTPS/TLS 加密查询）。
* 查询链路（面试常考）：浏览器缓存 → 系统缓存 / hosts → 本地 DNS（运营商，`递归查询`）→ 根服务器 → 顶级域（.com）→ 权威服务器（`迭代查询`），结果逐级缓存（TTL 控制）。
* 前端相关优化：`dns-prefetch` 提前解析第三方域名；减少页面涉及的域名数。

```html
<link rel="dns-prefetch" href="https://cdn.example.com" />
```

## 排查工具速查

| 工具 | 用途 |
|--|--|
| `ping` | 连通性与往返延迟（ICMP） |
| `traceroute / tracert` | 路径上每一跳 |
| `nslookup / dig` | DNS 解析结果排查 |
| `curl -v` | 查看完整请求/响应头、TLS 握手 |
| Wireshark / Charles | 抓包分析 |
