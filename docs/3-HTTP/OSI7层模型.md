# OSI 七层模型

## 七层与常见协议

| 层 | 职责 | 典型协议 / 例子 |
|--|--|--|
| 7 应用层 | 面向应用的语义 | HTTP、DNS、SMTP、FTP、WebSocket |
| 6 表示层 | 编码、加密、压缩 | TLS/SSL（加密）、字符集转换、JPEG |
| 5 会话层 | 建立/管理会话 | RPC 会话、SOCKS |
| 4 传输层 | 端到端传输、端口 | `TCP、UDP`（QUIC 构建在 UDP 上） |
| 3 网络层 | 寻址与路由 | `IP`、ICMP（ping）、路由器 |
| 2 数据链路层 | 相邻节点成帧传输、MAC 地址 | Ethernet、Wi-Fi（802.11）、交换机 |
| 1 物理层 | 比特流的物理传输 | 光纤、网线、无线电 |

记忆口诀（自下而上）：`物数网传会表应`。

## OSI 与 TCP/IP 四层对照（面试常画）

| TCP/IP 四层 | 对应 OSI | 说明 |
|--|--|--|
| 应用层 | 应用 + 表示 + 会话 | HTTP、TLS 实践中都算在这层 |
| 传输层 | 传输层 | TCP / UDP |
| 网络层 | 网络层 | IP |
| 网络接口层 | 数据链路 + 物理 | Ethernet |

OSI 是`教学参考模型`，实际互联网按 TCP/IP 模型实现 —— 回答「HTTPS 的 TLS 在哪层」时可答：OSI 视角在表示/会话层，TCP/IP 视角在应用层与传输层之间的安全层。

## 常见考点

* **每层的数据单元**：应用层报文（message）→ 传输层段（segment）→ 网络层包（packet）→ 链路层帧（frame）→ 物理层比特。
* **交换机和路由器分别工作在哪层？** 交换机在数据链路层（看 MAC），路由器在网络层（看 IP）。
