## 垫片Shimming
* 垫片（shim）是指在运行时提供某些功能的 JavaScript 代码。
* 处理全局依赖、兼容老旧代码、提供 polyfill、模拟浏览器 API 等。
  * `处理全局依赖`：一些老旧的 JavaScript 库依赖于全局变量，如 jQuery 依赖于 $ 或 window.jQuery，这些库在模块化环境中可能无法正常工作。
  * `兼容老旧代码`：在使用现代打包工具（如 Webpack）时，有时需要将不支持模块化的老旧代码集成到现代代码中，Shimming 可以帮助解决这些兼容性问题。
  * `提供 polyfill`：一些浏览器 API 在某些版本的浏览器中可能不存在，Shimming 可以提供这些 API 的 polyfill。
* 垫片的实现方式有两种：
  * 全局变量：将垫片代码直接注入到全局作用域，通过全局变量调用。
  * 模块化：将垫片代码作为模块导出，通过模块导入。

```javascript
const webpack = require('webpack');

// 方法一：配置ProvidePlugin
//  ProvidePlugin 是 Webpack 内置的一个插件，用来自动加载模块，而不需要在每个文件中手动 import 或 require。
module.exports = {
  // 其他配置
  plugins: [
    new webpack.ProvidePlugin({
      $: 'jquery',
      jQuery: 'jquery',
      _: 'lodash',
    }),
  ],
};

// 方法二：在其他模块中使用
module.exports = {
  externals: {
    jquery: 'jQuery', // 假设在全局环境中已经有了 jQuery
  },
};

// 方法三：imports-loader 允许你在模块中显式引入全局变量。
module.exports = {
  module: {
    rules: [
      {
        test: require.resolve('some-global-lib'),
        loader: 'imports-loader',
        options: {
          additionalCode: 'var jQuery = require("jquery");',
        },
      },
    ],
  },
};

```
