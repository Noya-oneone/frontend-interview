# 工程化

| **方面**             | **描述**                                           |
|----------------------|----------------------------------------------------|
| **模块化**           | 将前端代码分成独立的模块，提高代码的重用性和维护性 |
| **自动化**           | 使用工具自动化构建、测试、部署等流程               |
| **构建工具**         | 使用如Webpack、Vite等工具进行资源打包和优化       |
| **代码规范**         | 制定并遵循代码风格和规范，提高代码一致性           |
| **版本控制**         | 使用Git等工具进行版本管理，确保代码的版本可追溯   |
| **测试**             | 引入单元测试、集成测试等，确保代码质量             |
| **持续集成/持续部署** | 自动化集成和部署流程，提升开发效率和交付质量       |
| **文档**             | 编写和维护项目文档，帮助团队成员快速了解项目       |


| **方法**            | **描述**                                             |
|---------------------|------------------------------------------------------|
| **使用`Object.freeze`** | 将对象冻结，防止其属性被修改或添加。适用于静态数据。 |
| **使用`Object.seal`** | 将对象密封，只允许修改现有属性的值，但不能添加或删除属性。 |
| **私有变量**       | 使用闭包或`WeakMap`实现私有变量，防止外部直接访问。     | 
| **只读属性**       | 定义只读属性，防止对属性的修改。                      |
| **数据封装**       | 通过封装数据和方法，避免直接暴露内部数据结构。        |
| **严格模式**       | 使用JavaScript严格模式 (`'use strict';`) 避免一些常见的错误。 |




## CI/CD

* **CI/CD：** Jenkins、Travis CI、GitLab CI/CD、Docker容器化
* **CI/CD 流程**:代码管理、自动化构建、单元测试、集成测试、静态代码分析、打包与部署、自动化部署
* **CI/CD 工具：**
  * `版本管理`：Git、SVN
  * `构建工具`： Jenkins、阿里云、Gitlab
  * `测试工具`：Jest、Mocha、Karma、Nightwatch.js
  * `静态代码分析工具`： ESLint、Stylelint
  * `容器化工具`：Docker、Kubernetes
  * `部署工具`：Jenkins、GitLab CI/CD、Travis CI、阿里云、AWS

* **CI/CD 配置：**
  * `构建环境配置`：
      * Node.js版本
      * npm版本
      * yarn版本
      * 缓存目录
      * 构建命令
      * 测试命令
      * 代码检查命令
      * 打包命令
      * 部署命令
  * `构建脚本`：构建脚本可以帮助我们自动化执行构建、测试、代码检查、打包、部署等流程，提升开发效率
  * `CI/CD 文件`： 包括Jenkinsfile、.travis.yml、.gitlab-ci.yml、Dockerfile、docker-compose.yml等文件，这些文件定义了CI/CD的各个阶段的任务，可以帮助我们更加细粒度地控制CI/CD流程、TF脚本
      * Jenkinsfile // 定义Jenkins流水线
      * .travis.yml // 定义Travis CI流水线
      * .gitlab-ci.yml // 定义Gitlab CI流水线
      * Dockerfile // 定义Dockerfile
      * docker-compose.yml // 定义docker-compose.yml文件

### Docker

* Docker: 容器是一个标准化的软件单元，它将代码及其所有依赖关系打包，以便应用程序从一个计算环境可靠快速地运行到另一个计算环境。Docker容器镜像是一个轻量的独立的可执行的软件包。包含程序运行的时候所需的一切：代码，运行时间，系统工具，系统库和设置。
* Docker架构 (Docker引擎、镜像、容器、仓库）
* Docker基本命令
  * 镜像操作（搜索镜像、拉取镜像、构建镜像、推送镜像）
  * 容器操作（创建容器、启动容器、停止容器、删除容器）
  * 网络操作（创建网络、连接容器到网络、断开容器与网络的连接、数据管理、数据卷、挂载主机目录）
