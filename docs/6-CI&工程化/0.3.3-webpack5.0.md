# webpack5.0

### webpack 5

* **Webpack 5**
* 引入了一个新的功能叫做模**块联邦**（Module Federation）。这是一种 JavaScript 微前端解决方案，允许一个 JavaScript 应用程序动态地运行另一个应用程序的代码。`ModuleFederationPlugin`
* **共享模块**：可以在不同的 Webpack 构建之间共享模块，无需复制和粘贴代码。
* **动态加载**：可以在运行时动态地加载另一个应用程序的代码，而无需提前打包到一起。
* **独立部署**：每个应用程序可以独立开发和部署，无需协调和等待其他应用程序。

* 1、 `持久缓存机制`：Webpack 5 引入了持久缓存机制，可以显著减少构建时间。缓存数据被存储在磁盘上，减少了重复构建的时间。

```javascript
// 在 webpack.config.js 中启用持久缓存
module.exports = {
  cache: {
    type: 'filesystem',
  },
};
```

* 2、通过改进代码分割策略，Webpack 5 提高了拆分块的性能和灵活性。
自动拆分和按需加载更高效，减少了冗余代码和文件大小。

* 3、`模块联邦（Module Federation）`：允许多个 Webpack 构建之间共享模块，使得构建微前端架构变得更简单。可以实现动态加载和共享不同应用的代码。

```javascript 
// 在 webpack.config.js 中配置模块联邦
const ModuleFederationPlugin = require('webpack/lib/container/ModuleFederationPlugin');

module.exports = {
  plugins: [
  new ModuleFederationPlugin({
    name: 'my_app',
    filename: 'remoteEntry.js',
    exposes: {
  './Button': './src/Button',
    },
    shared: ['react', 'react-dom'],
  }),
  ],
};
```

新增了对 asset 模块类型的支持，简化了处理静态资源（如图片和字体）的配置。
```javascript
    // 在 webpack.config.js 中配置资源模块
    module.exports = {
    module: {
    rules: [
    {
    test: /\.(png|svg|jpg|jpeg|gif)$/i,
    type: 'asset/resource',
    },
    ],
    },
    };
```
