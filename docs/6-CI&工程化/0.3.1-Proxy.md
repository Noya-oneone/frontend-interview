# Proxy
* 在使用 Webpack 开发环境时，如果前端项目和后端 API 服务器在不同的域名或端口下运行，可能会遇到跨域问题。
 为了解决这个问题，Webpack 提供了 devServer.proxy 配置选项，可以将特定的请求代理到后端服务器，从而绕过跨域限制。

## 实现
首先，我们需要在 Webpack 配置文件中配置 Proxy：

```javascript
module.exports = {
  //...
  devServer: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
        pathRewrite: {
          '^/api': ''
        }
      }
    }
  }
}
```


然后，我们在前端代码中，通过 `axios` 发送请求时，需要将请求路径改为 `/api` 开头：

```javascript
axios.get('/api/users')
```

这样，前端代码就能正确地发送请求到后端 API 服务器。

## 注意事项

- 由于 Proxy 存在安全隐患，所以在生产环境中不建议使用。
- 由于 Proxy 存在性能损耗，所以在开发环境中使用时，建议关闭 Webpack 的热更新功能。
