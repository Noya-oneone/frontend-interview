# 快照测试 JEST

* `快照测试（Snapshot Testing）` 是一种用于检测 UI 组件或函数输出是否发生变化的测试方法。其工作原理是：
    * 在第一次运行测试时，将组件或函数的输出生成快照（通常是 JSON 格式），并保存到磁盘。
    * 在后续测试中，框架会将新的输出与之前的快照进行对比。如果有差异，测试会失败，提示输出发生了变化。
## 优点：
    快速检测 UI 改动：特别适用于 React 组件，确保组件输出符合预期。
    自动化对比：无需手动检查，节省时间。
## 缺点：
    误报风险：频繁的 UI 变化可能导致快照需要频繁更新，容易忽视实际错误。
    常用工具：Jest

## 实现

1. 安装 Jest
```bash
npm install --save-dev jest
```
2. 创建测试文件
``` bash
touch __tests__/snapshot.test.js
```
3. 编写测试用例
``` jsx
import React from'react';
import renderer from'react-test-renderer';
import App from '../App';

test('App component should render correctly', () => {
  const component = renderer.create(<App />);
  let tree = component.toJSON();
  expect(tree).toMatchSnapshot();
});
```
4. 运行测试
``` bash
npm test
```
5. 快照文件生成
``` bash
/__snapshots__/snapshot.test.js.snap
```
