
# 测试

## 分类
* `单元测试Unit Testing` ：单元测试是对软件中的最小可测试单元进行检查和验证。对于函数式编程，一个单元就是一个函数，对于面向对象编程，一个单元通常是类中的一个方法  
* `集成测试Integration Testing`：集成测试是在单元测试的基础上，测试多个组件或模块之间的交互
* `端到端测试End-to-End Testing`：端到端测试是一种全面的测试，它测试一个系统的工作流程是否如预期那样工作，包括所有的组件、数据库、网络等。端到端测试主要用于确认整个系统是否达到了设计的要求

## 框架
* `Jest`： **unit test**、 **integration test**
* `Puppeteer（Headless Browser）`：**E2E测试** Puppeteer 是 Google 开发的一个 Node.js 库，提供了一套 API 来控制无头浏览器（如 Chrome 或 Firefox）。它可以用于页面爬取、页面截图、PDF 生成、端到端测试等。Puppeteer 适用于需要进行浏览器自动化操作或端到端测试的场景。
* `Mocha`：行灵活配置的单元测试和集成测试的场景
