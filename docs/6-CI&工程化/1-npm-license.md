# npm包里面有哪些license是允许被商用的？

| 许可证类型 | 允许商用 | 主要限制 |
|------------|----------|----------|
| MIT        | ✅       | 需要保留原作者的版权声明和许可证 |
| Apache 2.0 | ✅       | 需要保留版权声明、专利条款；修改后的代码必须注明变更 |
| BSD 2-Clause ("Simplified") | ✅ | 需要保留版权声明和免责声明 |
| BSD 3-Clause ("New" or "Revised") | ✅ | 不能使用原项目作者或贡献者名义推广衍生产品 |
| ISC        | ✅       | 类似于 MIT，要求保留版权声明 |
| MPL 2.0    | ✅       | 允许商用，但修改后的文件需开放源码 |
| Unlicense  | ✅       | 公共领域，没有任何限制 |
