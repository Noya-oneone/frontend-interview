# webpack 生命周期

## 生命周期
| 阶段 | 钩子名称| 描述   |
|----|-----||
| **初始化**   | `beforeRun`、`run`、`compile` | 在开始编译之前和开始编译时触发。 |
| **编译** | `compilation`、`compilations` | 在每次编译时触发，提供编译相关信息。 |
| **处理插件** | `emit`、`afterEmit` | 在生成文件之前和之后触发。   |
| **生成** | `afterCompile`、`done`  | 编译完成后生成输出文件，标志编译结束。   |
| **输出** | `afterEmit` | 文件写入输出目录后触发。 |
