# webpack tapable

* tapable 是 webpack 的一个`核心模块`，它提供了许多可扩展的功能，包括插件系统、钩子系统等。
* tapable 的作用主要是提供插件系统和钩子系统,实现 webpack 的功能扩展

## 4. tapable 的核心类？
- Compiler：webpack 的核心类，负责编译整个项目。
- Compilation：webpack 的编译类，负责编译每个模块。
- Plugin：webpack 的插件类，负责实现功能扩展。
- Tapable：tapable 的核心类，提供插件系统和钩子系统。
    - Hook：tapable 的钩子类，提供钩子系统。

### tapable 9 个 钩子Hook

| 钩子类型| 介绍   | 使用场景|
|---------|--------|-|
| `SyncHook`  | 同步执行，`无返回值`，用于`顺序执行一系列任务` | 需要依次执行一系列操作且不需要等待异步结果时使用 |
| `SyncBailHook`  | 同步执行，任一事件函数有返回值时跳过剩下的任务 | 需要中途退出执行链条时使用  |
| `SyncWaterfallHook` | 同步执行，上一个事件函数的返回值可以传给下一个事件函数 | 需要传递和处理数据链时使用  |
| `SyncLoopHook`  | 同步执行，事件函数返回值为 `true` 时会重复执行当前任务，直到返回 `undefined`   | 需要重复执行某个操作直到某个条件满足时使用 |
| `AsyncParallelHook` | 异步执行（并行），所有事件函数并行执行，`无返回值`   | 需要并行执行异步操作时使用  |
| `AsyncParallelBailHook` | 异步执行（并行），任一事件函数有返回值时跳过剩下的任务 | 需要并行执行异步操作且中途退出时使用|
| `AsyncSeriesHook`   | 异步执行（串行），事件函数按顺序依次执行，`无返回值` | 需要按顺序执行异步操作时使用|
| `AsyncSeriesBailHook`   | 异步执行（串行），任一事件函数有返回值时跳过剩下的任务 | 需要按顺序执行异步操作且中途退出时使用  |
| `AsyncSeriesWaterfallHook`  | 异步执行（串行），上一个事件函数的返回值可以传给下一个事件函数 | 需要按顺序传递和处理数据链的异步操作时使用 |
