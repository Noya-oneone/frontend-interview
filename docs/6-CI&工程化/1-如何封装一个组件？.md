# 如何封装一个组件？

## 怎么防止别人串改你封装组件的数据

| 方法  | 适用场景| 具体情况|
|--|--|---|
| **Object.freeze** | 数据`对象在初始化后不再需要修改`。<br>只读配置对象或常量。  | 冻结对象，使其不可修改（不能添加、删除或修改属性）。|
| **私有字段（ES2022+）** | 使用类封装数据。| 在类中使用私有字段（以 `#` 开头）来保护数据，这些字段不会被外部访问。 |
| **闭包保护数据** | 函数式编程风格。<br>需要创建多个具有独立状态的对象实例。 | 使用闭包将数据封装在函数作用域内，外部无法直接访问或修改数据。 |
| **不可变数据结构**| 需要`频繁操作`或`传递数据但不希望数据被修改`。 | 利用不可变数据结构库（如 Immutable.js）来保证数据不可修改。 |
| **Object.defineProperty** | 需要更精细地控制对象属性的可写性和可配置性。<br>在不支持私有字段的旧版本 JavaScript 环境中使用。 | 使用 `Object.defineProperty` 设置属性为只读。  |
| **Proxy** | 需要动态拦截和定义对对象基本操作的自定义行为。 | 利用 `Proxy` 拦截并控制对对象的访问。 |


* 使用 `Object.freeze`
```javascript
class MyComponent {
  constructor(data) {
 this._data = Object.freeze(data);
  }

  getData() {
 return this._data;
  }
}

const component = new MyComponent({ key: 'value' });
console.log(component.getData()); // { key: 'value' }
```

* 在类中使用私有字段（```以 # 开头```）来保护数据，这些字段不会被外部访问
```javascript
class MyComponent {
  #data;

  constructor(data) {
 this.#data = data;
  }

  getData() {
 return [...this.#data];
  }

  setData(newData) {
 if (Array.isArray(newData)) {
this.#data = [...newData];
 }
  }
}

const component = new MyComponent([1, 2, 3]);
console.log(component.getData()); // [1, 2, 3]
```
* 通过闭包保护数据: 使用闭包可以将数据封装在函数作用域内，外部无法直接访问或修改数据
```javascript
function createCounter() {
  let count = 0;

  return {
 increment() {
count += 1;
 },
 getCount() {
return count;
 }
  };
}

const counter = createCounter();
counter.increment();
console.log(counter.getCount()); // 1
```

* 使用不可变数据结构利用不可变数据结构库（如 Immutable.js）
`List 、 Stack 、 Map 、 OrderedMap 、 Set 、 OrderedSet和Record `
| 数据类型      | 简介     | 特点    |
|----|----|--｜
| **List**      | 有序的可重复元素集合，类似于数组。   | 支持快速索引、插入和删除操作；元素按插入顺序排列。      |
| **Stack**     | 一种后进先出（LIFO）的数据结构。     | 只允许在一端（称为栈顶）进行插入和删除操作。     |
| **Map**| 键值对集合，键是唯一的。      | 允许任意类型的键；键值对按插入顺序排列。  |
| **OrderedMap**| 键值对集合，保持键的插入顺序。| 具有 Map 的所有特性，并且键值对按插入顺序保持有序。     |
| **Set**| 无序的唯一元素集合。   | 不允许重复元素；元素按插入顺序排列。      |
| **OrderedSet**| 保持插入顺序的唯一元素集合。  | 具有 Set 的所有特性，并且元素按插入顺序保持有序。|
| **Record**    | 描述固定结构的键值对集合，类似于普通对象，但不可变且有更高效的性能。     | 键是字符串或 Symbol，值可以是任意类型；提供更好的性能和内存使用效率；用于定义不可变的、固定结构的数据。   |



* 使用 `Object.defineProperty` 设置属性为只读
```javascript
 class MyComponent {
 constructor(data) {
  Object.defineProperty(this, '_data', {
  value: [...data],
  writable: false,
  configurable: false
  });
 }

 getData() {
  return [...this._data];
 }
 }


const component = new MyComponent([1, 2, 3]);
console.log(component.getData()); // [1, 2, 3]
```

* 利用 `Proxy ` 拦截并控制对对象的访问 (使用 getters 和 setters、订阅发布者模式)
```javascript
class MyComponent {
  constructor(data) {
 const handler = {
get(target, prop) {
  if (prop === 'getData') {
 return () => [...target._data];
  }
  return target[prop];
},
set(target, prop, value) {
  if (prop === '_data' && Array.isArray(value)) {
 target[prop] = [...value];
 return true;
  }
  return false;
}
 };

 this._data = [...data];
 return new Proxy(this, handler);
  }
}

const component = new MyComponent([1, 2, 3]);
console.log(component.getData()); // [1, 2, 3]
```
