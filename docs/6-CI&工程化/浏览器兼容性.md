## 浏览器特征


| 浏览器           | 内核            | 描述                                      |
|------------------|-----------------|-------------------------------------------|
| **Google Chrome**| Blink           | 由 Google 开发，基于 WebKit，性能和兼容性较好   |
| **Mozilla Firefox**| Gecko          | 由 Mozilla 开发，关注隐私和开源技术        |
| **Safari**       | WebKit          | 由 Apple 开发，优化了苹果设备上的性能和能效   |
| **Microsoft Edge**| Blink (旧版：Trident) | 目前使用 Blink（新版基于 Chromium），之前使用 Trident |
| **Opera**        | Blink           | 由 Opera Software 开发，基于 Chromium 内核   |
| **Internet Explorer**| Trident       | 由 Microsoft 开发，较旧的浏览器引擎       |
| **Brave**        | Blink           | 基于 Chromium 内核，注重隐私保护          |
| **Vivaldi**      | Blink           | 基于 Chromium 内核，提供高度自定义功能    |
| **Tor Browser**  | Gecko           | 基于 Firefox 的安全版本，注重匿名和隐私    |


## Polyfill

* Polyfill 提供了对现代 Web API 或特性的实现，使得旧版浏览器可以像新版本浏览器一样支持这些特性。
* 常见的 polyfill 包括：
  * 垫片（polyfill）：提供浏览器不支持的 JavaScript 功能的实现。
  * 填充（shim）：提供浏览器不支持的 CSS 功能的实现。
  * 库（library）：提供浏览器不支持的 API 的实现。
  * 工具（utility）：提供浏览器不支持的工具函数。
* 它帮助开发者编写兼容旧版浏览器的代码，使得应用或网站能够在各种浏览器中一致地运行。
* Polyfill 通常以 JavaScript 文件的形式存在，在页面加载时引入。它们可以检查浏览器是否已经支持特定功能，并在需要时才加载。

## babel

* 在项目根目录下创建一个 .babelrc 或 babel.config.js 文件，配置 Babel 使用 @babel/preset-env 以支持旧版浏览器。

##  css
* Autoprefixer 是一款自动添加浏览器前缀的工具，它可以自动识别 CSS 规则并添加浏览器兼容前缀。
* 配置 PostCSS 并使用 Autoprefixer 插件，可以自动添加浏览器前缀。
