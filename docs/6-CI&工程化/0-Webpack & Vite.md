# 构建工具

## webpack

* **webpack**: 模块打包器、它能够转换、打包或包裹任何资源，包括图片、样式表、HTML 模板
* 在编译过程中，会将所有模块打包为一个**bundle.js**文件，然后再运行这个文件
* webpack的热更新是**全量更新**，即使修改一个小文件，也会重新编译整个应用，这在大型应用中可能会导致编译速度变慢。
* webpack有着**成熟的插件生态**，几乎可以实现任何你想要的功能，扩展性非常强
* 它更侧重于**模块的转换和加载**，例如通过 Babel 将 ES6 代码转换为兼容旧版本浏览器的代码，尤其是那些需要处理多种类型资源


* 分包原理
  * Webpack 分包的原理是通过“`代码拆分（Code Splitting）`”来优化项目的加载性能，主要包括同步分包和异步分包两种方式。
  * `同步分包`： Webpack 会根据配置`将多个入口文件打包成多个 bundle 文件`。常见方式是使用 entry 选项定义不同的入口点，每个入口点会生成一个单独的文件。
  * `异步分包`： Webpack 在代码中检测到动态导入`（import()）时，自动将其打包成一个单独的 chunk`，只有在需要时才会加载。适用于按需加载、懒加载等场景。


## vite
* vite:它是一种新型的前端构建工具，旨在显著**改善前端开发体验**。
* vite以其更快的**编译速度**和更低的**内存占用率**，给前端开发带来了全新的体验
* 开发服务器: 开发服务器利用浏览器的原生 ES 模块能力来提供源文件，支持热模块替换（HMR）等功能
* 构建工具: 生成优化后的生产代码、快速启动和高效开发，特别适合现代前端项目。
* vite在**开发模式下**，**没有打包的步骤**，它利用了浏览器的ES Module Imports特性，只有在真正需要时才编译文件。
* **在生产模式下**，vite使用**Rollup进行打包**，提供更好的tree-shaking，代码压缩和性能优化
* vite的热更新是**增量更新**，只更新修改的文件，所以即使在大型应用中也能保持极快的编译速度。
 
## rollup

* Rollup在打包过程中**移除未使用的代码**，优化最终 bundle 的体积，将小块代码编译成大块复杂的代码
* Rollup 特别适合**构建库**，因为它默认支持 ES6 模块，并且可以很容易地**输出为多种格式**

## Parcel

* Parcel 是一个快速、零配置的 Web 应用打包工具，它使用**高度可配置**的插件系统，可以快速地将代码转换为浏览器兼容的格式，并提供丰富的功能，如按需加载、代码分割、快捷的开发服务器、自动刷新等。
* Parcel 适用于**快速原型开发**，因为它可以快速地启动开发服务器，并且可以自动刷新浏览器，使得开发体验非常流畅。
* Parcel 适用于**大型项目**，因为它可以利用多进程并行构建，并且可以快速地实现代码分割，以提高性能。
