# Puppeteer

* Puppeteer是一个Node.js库，它提供了一个高级API来操纵浏览器，可以用来自动化测试浏览器，模拟用户交互，捕获页面截图，以及生成PDF文件。
    * 通过 Puppeteer 的 API，可以模拟用户在页面上的各种操作，例如`点击、输入文本、滚动`等
        * await page.click('#submit-button'); // 模拟点击按钮
    *` await page.screenshot({ path: 'test-result.png' });` 截图录制

* Puppeteer的主要优点是它可以自动化测试浏览器，而不需要手动操作，而且它还可以捕获页面截图，生成PDF文件。
* Puppeteer的主要缺点是它需要Node.js环境，而且它只能在Chrome和Firefox浏览器上运行。

##  Puppeteer 能做什么？
* `页面分析`：Puppeteer 启动后加载目标网页，获取页面的 DOM 结构及其样式信息。
    * 通过控制浏览器的 API 与页面进行交互
    * Puppeteer 提供的 page 对象来操控页面
    * document.querySelector 和 document.querySelectorAll
    * page.evaluate() 方法可以执行 JavaScript 代码并返回结果
* `元素替换`：通过 Puppeteer 获取页面中需要生成骨架屏的内容区域，替换或遮盖实际内容。通常会将文本替换为灰色的占位块，图片替换为灰色矩形，按钮等交互元素替换为线框。
* `注入样式`：通过 Puppeteer 注入自定义的 CSS 样式，给所有指定的 DOM 元素添加骨架屏的样式，比如使用 background-color、border-radius 来模拟加载中的样式。
* `截图或 HTML 导出`：在完成骨架屏渲染后，可以通过 Puppeteer 生成页面截图或导出带有骨架屏的 HTML 文件。


## 基本用法
1. 首先，我们需要引入puppeteer模块。
2. 然后，我们使用`puppeteer.launch()`方法启动浏览器，并获取一个`browser`实例。
3. 接着，我们使用`browser.newPage()`方法创建一个新的`page`实例。
4. 然后，我们使用`page.goto()`方法访问一个网址。
5. 最后，我们使用`page.screenshot()`方法生成页面截图，并将其保存到本地。
6. 最后，我们使用`browser.close()`方法关闭浏览器。

``` bash
npm install puppeteer
```

``` js
const puppeteer = require('puppeteer');

(async () => {
    // 启动浏览器
    const browser = await puppeteer.launch();
    const page = await browser.newPage();

    // 加载目标页面
    await page.goto('https://example.com', { waitUntil: 'networkidle2' });

    // 生成骨架屏的占位样式
    const skeletonCSS = `
        .skeleton {
            background-color: #e0e0e0;
            border-radius: 4px;
            display: inline-block;
            animation: pulse 1.5s infinite;
        }
        @keyframes pulse {
            0% { opacity: 0.6; }
            50% { opacity: 1; }
            100% { opacity: 0.6; }
        }
    `;
    
    // 注入骨架屏样式
    await page.evaluate((style) => {
        const styleTag = document.createElement('style');
        styleTag.innerHTML = style;
        document.head.appendChild(styleTag);
    }, skeletonCSS);

    // 选择目标元素并替换为骨架屏
    await page.evaluate(() => {
        const elements = document.querySelectorAll('h1, p, img'); // 选择需要生成骨架屏的元素
        elements.forEach(el => {
            if (el.tagName === 'IMG') {
                el.classList.add('skeleton');
                el.style.width = '100px'; // 设置宽度
                el.style.height = '100px'; // 设置高度
                el.src = ''; // 清空实际图片
            } else {
                el.classList.add('skeleton');
                el.style.width = '100%'; // 设置宽度
                el.style.height = '20px'; // 设置高度
            }
        });
    });

    // 可以选择等待一定时间以模拟加载过程
    await page.waitForTimeout(3000);

    // 截图或导出 HTML
    await page.screenshot({ path: 'skeleton-screen.png' });

    // 关闭浏览器
    await browser.close();
})();
```
